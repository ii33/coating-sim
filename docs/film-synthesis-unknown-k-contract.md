# 从零合成的显式未知 k 无损假设

日期：2026-10-20（策略引入；默认值按当前实现修订）。此项是显式保存的算法输入假设，不是吸收数据测量或真实材料无损的证明，也不改变光学材料源记录。当前从零合成界面和请求模板默认启用该未知 k=0 假设，用户可关闭以恢复缺 k 严格拒绝。接口真值以当前代码类型、签名、配置及契约测试为准；本文件解释跨模块边界，当前复用既有设计bool：请求的唯一数值策略为 `environment.assume_lossless`；GUI配置为 `synthesis.assume_unknown_k_zero`，property/slot为 `synthesisAssumeUnknownKZero` / `setSynthesisAssumeUnknownKZero(bool)`，复选框objectName为 `filmSynthesisUnknownKZeroField`。不新增请求顶层字段或schema版本。

## 输入、状态所有者与策略

优化页提供独立的“未知 k 按 0 计算”选项；当前新建从零合成默认已选中，用户可关闭。复用项目现有无损假设语义时，必须保持“仿真使用消光系数 k”启用；不得通过关闭全部 k 来实现此选项。控制器拥有可编辑策略草稿，开始时冻结到唯一请求；该次 worker、候选、审计、历史结果及保存都使用该快照，不能在后台读取后来改变的 GUI 策略。

只允许把源记录没有提供的 k 当作无量纲0。已提供的有限非零 k 必须保留原值；已有 k 数据的域外查询是波长域错误，不是“未知值”豁免。无效/非有限 n、n≤0、损坏的 k、缺少材料/集合以及任何应拒绝的域外查询仍失败。严格策略下缺 k 仍拒绝。入射端口和单面/front适用边界沿用核心规则，不凭无损假设扩大支持范围。

## 冻结、计算、审计及输出

唯一物理策略随请求及其冻结快照往返，保持原材料/光学集合的标识、原始数据及来源。实际计算可利用原有采样器的未知值零回退，但只有冻结请求的布尔值为 true 才获得该许可（当前合成默认 true，可关闭）；该许可不放宽 n、已知 k 域和非法数据检查。任何审计新增点都再次检查相同规则。

输出须明确标记“未知 k 的无损近似”，列出受影响的 material_id/optical_set_id 和适用目标波段。已知 k 保持来源属性，假设的0不得标为实测或来源给定0；结果达标表示在该假设下通过有限目标审计。请求候选池与最终光路中受影响引用须能区分，避免把未使用候选误称为最终膜系材料。有限审计依旧不是连续证书。

设计/配置、JSON请求、队列、检查点、结果、候选保存及重新打开必须保留同一策略。保存原始未知 k 数据，不把零写回材料库；结果说明和可编辑设计保留该假设。缺少必要策略/材料闭包或发现不一致时明确拒绝保存/执行，不从实时目录猜补。当前合成GUI和请求模板默认启用该假设，用户可关闭；完整typed设计仍按既有schema要求显式布尔assume_lossless，缺字段或非布尔在设计校验处明确拒绝，不靠后续KeyError。旧结果不能被重新解释为已选择本近似。

## 异步、取消与错误

编辑选项使旧预览/结果失效，运行时禁止修改本次冻结值。取消、迟到结果、工程/源版本围栏沿用现有 run coordinator 和 typed scheduler；不会因缺 k、心跳或无响应标志自动批准近似。当前新建合成默认启用该假设，但用户可关闭；只有冻结策略为true时才按0计算。计算前错误不提交队列、不修改设计；审计中新域错误不得提交完整达标候选。默认轮数、评价数和层数预算仍未指定，不恢复低额默认预算。

## 定向验收

关闭该选项的仅 n ZnS 基片须严格拒绝；默认勾选时通过真实界面点击开始并见运行/结果，同时显示假设。反例覆盖已知非零 k 保持、n/已知 k 域外仍拒绝、源记录 SHA 不变、请求/结果/审计/保存往返一致、取消/回写不混策略。成功标准须声明材料来源与假设，不能把 synthetic 或假设吸收算例当实测材料达标。

本选项及元数据组织为“本项目约定”，未找到外部依据，仅为本项目实现。复折射率和有限审计定义沿用离线[算法文档](algorithms.html#film-synthesis-audit-20261020)。

## 当前实现字段及结构seed边界

唯一数值策略是既有 `environment.assume_lossless`，且 `use_k=True`。GUI候选结果说明读取冻结结果的 `absorption_assumption`，其中 `affected_materials`表示请求冻结池/seed/环境中受影响引用，`used_affected_materials`表示实际候选活动光路引用，分别展示。原材料记录不添假k表。显式seed副本保持同一策略，源设计不因勾选被替换。

自动合成入口若接收 `physical_structures`，仅在构造该请求的seed时显式传递同一未知k策略；生成处方仍受原nH>nL、透明模板和域限制，不把已知吸收清零。独立物理参数GUI不因此自动开放此近似。可选API参数的默认严格语义及输出设计flag须一致，最终以当前签名和契约测试核验。

具体构造签名：`generate_physical_structure(environment, spec, frozen_material_snapshot, *, assume_unknown_k_zero: bool = False)`。显式开启须与保存的environment标志相符；默认严格。自动合成IO及typedjob派生seed使用请求同一值，独立构造GUI继续默认严格。候选保存除bool外还须保留可读假设/实际受影响引用注记，完整冻结结果另保留全请求池和实际光路清单。

## 候选声明与界面拒绝边界

输入池中缺k的材料可以未被实际候选使用。候选级claim和conditional_on_assumption须以used_affected_materials为准，affected_materials仍完整保留输入池范围，不把未用候选说成最终光路。source采样策略保持明确，源schema以validate_optical_set为真值，不额外接受猜测的k字段。

无损复选框在运行、关闭以及尚有未处理非法编辑时不可改变；若在信号/状态竞争边界setter拒绝，恢复到controller属性绑定，不保留与请求不同的视觉勾选。错误修正后重新可编辑，不能因一次拒绝破坏后续checked绑定。历史checkpoint若缺工作量字段，合法候选仍可查看/保存，工作量显示未知，详见执行契约。
