# 膜系优化方法使用说明

## 选择方法

所有固定层序方法只修改稳定层 ID 所选变量的物理厚度，闭区间界限单位 nm。
材料、光学数据集、层序和未选中层固定；目标 R/T 是 0–1 的功率比例，不是百分数。
`solver="baseline"` 保持旧默认方法。其他方法必须显式选择，不能因依赖缺失而静默换方法。

| 方法 ID | 基本原理 | 优点 | 缺点与不适用场景 | 适用场景与技巧 |
|---|---|---|---|---|
| `baseline` | 每轴含端点的17点扫描，再坐标正负试探；无改善步长减半 | 确定性，原有行为，无SciPy需求，易解释 | 耦合变量时可能停在差的局部解；粗网格可漏掉窄谷；不是全局搜索证明 | 小规模和回归基准；先设真实工艺界限，保留与其他方法的对照 |
| `powell` | 有边界的方向集与一维线搜索 | 无导数，能探索非坐标方向 | 仍是局部法，线搜索耗多次光谱；振荡多峰可能停错谷 | 已有可用层序的厚度精修；先缩小合理边界，再给足完整评估预算 |
| `nelder_mead` | 单纯形反射、扩展、收缩与缩小；边界裁剪顶点 | 无导数，可探索变量耦合 | 边界裁剪可使单纯形退化；维度增加时慢；不宜高维或边界狭窄解 | 少量变量、局部起点；从内部起点尝试，和Powell交叉检查 |
| `multistart` | 当前起点及seed控制的均匀随机起点分别运行Powell，共享预算 | 降低单一起点依赖，可复现 | 不是新的局部算法或全局保证；预算过少时每个起点精修不足 | 多峰而变量较少；增加起点时同比增加预算，用不同seed复核 |
| `differential_evolution` | 群体个体差分变异、交叉、选择 | 无导数，群体探索多个盆地 | 完整代评估开销大；小预算可能连初始群体都算不完；不保证全局最优 | 宽界限与较强耦合；预算至少覆盖多个群体代，用独立seed并另做局部精修 |
| `simulated_annealing` | 有边界随机扰动；Metropolis概率允许临时变差，温度逐步下降 | 可跨越局部障碍，内存开销小，可复现 | 对温度、步长和预算敏感；短退火容易冻结；不是严格的全局收敛日程 | 多峰探索或DE群体过贵时；先做探索，再用局部法精修；记录seed |
| `trf` | 解析厚度Jacobian驱动有边界信赖域反射最小二乘 | 局部通常节省候选评估；直接利用多条件残差 | 残差平方和与原始最坏误差目标不同；局部法；解析能力域外显式拒绝 | 单面前表面、可靠解析域内的局部精修；对照原始最坏误差和留出验证，避免只看平方和 |
| `lbfgsb` | 解析梯度与有限内存拟牛顿近似，在厚度界内做局部下降 | 无需完整Hessian，可用精确梯度 | 线搜索可能失败；平方和代理不等于minimax；不能用于未支持结构 | 解析域内的局部精修；归一化厚度尺度，先用可行起点，与TRF对照 |
| 独立needle入口 | 依次在明确材料与界面上试插有限薄层，精修后仅接受原指标严格改善的结构 | 可探索固定层序之外的结构，预算和回退明确 | 本项目有限插入启发式，不是零厚度needle敏感度算法；材料/层数搜索受限且制造可行性未自动验证 | 允许新增层时，先限定候选材料、最薄层、总层数和厚度上限；与固定层序结果对照 |

## 原始目标、代理与验收

条件误差 `e=abs(actual-target)/scale`，范围目标为越界距离/scale。
每个启用目标展开为所有波长×角度条件；默认每点等权，用户目标权重作为每点的额外倍率。一个目标的总权重质量是有效点数乘用户权重，不先求目标均值。
最佳候选比较键为 `(未达标标志, sqrt(sum(weight*e²)/sum(weight)))`：已达标候选始终优先，同组内比较逐点加权 RMS。`max(e)` 独立用于每个条件的达标判定，权重不能掩盖违约。
无导数方法的标量搜索以逐点加权 RMS 驱动，未达标时增加可行性屏障；外层候选档案仍保存最佳完整候选。
TRF与L-BFGS-B用带符号残差的加权平方和；范围残差在范围内为0、外部取带符号越界值，
在边界导数取0。范围平方罚函数一阶连续，但残差在边界不可微；这个边界约定属于本项目实现。
不把含达标边界的排序键直接传给梯度法。

评分由共享helper进行有限性校验，RMS先分解二进制尾数和指数，再缩放累积并恢复最终指数。
它保留可表示的极大/极小RMS（例如1e−200误差与1e−300权重的RMS仍为1e−200）；真正非有限的归一化、带权指标或解析残差/J/cost/gradient显式拒绝。
此数值实现不提供任意精度保证，也不改变原始K。

`targets_met` 只表示请求网格的最大归一化误差小于等于
`acceptable_normalized_error`，不代表连续谱全域满足，也不代表搜索正常结束或全局最优。
多角度与s/p目标仍独立计算；`unpolarized` 按既有物理语义平均s/p功率。
优化结果保留每个原网格条件的实际值与误差。

默认再用每个波段 `(N-1)*2+1` 个点验证，原点间插入中点；单波长仍1点。
仅增加波长采样，不自动增加角度。留出网格只用于验收，不参与选优。
每个objective先生成全局网格，再以至多10001点非重叠分块；10001是工作分块大小，不是目标总采样上限。每个波长/角度只统计一次，单点尾块保留，不跨不同objective合并目标。
`validation_complete`、`validation_targets_met` 及验证误差与训练结果分开；
取消、未完成或验证失败不能宣称验证通过。中点加密仍可能漏掉更窄的峰，正式设计应按制造和测量要求进一步检查。
这些网格、误差优先级和默认阈值都是“本项目约定”，没有外部来源证明它们适用于所有膜系。

## 预算、取消、失败和可复现性

固定层序默认共享200轮/1000次完整候选评估，用户仍须明确设置正整数停止预算，不另设人工计算量顶值，也不以0/None表示无限预算。原每目标10001个波长、角度361点、训练20000条件和验证200000条件的人工配额已经移除；保留数值/物理有效性检查及实际分配、后端资源失败反馈。厚度变量可覆盖全部合法膜层，不再单独限制8个；设计文件仍保留正反两面合计4096层的解析/校验边界，该边界不是本轮新增的优化计算量配额。
失效候选消耗评估预算；所有起点和群体使用同一预算。
解析适配完整候选缓存为容量2的LRU，成功/失败共用容量；fun/J同点命中不计次，淘汰重算计次。
初始普通谱值计1次，首次Jacobian另计1次，预算1时只返回普通谱值候选；独立best档案不随缓存淘汰。
留出验证另报计数，不混入搜索预算。每个方法需要检查其终止原因与失败计数，不能把耗尽预算显示成达标。
取消在完整候选边界生效；初始候选仍完整评估以提供可用回退设计。checkpoint只发布完整计算的最佳候选。
初始候选失败抛出明确错误；后续失效保留原最佳候选并记录失败。取消不自动应用候选。
seed只控制随机方法，固定方法仍回显以便记录。相同快照、依赖版本、参数和seed下复现；跨SciPy/平台的浮点轨迹不作逐位保证。

先选覆盖工艺可行厚度的上下限，不要只用极宽范围；规范权重与归一化尺度，避免某类条件以数值尺度主导代理。
比较算法时保持冻结材料、目标、搜索预算和验收网格相同。先保留旧基线，再记录独立seed的结果和失败，而不是只挑一次最好结果。
没有默认算法适用于所有膜系；最坏误差下降、留出通过和制造可行性应分别检查。

## 解析导数与needle的能力边界

解析模块采用与现有光学内核相同的符号、复折射率及s/p导纳，对稳定复振幅递推逐层解析求导，导数单位为每nm。
仅支持单面、从front入射的coherent前表面结构；双面、不相干基板、背向入射及专用内部临界分支显式拒绝。
QW层先按既有参考波长规则转为物理nm；求解变量仍是nm，不是QW标量。
支持域通过中心差分和现有service谱值对照后才可接入梯度法；中心差分仅用于测试。

needle独立请求包含基础固定层序请求、显式材料/光学集引用、新增层数与总层数预算、
新增层最薄/最厚nm、每界面试插次数及seed。现有层稳定ID保留；新增ID确定性生成。
当前默认最多新增1层、总层数4096、插入厚度0.5–200nm、每界面每材料1次试插、seed=0；
新增1层是可调预算的默认值，显式增大 `max_added_layers` 可执行多轮接受插入，每轮保留已接受层，仍共享同一迭代/评估预算；独立经典结构请求的单轮边界不适用于该有限试插API。
原有选中变量与新增层不再共用人工8变量上限；实际按显式新增/总层预算执行，现有文档解析最多4096层是资源防护。插入厚度界限仅约束新增层，原变量沿用自己的nm界限。
这些是本项目约定，调用方应按制造约束显式记录采用的预算。needle独立API尚未接入固定层序队列请求。
只接受严格改善的完整原指标候选，失败或取消回到最后已验收结构。整个结构搜索共享预算。
基础请求无旧层变量时仍统一验证solver、seed、有限容差、步长与预算等全部控制字段；加密验证同样非重叠分块。
不复制或宣称实现Macleod Optimac等专有方法，未公开细节不补写成已知算法。
