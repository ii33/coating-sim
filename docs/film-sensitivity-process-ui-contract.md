# 膜厚工艺误差与保名义优化面板契约

日期：2026-10-23。此文解释正式敏感性面板边界；接口真值仍为
`FilmSensitivityQuickController`、QML objectName 与核心 typed request/result。
沿用 `film-sensitivity-contract.md` 的来源身份、物理回放、终态、报告原子性和应用确认门禁。
不修改生产渲染后端、共享 Theme 控件、普通目标、原采样网格或原验收阈值。

## 输入、默认与兼容

新面板只默认选择 `nominal_preserving` 和 `finite_scenario_worst`。
每层绝对 nm、相对 %、误差幅度语义、分布、样本数与 seed 均需明确填写/选择，
没有未经校准的制造精度、分布、样本数或安全余量。相对数值除以 100 后进入请求。
同层误差为 `absolute_nm + relative_fraction * d`，两项共用一个系数，直接相加而非 RSS。
兼容 `setMagnitude` 的旧 magnitude/unit 项仍相加；新层不擅填旧幅度。
所有数值需有限且非负；样本数和 seed 用严格整数文本，拒绝 bool、非文本、NaN、负数和半成品。
空分量仅在另一分量有明确数值时代表该分量为零，全部留空不可提交。

用户明确区分有界幅度与标准差 1σ；有界均匀与前者匹配，高斯与后者匹配。
高斯系数不裁剪，可超出 ±1，因此绝不能宣称为有界误差。
误差模型可选择逐层独立、全部共模、同材料共模、沉积顺序线性漂移。
分布只是用户选择的假设，不是已测工艺校准或制造良率。

生成按钮调用核心 `generate_film_sensitivity_scenarios`，保存返回的完整显式系数和权重，
真正放进随后冻结请求。任一配置编辑使旧场景失效；来源设计改变也拒绝复用旧场景，必须重新生成。
旧 `generateScenarios` 仅保留明确 ± 轴扰动/共模探针，不称为 Monte Carlo；新正式入口使用显式采样。
分析仍可独立选择线性敏感度；保名义优化拒绝线性目标，必须选择有限场景最坏或加权 RMS。
纯降敏 `robustness_only` 为显式选择并醒目提示名义指标可能恶化。
旧 JSON 缺 policy 的解析仍由核心保留 `robustness_only`，界面不迁移、不重标历史。

## 唯一状态所有者与编辑边界

控制器拥有工艺草稿、完整场景、运行代次与只读报告；QML 只显示/发送用户编辑，不复制科学状态。
编辑文本立即送入草稿，未完成数字不能沿用上一次已提交值误启动。
生成场景前重新取当前设计；启动前重新验证所有草稿与场景来源，冻结后本次请求不可变。
运行期间拒绝配置修改/重复启动；取消只表达意图，等完整前向边界与队列终态确认。
关闭沿用 durable job 观察者/项目所有权语义，迟到代次不得覆盖当前状态。

## 状态、结果与确认

加载/冻结/排队可见并禁用重复提交；没有膜层显示空数据及“先添加/合成真实膜系”，不伪装为计算失败。
输入不完整、分布语义冲突和来源变化明确显示原因，保留草稿，不自动猜测或降级目标。
物理/提交失败沿用原错误状态；提交结果不确定时禁止自动重复提交。
初态名义不满足时说明先恢复原名义约束或更换初态；不更改目标或加入 margin。

报告同时显示 frozen policy、幅度/1σ语义、名义与有限场景各自结果，并明确局部非全局、非良率保证。
最终 partial 只有核心已验证的有效候选才可能沿原门禁应用；保名义策略额外要求候选名义满足。
失败、取消、未完成检查点与只读历史不能应用。正常运行结果仍需页面显式应用确认，
再复核源 revision、pending edit epoch、项目上下文，并作为一个可撤销的未保存事务写回。
报告保存仍使用同目录临时文件/完整序列化/fsync/原子发布；覆盖必须明确确认。

## 页面布局与验证

沿用共享 Theme token 逻辑 px/pt、原对话框几何与确认路径；不再乘 DPR。
配置区垂直滚动，轻量草稿通知不重建膜层编辑器，保留焦点和滚动。
按钮 objectName 与输入 objectName 提供真实 Qt 定向验证入口。
当前云环境禁止创建 AF_UNIX；测试仅以 offscreen QML、真实控制器冻结的 JobSpec 和
直接 production execute_job 验证，不启动/探测调度器端点。端点与生产图形栈仍需 CI/主机验证。
