# TFCalc 明文层表导入

日期：2026-10-14

1. 在 Qt Quick 膜系设计窗口先设置要沿用的基片、介质、入射面及光学开关。
   点击“打开”，选择 `.tfd`。窗口会先提交当前输入，再显示同窗导入对话框。
2. 核对预览中的层数、前八层及原始两列数值。第一/第二层表是文件记录，
   不自动等同正/背面。选择要导入的源表及要替换的目标面；导入背面前须将
   当前基片设为双面。空表不能导入。
3. 默认采用本次用户明确确认的明文 profile：LAYER 第二数值是物理 nm，
   层序从基片向外。其他文件若不符合，展开“高级映射”选择数值列、物理
   nm/μm 及源顺序；外侧向基片的输入会反转成项目保存顺序。不从光学厚度
   或新材料的 n 自动换算。
4. 每个材料别名都必须手动选择已有项目材料，再选择其所属光学数据集。
   不会仅凭名称猜测材料，也不会补造 n/k。先在材料库准备缺少的数据。
5. 核对参考波长，勾选沿用当前环境及设置。默认沿用当前参考波长；改它会
   改变另一面保留的 QW 层物理厚度，nm/μm 层不变。未知环境、目标、绘图
   及 flag 不导入；TFCalc 原始表达式只写入备注，不执行。当前表达式文本/
   符号草稿保留并标为不同步，不用于重建导入层表。可展开报告查看未解释项。
6. 点击“生成导入预览”，确认层数、总物理厚度、目标面，再点击“确认替换…”
   和替换确认。之前的预览/取消/失败不改变设计。成功后为未保存草稿，
   配对光谱窗口沿用同一文档；另存为 `.cfilm`。原 `.tfd` 不会被改写。

切换输入、重新打开、取消、禁用插件、设计变更或关闭都使旧预览失效。
发现冲突时先完成设计输入，然后重新打开文件生成预览。插件启停只作用于
当前膜系服务的内置导入器；没有扫描第三方目录或执行外部代码。

只接受 UTF-8/ASCII、最大 2 MiB、VERSION 1 星号分隔明文子集。其他版本、
二进制、截断或层数不符会报错。这里不宣称完整 TFCalc 兼容或性能等价；
更多接口边界见 [契约](tfcalc-import-contract.md)。
