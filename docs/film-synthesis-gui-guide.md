# 使用从零合成和物理结构生成器

日期：2026-10-26。入口来自当前主项目源码；本轮没有发布安装包。在项目检出目录使用现有启动器进入工程；膜系设计和优化仍为现有页面。

## 批量修改厚度约束

优化窗口的“约束”页可一次修改现有膜层的厚度上下限，单位为真空纳米（nm）。默认范围为“全部层”；“已选择的厚度变量”复用逐层的选择按钮，不新增一套选择状态。下限、上限可单独填写，留空表示保持该项原值，0 是有效下限；空白上限在此处不表示删除已有上限，需要取消单层上限时仍使用原单层编辑框。

点击“应用边界”才提交。所有受影响层的最终上限都须大于下限；任何一层冲突或输入非法均拒绝整批，保留原边界及输入草稿。成功后一次更新和保存现有优化配置，不改膜层厚度、层选择、光学目标或算法设置；仍可继续逐层编辑。加载合成新结构后操作当前层ID，不把旧层约束套到新层。批量面板只拥有未提交文本及反馈，实际边界与配置仍由既有优化 controller / 文档会话拥有；计算期间沿用原编辑禁用规则，不修改运行任务的冻结请求。

## 从空栈开始自动合成

1. 在当前工程打开膜系设计，设置实际入射介质、基片及光学数据集；当前核心支持单面、front入射并保留真实n/k。可以保持正面层序为空。
2. 打开现有优化页，在“算法”页的模式中选择“从零自动合成”。目标页沿用当前目标和百分比单位。角度下限和上限可以相等，表示单角度（包括0°和非零角）；先填下限、再填上限时中间文本会保留，未完成或非法范围会提示并阻止开始。候选膜料区点击“＋ 添加候选材料”，逐行选择当前工程膜料及其光学数据集，使用“×”删除该行；数据集随该行材料联动，空列表不能开始。
3. 总轮数、评价数和可选厚度/层数限制留空表示不设该限制。只有需要把当前处方同时加入起点时，才勾选使用当前设计；默认保留N=0路线。
4. 点击开始后，任务进入当前工程的现有队列。查看实际阶段、评价数、层数、指标、心跳及停止原因；取消是协作式，等待当前不可分割求解返回。
5. 结果区查看逐目标分数、候选层表和审计状态；“查看候选采样光谱”显示任务目标的冻结采样点，不表示连续谱。普通优化和从零合成正常完成后，完整合法候选自动写回原膜系并刷新同工程光谱。用户在当前窗口或对应工程队列明确取消时，同样应用取消前完整计算的最好合法候选；这可能尚未达标或没有独立审计，界面会注明。应用可撤销，不自动保存。来源已编辑、材料改变或资源切换时保留候选并提示冲突；失败与历史队列结果不自动应用。独立减层/减厚仍由用户显式应用。

实时光谱默认自动调整纵轴上限，纵轴数值为百分比；关闭“自动轴”后可输入百分比上下限，后续曲线不会覆盖手动范围。图下“当前最佳”详情来自同一个真实冠军，显示层数、总厚、所选波段/角度的完整原网格均值及峰值、全目标最大归一化违规和 RMS。均值仅作统计，逐点达标仍由原目标判定。

数值伪零层在发布候选前按相位尺度清理并复算，不把真实亚纳米层按显示位数截成零。预算或取消使清理未完成时，界面明确说明潜在更优试探未被采用，保留此前完整候选；该候选的审计状态按自身身份显示。没有安全完整候选时，原设计不变。规则及精确阈值见[算法说明](algorithms.html#film-numeric-zero-20261026)。

当前运行的项目候选使用提交时冻结的完整可编辑材料闭包。独立 `.cfilm` 仅保存材料引用，当前材料已被修改或缺失时会拒绝另存，避免重开后使用不同 n/k；此时使用项目候选保存。完整可编辑设计的材料闭包缺失时明确拒绝应用，不自动从后来变化的目录补值。旧历史队列没有当前可信来源与GUI额外闭包时，若其活动快照不足以保存完整可编辑引用，会拒绝另存并指出缺失材料；仍可查看层表和候选采样图。

角度与候选行随现有设计优化配置保存。重新打开保存的设计后，候选行顺序、材料/数据集稳定标识和合法角度保留；未完成编辑须先修正后保存可运行配置。

任务是否正常完成、数值局部是否收敛、返回候选是否达标分别显示；完整有限审计也不等于达标或连续证书。默认 hybrid 在合理结构经过本轮实质局部优化后，即使指标未达到，也可因数值收敛或无有效改善正常结束本轮，保留最佳完整候选并列出剩余违规。取消、预算耗尽、审计拒绝与收敛分开显示，不据此声称全局不可行。

### 本轮完成后继续结构搜索（2026-10-28）

局部完成后仅接受不恶化既有最佳指标的减薄，无可接受减薄便保留局部结果结束。减薄没有固定总评价数或时长硬上限；单次局部求解的迭代保护若仍产生实质变薄，则继续同拓扑求解，直到收敛、无有效改善、错误、资源保护或用户取消/显式预算停止。未达标不会触发自动无限扩结构；点击“继续搜索”才创建下一任务，从已保存的结构源游标、待评候选、候选池和随机推进继续。它与下文旧“从保留结果继续”的候选暖启动是不同操作。查看、保存、关闭重开保留前沿；兼容厚度/拓扑编辑先重新评分当前设计作为 seed，目标/材料/约束不兼容则说明重建原因并保留旧状态。

返回结果、自动写回、光谱和底部最佳详情使用同一已完整核验候选。新结构局部终态不及历史冠军时仍可结束本轮并返回历史最佳，但不把该终态的收敛标签贴给历史冠军。来源修订、编辑代际和项目切换保护照旧；正常未达标结果按真实差距显示，不伪造原目标已通过。

## 取消后从保留候选继续

常规固定层序优化和从零自动合成（含默认 hybrid 的内部增长/针插）取消后，完整候选可点击“从保留结果继续（重新启动求解器）”。对话框分列上次已耗计量与本次新的预算；它创建独立队列作业，不累计或改写旧作业，原 mean/pointwise 目标、边界、材料数据、算法选项和已解析种子不变。只继承真实候选几何，不恢复 L-BFGS/SLSQP 内部状态、DE 群体或随机数游标。新的首个评分会重新计算保留最好候选并计入新预算；没有完整新评分时，上次结果单独保留，不冒充新结果或再次自动应用。

来源改动、撤销、未提交字段、材料冲突、资源或项目切换时，按钮禁用并说明原因。当前版本的新作业把稳定膜系来源与可编辑材料增量保存在现有工程队列；重新打开同一未改变的已保存工程膜系后，可从通过验证的取消历史结果继续。当前协议的匿名稿或缺少可信来源绑定的历史仍只读，不猜测归属；旧 schema 显式拒绝，不兼容迁移。独立“结构优化”模式与工艺薄层修复暂不支持该入口。详见[继续优化契约](film-optimization-continue-contract.md)。

## CPU 工作进程和前向设备

“算法”页从零合成模式中的“CPU 工作进程数”请求候选评价进程池宽度：1为串行，正整数请求相应数量；默认hybrid的0按冻结时可用CPU自动选择，不存在人为4或8进程上限。显式legacy兼容路线的0保留原来的最多8个默认。真实并发还取决于候选数、计算工作量、阶段/总预算、冻结内存和通信大小，不能从请求19推断实际19。

“独立候选逻辑批次”留空为AUTO，冻结时按请求数及可用CPU解析为正整数；也可显式填写正整数。它不是实际worker保证。相同冻结批次下改变执行进程数，保持源序、采样、解析导数和候选采纳顺序；改动逻辑批次本身会改变搜索调度，不是同一串并对照。结果区分别显示请求数、真实PID数量、阶段准入并发上限及退回串行原因。

多进程只加速相互独立的工程先验/全局候选和同一已确定针扫轮次。联合全部厚度优化、候选档案采纳、后续轮次构造及独立验收仍保持必要的顺序依赖；独立敏感性工作流本轮也不宣称多进程加速。子进程各自保留冻结材料上下文，并非共享内存；小任务可能因启动和通信成本保持串行。此设置不是总轮数、评价数或时间限制。

“前向设备”默认CPU；点击“重新探测 GPU”异步检查当前执行环境，选择可用CUDA、ROCm或XPU以及具体“GPU 设备”。探测会显示加载、无可用设备或失败原因，探测过程中可继续查看页面。该选择只加速有限厚度growth前向，解析导数、needle、精修和验收仍在CPU；结果区以实际设备为准。当前首版仅支持本地GPU任务，远程GPU会在开始前明确拒绝，CPU远程任务仍可使用。

GPU是否可用须以当前执行环境的异步探测为准。探测失败不表示其它计算模块的GPU能力可以复用；保持CPU默认，不根据微型前向计时推断完整优化的加速。选择其它解释器应保留原GUI环境，先验证设备和依赖，再测试完整任务。

## 点击开始后提示 n/k 无效

从 N=0 起步初始继承当前设计的基片；可在从零参数区顶部选择真实基片材料与光学数据集，并配置候选膜料。选择进入冻结请求和结果应用，不改变厚薄基片、背面模式或入出射介质。角度上下限 0/0、空正面膜堆本身合法。新建或未配置时，针插前局部优化与“未知 k 按 0 计算”默认开启，可显式关闭并保存；已有明确选择优先。未知 k=0 是带标注的无损假设，不改材料记录；已知有限 k 保留，非法数据及 n/已有k的波长域仍严格。

若提示包含 `builtin_research_ZnS_substrate` / `ri_zns_debenham_n`，当前这份“Debenham-Klein/块材20°C/1986”内置数据只提供 n。其 n 波段覆盖 405–13000 nm，但 k 未知。可回到膜系设计的“基片与介质”设置，为实际基片导入/选择覆盖目标区间且明确提供 n/k 的可靠数据；也可在愿意接受未知吸收近似时勾选上述选项，结果会注明假设及受影响材料。保持原材料记录和来源，不以沉积膜样品代替块材，也不把用户明确选择的计算假设写成材料源的 k=0。修改来源设计后保留草稿，重新打开优化页使请求绑定当前设计；再核对候选材料及各自数据集、目标和单角度设置后开始。首个失败输入被指出不表示其余材料已经通过所有校验。未通过输入校验时尚未提交任务，原设计不会被替换。

明确标为 synthetic、已定义 k 的标准材料可用于验证程序链路；这样的结果不代表真实 ZnS 设计已经获得材料数据或达到实物指标。

## 构造物理结构作为处方或搜索起点

在膜系设计侧栏选择“参数设计”，再切换至“物理结构与组合段”。使用当前设计的入射介质、基片和参考波长；不会暗中改为另一种端口或基片条件。

- 选择多堆/匹配、多腔/耦合镜、啁啾、数字rugate或组合机制。按需要增加、删除和移动结构段；表单次序为基片→入射侧。
- 为“高折射率膜料（H）”“低折射率膜料（L）”选择当前工程材料和光学数据集。常见结构只需这两项，腔层默认复用H，也可选L；多个用途可选择同一材料，不表示必须三种不同材料。仅确实需要独立腔层或匹配层时，才“添加独立用料”。各段的波长/厚度单位为nm，光学厚度n·d/λ为无量纲（0.25为四分之一波长），相位为rad。膜对数、匹配厚度、独立端镜/耦合镜、腔参数、啁啾范围或rugate分片可在表单中编辑。
- 可填写额外材料校验波长。点击“预览真实逐层处方”，检查材料、数据集、物理nm厚度与适用限制。未知k或波段不足会报错，不套用经典模板的未知k无损选项。
- 点击“确认替换当前草稿…”并确认后，结果成为当前文档的未保存草稿；保存/覆盖沿用原操作。其他编辑前可使用“撤销应用”恢复一次。改变参数或材料后须重新预览。

生成不会自动优化。需要继续搜索时，从同一设计打开优化页，并显式选择把当前设计作为附加起点。结构生成不代表其光谱已达标；数字rugate的深亚波长近似、相位/GD/GDD未支持等边界见[物理结构契约](film-physical-structures-contract.md)。Ge有限增层加TRF的研究邻域脚本没有列为产品模式。

输入、状态所有者和异步边界见[GUI契约](film-synthesis-gui-contract.md)，算法与来源见[离线算法文档](algorithms.html#film-synthesis-audit-20261020)。

## CUDA GUI 启动（可选）

默认沿用项目现有解释器；CUDA是独立可选入口，不会替换默认环境。若已配置带CUDA支持且依赖齐备的Python，在项目检出目录用该解释器运行 `launcher.py`，然后在“膜系优化”→“从零合成”执行设备探测并明确选择CUDA；未选择时仍沿CPU路径。

例如在PowerShell中，先将 `$CudaPython` 设为自己已安装、验证过的CUDA Python可执行文件，再运行：

```powershell
& $CudaPython .\launcher.py
```

这个命令不安装CUDA、不修改现有虚拟环境或应用设置。临时环境可能被系统清理；解释器不存在时先按实际安装状态修复，不依赖某台电脑专用的快捷方式或文件路径。启动和探测成功不等于优化算法已运行或达到目标。

## 2026-10-22：默认混合搜索与独立敏感性

- “从零合成”默认使用 hybrid：多结构工程先验广筛、完整候选档案、局部/全局探索、解析批量针插、删层/同材料同光学数据组合并，再用全部原始条件精修。legacy 是显式兼容选项，不是新默认。批针数量、可选针前局部优化、位置细化和档案容量均可设置；层数/制造厚度留空表示未施加该项约束，并非默认32、70或104层。
- 探索 merit 与名义最坏违规分别记录；等窗口加权是默认探索度量，不改变任何原始采样点或严格验收。可临时恶化最坏点的探索终态不会替换掉独立保存的严格冠军。预算停止、求解失败、资源限制和收敛不是同一状态。
- 计算内存护栏提供自动、手动字节和关闭三种模式。自动只在冻结时测量一次可用内存并以一半作为阶段预估上限，保存实际解析值供重放；无法测量时明确记录保守回退。它是阶段准入预估，不是内存配额或物理层数上限。结果显示实际资源跳过，用户可提高显式上限或关闭护栏，但须自行承担内存风险。
- 优化窗口的“敏感性”只保留两个独立入口：参数表分析与默认理想敏感度优化。理想优化须显式选择绝对J·1nm或相对J·d，默认受控政策须为每个目标填写固定初始光谱退化额度（百分点）；也可显式选择原名义硬约束。参数表不向优化目标注入幅度、权重、相关性或工艺预设。
- 当前GUI为本地CPU独立队列，只支持既定单面固定层序R/T解析域；具体限制见[两入口契约](film-sensitivity-workflows-contract.md)。原名义与guard/F分别显示。合法候选须明确确认后才应用；来源版本、编辑代际或材料改变拒绝回写。表格只有分析无应用候选。已移除的工艺场景格式与理想schema 1不支持、不迁移，也不打开通用结果fallback。

回归示例中的通过仅代表该示例的独立有限网格验收，不保证任意目标可解。原四窗口的正式冷启动长测尚未通过，不能把研究已知处方重放或“无软件异常”称为自动合成达标。

### 名义通过不再借用求解容差

结果、独审、CLI及队列分别报告“原门限名义验收”和“求解容差可接受”。例如实际R=4%、上界3.95%、归一化求解容差0.001时，后者可接受但前者失败，不能显示为达标。求解容差配置及原目标数值保留，不自动加制造余量。精确R≤0遇到微小正反射时同理。

自动合成目标行的“严格上界”表示数学 `<`，所以严格R<3%在等号处不通过；未选择仍保留原来的含等号上界。设置仅属于自动合成及独立敏感性，不混入普通结构优化v1请求。敏感性报告中的百分比违规和归一化误差也分别显示。

## 显式实验：目标进展交接与工艺薄层修复（2026-10-25）

目标进展交接实验已移除；普通进度、当前最佳与真实结构续搜保持。

工具栏“工艺薄层修复…”针对当前真实设计，和从零合成不同。2026-10-27起只需三项：单层目标厚度nm、厚度容差nm、光学指标容差百分点。无需选层，自动识别低于“目标−厚度容差”的薄层，其他层可联动且允许增删合并。目标10nm、容差2nm表示完成时全部非零保留层不薄于8nm，100nm厚层仍可保留，并非总膜厚目标或8–12nm统一区间。允许薄层连续降到精确0以尝试消层；0不计薄层不足，不以极小正数代替。零厚定向局部片只把选中层拉向0，其余层继续原厚度修复目标并联动补偿，不新增参数。QW源按原材料和参考波长换算成物理nm。

光学容差逐点比较本轮固定原快照的对应波长、角度、偏振及R/T曲线；50%变51%是1个百分点，不能用正负变化的均值抵消。没有启用目标时继承当前仿真配置/原曲线的波段、采样、角度和偏振，原目标状态为不适用；仅无现有配置时复用原仿真默认值，材料插值/外推政策不变。

过程中逐层显示原始、当前试探和最佳完整候选厚度及变化，当前/最佳总厚度分别来自同一候选hash和seq下的完整物理层表；未换算QW报未知，真实空设计总厚才为0。各行仅以一条背景条表示当前厚度，共用同一nm刻度；刻度上限由本轮原始、当前和最佳厚度共同确定，只扩不缩，新一轮才重置。新增、删除和合并按稳定层ID/来源标记，不把第几行当作同一层。当前0标为“待核验消层”，仅供预览；必须删除0、仅合并同材料同光学数据的相邻层、重新训练并独审新hash后，才可能成为可应用最佳。原生最小非零厚度只允许被零厚定向选中变量的训练试探穿过，正式非零保留层仍守原生全部边界。应用后主显示切到实际完整最佳候选，旧未审试探不能冒充已应用结果。已达标的原指标必须保持；原本未达标的条件不允许继续恶化，其名义状态仍如实显示失败。原指标和曲线变化分别列证据，不加入未启用mean目标。

厚度不足严格改善且守住光学保护即可“应用当前改进”，不必等全部薄层达到下限或局部收敛；应用确认冻结当时候选并停止本轮。例：下限8nm，7→7.5→7.9nm均可能是有效阶段改进，仍会显示剩余不足。外层不设固定总秒数/候选数上限，局部求解片有界；达到修复目的、自然停滞或资源停止会说明原因，本轮未找到不代表无解。用户“取消优化”后自动应用最后完整核验的改善冠军一次，无改善则保持原设计；自然结束保留手动回看/应用。来源编辑、材料/目标/比较设置变化、关闭或项目切换仍阻止旧任务覆盖。应用刷新完整拓扑、约束与光谱，并可一次撤销。JSON报告保留，v1/v2历史仍按原协议显示。
