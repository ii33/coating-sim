# 混合合成与独立敏感性集成验收

日期：2026-10-22。本文记录功能边界和实际测试，不提供连续全局证明、制造通过或任意目标可解承诺。接口与算法见[合成契约](film-auto-synthesis-contract.md)、[敏感性契约](film-sensitivity-contract.md)、[使用入口](film-synthesis-gui-guide.md)及离线[算法文档](algorithms.html#film-hybrid-synthesis-20261022)。

## 功能与正式路径

- 默认混合调度串联多族工程先验、可重用完整设计档案、局部/全局探索、原宿主锚点解析批针、真实联合厚度优化、删层/同光学引用合并和全原网格SLSQP。严格冠军、实际探索终态与已独审冠军分开；名义通过不由求解器辅助变量t或探索SSE替代。
- 默认保留1nm原始波长网格及全部角度/偏振条件。无70/104隐性层数限制。自动内存护栏按冻结时可用内存一半解析，正整数手动字节及null关闭仍支持；解析值和资源跳过随结果保留，不将资源拒绝称物理不可行。
- 敏感性使用独立请求/结果/序列化、命令行、MCP准备与确认提交、本地CPU队列、完整检查点、取消、报告和显式应用路径。实际优化用户所选误差目标；线性Jacobian估计与完整有限扰动分开。普通名义目标不加默认余量。
- GUI应用走原版本/未提交编辑epoch/材料绑定检查与撤销路径。历史队列结果只读。硬件渲染配置未因测试降级。

## 正式冷启动测试，不混入已知答案

类别库16项正式CLI测试使用其原有显式制造约束及每项10秒/100评价/1轮限额：全部完成独立审计，5项通过（V形AR、窄HR、窄分光、近红外AR、红外HR），11项cycle_limit且未通过，0软件失败。最终重跑共1044评价、153次真实针扫描、12次全原约束SLSQP调用。该小预算回归只验证实际路线与如实验收，不把未通过类别隐藏掉。

原四窗口正式CLI完全冷启动不使用研究89层处方，保持184600个原始条件、四窗1nm、39–51°各0.5°、实际冻结零k输入、HR≥99%及IR<3%。唯一加长实验把300秒改为1200秒，其他1000评价/8轮限额、材料、网格、等窗权重和冻结自动内存值不变。结果：

- not_found/time_limit；104次完整物理评价，0失败；实际约1205秒含不可分割调用和清理。
- 真实批针/联合SSE/精确清零合并后到108层。全部184600条原约束SLSQP产生完整有界调用记录：108变量、11物理候选、10迭代，stage_budget停止而非收敛。
- 原网格实际最坏违规0.016312095648；求解器t=0.0156403036872较小，但未被误用作验收。无资源跳过。
- 内置加密审计因总时间耗尽未完成，validation_complete=False、targets_met=False，不能称完整合格链已完成。
- 对相同返回处方的独立固定候选复算：原184600与加密723436条件都失败。加密最坏违规0.0171295562392，585.5nm/51°的R约97.287%，低于99%；两IR窗最坏R约4.578%与4.571%，高于3%。另外的归一化场传输复核与生产R相差约4×10⁻¹⁴。

研究89层已知处方的名义验证与此软件冷启动测试是不同证据。本版本实现真实搜索路线，但上述复杂四窗的冷启动求解质量仍未达到目标；不能据此声称全球不可行。

敏感性新增19个对抗测试，连同原有作业/Qt控制器共79项通过。六类真实缺陷先被复现再修正：非法空/布尔请求身份、不同冻结任务结果错绑、失败检查点误标取消、报告部分写故障、首次准备失败不可见、失败/取消调度状态被内层候选覆盖而误可应用。原断言未放宽；历史正例补充真实不可变JobSpec及digest，错绑/数值篡改负例仍拒绝。

真实注册MCP工具经历只读准备、计算确认、去重提交，实际执行scheduler.worker.run并写规范/检查点/终态文件；仅传输使用内存替身，没有用绕过受限socket的替代IPC。兼容HR与多谱精修另补4个全固定上下界的真实SciPy红测，修复缺失nit诊断导致的崩溃，75项相关测试通过。
