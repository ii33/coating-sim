## 结果与范围

移除光谱仿真的 10,001 点上限及 `samples × (front_layers + back_layers + 3) <= 1,000,000` 配额；UI、`simulation_settings`、冻结快照与服务入口不换用巨大固定上限。默认仍是 400–700 nm、301 点、1 nm。Python 整数文本控件避免 Qt 的有符号32位上限；QML 对无法精确表示的整数明确报错。计算与导出没有截点或降采样。

保留整数/有限正数、运行时可寻址与浮点可分辨精度校验、材料/光源域、透明外部端口及被动膜层条件、4096层设计限制和所有优化预算。光谱继续在本地 UI 后台线程或 API/MCP 直接执行，没有新增队列任务；既有优化队列不改动。`film_optics.py` 数值内核与任务前快照 SHA-256 相同。

接口约定先写入 [Quick 光谱契约](film-simulation-quick.md)，实现和算法同步见 [离线算法14m](algorithms.html#film-spectrum-unlimited-points)。服务增加可选 `cancel_event`，取消以 `InterruptedError` 结束且不发布部分结果。每次捕获一份材料目录；连续非重叠块最多4096点，按设计介质数和32MiB工作块估算缩小。全局基片模式、源谱归一化、积分与相位接缝判定保持一致；QW参考查询只归档一次，后续块不混入光谱查询计数。

## 真实限制与剩余问题

- 全量网格、结果与导出仍需O(N)内存。分块目标只控制工作块估算，不保证整体峰值，不按即时空闲RAM拒绝、不自动降采样；内存不足仍可能失败。没有进行会拖死机器的无界分配测试。
- 取消是合作式检查，当前NumPy运算不能抢占；API/MCP仍是直接同步调用，没有新增取消句柄。核心的可选事件与UI关闭/参数修改路径已验证。
- QML超过JavaScript精确整数范围明确拒绝；浮点波长无法严格递增、数组长度不能表示时也拒绝。这些是真实表示能力边界，不是固定业务配额。资源提示估算已提交参数，草稿编辑期间不实时重算。
- Widgets全套未全绿：缺少固定ID的真实ZnS材料夹具，及主题测试期待`#ff000000`而当前共享主题为`#ff17212b`；任务前UI同样失败。未为点数任务补造生产材料、改共享主题或扩大旧窗口重构。
- Luna文档阶段两次流连接中断，Sol接手完成；环境工具随后可执行。没有遗留测试等待、未解决权限拒绝或用户进程操作。
