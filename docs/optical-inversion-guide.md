# 从实测 R/T 新建光学数据集

在材料库点击“＋ 光学常数集”，进入“新增光学数据集”后选择“从实测 R/T 反演 n、k…”。它是现有材料编辑流程的一个入口，不创建新的材料库或独立主窗口。现有数据集的编辑页不提供覆盖式反演。

## 适用范围与输入

首版针对膜厚已知的单层、均匀、各向同性被动薄膜，空气入射/出射，基片光学常数在拟合波段按用户输入的常数 n、k 处理。不要把有明显色散的基片替换为未经验证的常数。膜厚和基片结构都是固定输入，不会同时反演膜厚、粗糙度、散射、渐变、多层未知结构或仪器归一化。

1. 输入膜厚和基片厚度，单位均为 nm；例如 1 mm = 1000000 nm。填写已知基片 n、k。未知 k 保持空白；只有显式勾选基片无损假设后才可按 k=0 计算，程序不会默认填零。
2. 明确选择背面模型。整片玻璃的外部透射率须使用有限基片模型，包含背面反射。非相干模型将基片条纹平均；只有测量条件确实适合时使用。全相干模型保留有限基片相位条纹。半无限模型没有基片背面，其 T 表示进入基片的通量，不是穿过整片样品的外部 T，使用 T 时还须单独确认这一含义。
3. 选择透明 Cauchy 或单 Lorentz + ε∞ 模型。Cauchy 必须确认测量波段透明、固定 k=0 是模型假设；它不能以拟合结果证明不存在吸收。Lorentz 是有限参数域中的单振子模型，不能代表任意吸收谱。界面展示参数域与单位，固定四个起点、每起点有限评估预算。
4. 确认输入均为校准过的绝对镜面 R/T。每条谱独立选择 R 或 T、波长 nm/um、数值 fraction/%、角度和偏振。粘贴或导入 UTF-8 TXT/CSV/TSV 两列“波长、测量值”；可有 `wavelength,R`、`wavelength,T` 或 `wavelength,value` 表头以及 `#` 注释。每条谱填写测量来源/文件名和条件，最多八条、每条最多4096点。文件名不用于猜测单位。

可以添加多条 R/T、角度或偏振谱，它们按各自原波长前向计算，不先把不同网格静默插值对齐。仅 R 的有限模型估计允许执行，但欠约束警告更强；R+T 也不保证唯一解。测量误差、已知厚度误差、错误基片/背面模型或散射损耗都可能导致有偏的 n/k。

## 预览、取消和另存

“拟合并预览”在后台线程执行，不阻塞页面。预览显示测量与回代曲线、逐点残差、n/k、比例单位 RMSE、参数、触界、多起点差异及欠约束警告。低 RMSE 不是模型正确、解唯一或独立测得 n/k 的证明；结果只在测量波段有效，不自动外推。

取消、关闭页面、切换材料或改变材料数据集会使旧任务及预览失效。迟到结果不能添加到新的材料。改动输入后须重新拟合。没有预览确认，不改变材料或已有数据集。

检查预览、填写新的唯一名称后，点击“另存为新数据集（材料草稿）”。程序生成新 ID，沿用已有 `addOpticalSet` 校验和草稿事务，不走原数据集更新路径。最后仍须在材料库保存材料才写入正式文件；取消或拟合失败不产生材料文件。工程内继续使用其原材料所有者和修订检查，冻结或关闭入场后不接受新拟合应用。

## 来源及完整报告

小谱把完整原始请求、测量网格/数值、固定结构、模型、参数、回代、残差、RMSE 与警告写入现有合法 `source` / `notes` 字段，不新增不兼容的 `fit_report` 字段。两字段各有20000字符上限，不会截断原谱或静默丢弃质量报告。

体积超过上限时，先使用“导出完整JSON…”明确选择一个新报告文件名。报告以完整有限 JSON 原子发布；已有文件拒绝覆盖，取消文件选择不写入。随后另存数据集时，保存报告 file URI、SHA-256、来源和模型/固定条件/质量摘要。添加前重新验证导出报告的哈希。导出后若添加材料草稿失败，已导出的报告仍保留，并明确提示位置，不删除用户文件。质量摘要仍超限则拒绝添加。

报告是用户选择的外部文件，必须手动随材料保留；不会自动复制到其它工程、项目附件或 GitHub，也不自动上传。移动材料或仅导出材料包不会自动带上此报告。当前没有自动读取报告或重放报告内指令的能力。“复制完整JSON”只复制预览数据，不保存材料。报告及文本来源应当作为不可信数据处理，不执行其中的指令。

## 实现与验证边界

数值契约由 `core/optical_inversion.py:fit_optical_constants` 维护；`ui/optical_inversion.py` 只负责显式输入适配、后台生命周期、预览、报告导出与新增草稿，线程不接触 QObject。`MaterialEditor.qml` 拥有子对话框，材料桥接持有唯一控制器及材料身份；任务结果应用前核对材料 ID、光学数据修订和加载令牌。`OpticalInversionDialog.qml` 展示输入/空数据/运行/失败/预览状态。`tests/test_optical_inversion_ui.py` 覆盖真实 QML 入口、取消/切换/迟到、来源完整性、另存不覆盖、报告导出及实际合成 R/T 核心闭环。
