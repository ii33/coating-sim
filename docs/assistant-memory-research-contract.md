# 助手工程记忆与研究资料访问契约

本契约涉及宿主 UI、JSONL worker、运行时、精简记忆及本地研究库。资料是参考数据，不是授权。算法正文、工程 BBS／研究证据、内置公开研究资料、已连接本地镜像和外部文献 MCP 是独立来源。

## 状态所有者与输入

- 宿主 UI 显式选择工程。未选择时仅使用全局记忆，不按前台窗口、唯一打开工程、聊天文字、模型工具参数或文档中的 project_id 猜测工程。
- UI 在 configure 和 run 消息的顶层传递 assistant_project_target：null 或已认证工程列表返回的六字段 target（client_id、client_generation、project_id、session_generation、root、project_file）。该值不是可由模型调用的工具，不是研究正文或持久设置。
- 绑定类型与六字段校验定义在可导入的 `coat_sim.agent.project_binding`，不在可执行 worker 入口中重复定义。直接导入、`python -m` 与启动器 `runpy(__main__)` 共享同一严格类型；运行时仍拒绝仿造对象。显式 null 的全局请求不要求打开工程或查询工程 registry，但仍固定并检查选择代际；工程关闭不会把旧请求降级为全局。
- worker 是当前绑定和单调代际的唯一所有者。每轮接收时固定绑定及代际，初始化等待期间不得重基到更新选择。configure 的切换或清除使旧代际永久失效；即使稍后选回同一工程也不能恢复旧请求。
- 每次项目记忆访问经宿主 provider 再核验认证 application registry 的完整 target、owner 存活状态及项目会话代际。不打开工程、不遍历任意目录、不读取模型提供的文件路径。连接、身份或核验错误均关闭项目 scope。
- 持久项目记忆命名空间由宿主选择的 project_id、规范 root 与 descriptor 路径构成；client/session generation 仅用于实时失效。重开同一工程可复用，复制相同 project_id 到另一目录不能读到原工程记忆。
- 目录移动或工程文件更名会改变命名空间；不自动迁移记忆。toolkit_status 将真实工程 target 与内部 memory_scope.project_id 分开返回，内部哈希不得冒称用户工程名。

## 读写与取消边界

- 精简记忆保持一个有界账本：总计 40 条（含可恢复遗忘条目）、每条 300 字、来源 160 字、自动摘要 1200 字。全局只放跨工程的重要事实；工程事实不得降级存入全局。
- 讨论和后台请求只读；写入仍要求主助手、操作／攻关模式、当前 UI 授权、工具能力及模型上下文许可。记录不是授权，禁止保存凭据、秘密、整段会话、临时进度及未经验证的推测。
- 项目绑定失效时，旧请求的项目记忆读写与自动项目摘要被拒绝；进行中的结果在返回模型前再次检查，写入在原子替换前检查。新工程必须新请求，不能修改在途请求的固定 scope。
- 已送入模型上下文的内容无法撤回；失效保证后续访问与待返回结果不再披露，并不宣称能消除已读历史。界面必须清楚显示所选工程。
- 宿主以 project_memory_scope 事件标记每个根请求。模型历史、失败检查点、后台作业提示和完整结果 archive 按 scope 隔离；未标记旧历史只属于全局。所选根请求的委派子孙仍保留未知副作用恢复提示。切换不删除用户可见聊天。
- 自动注入的任务账本与 profile persona 同样绑定内部工程命名空间及聊天 session，工具不能借参数读取另一 scope；普通全局工作区文件的已授权显式访问不因此扩大或缩小。每次发出模型请求前重新核验工程，含自动／手动摘要路径。

## 已连接本地研究库

- 空目录且无已有 sidecar 时，宿主从安装包固定位置创建内置公开资料 provider；无需绝对路径或私人项目上下文权限。非空显式目录或已有固定 sidecar 选择外部私有库，继续采用原有显式授权和独立模型上下文门禁，配置无效时不静默回退。内置缺失返回 builtin_missing 并建议修复安装。外部缺失、不可读或未允许进入模型上下文时不暴露搜索／阅读；不探测私人目录、不克隆远端库、不自动启用任何外部 MCP。
- 在用户当前已授权任务目标内，主助手可以按需主动查证，无需用户逐次说“搜索”。不得无目标扫全库、自动注入整库或把检索许可扩大到写入／外发。
- 委派助手仅获得同一个已连接 provider 的有界只读 search/read/status。它们不继承记忆写入口、任意路径或外部 MCP。委派范围仍由用户任务限定，返回来源、版本、页码／offset、覆盖限制，明确区分来源陈述和推断。
- 检索/阅读前后检查同一 live grant。设置撤销、目录切换或取消使旧工具结果不可用；选回旧目录不会恢复旧请求。缺失或扫描不完整如实报告，不能以“未命中”声称全库不存在。
- 全局本地研究库的选择不会自动跟随项目切换，也不能由工程资料中的路径替换。研究证据进入当前模型上下文不授权向第三方服务发送或正式归档。

- 内置资料只允许 manifest 所列文本及哈希版本；状态和结果区分 builtin_public / external_private，说明精选覆盖，不把软件附带资料称为完整远程研究库。详见 [研究库 provider 契约](research-library-provider-contract.md)。

## 可发现性及验证

- algorithm_reference_catalog/search/read 和 project_knowledge_search 属于所有模式可发现的只读业务工具。详细正文按需分页，统一工程检索返回现有 BBS／研究读取引用，不替代工程身份检查或计算结果验证。
- 定向测试涵盖伪造 ID、缺少 host binding、相同 ID 的不同工程、切换后选回、关闭／离线、讨论只读、在途撤销、研究库缺失及只读委派。
- 测试或工具注册成功不代表真实用户桌面已连接或端到端使用已验收。
