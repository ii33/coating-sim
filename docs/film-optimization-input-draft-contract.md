# 膜系优化目标输入草稿与提交契约

日期：2026-10-20。重申用户既定全局规则：输入框在输入完成后才校验，只提示警告，不以重置、夹取或默认值处理错误。本阶段先修目标上下限，并定向核对同页角度/波长范围及公共输入组件；不扩展无关页面。

## 所有者与输入状态

输入编辑中的原始字符串是草稿，输入过程不进行业务校验、不回填/夹取/纠正、不解析百分比去覆盖文本。原始字符串在Enter或编辑完成失焦后仍保留，包括空文本、科学计数中间态、倒置上下限及其他非法值。完成编辑后才校验并显示具体警告。仅获得/失去焦点不修改业务数值或制造dirty。

Controller拥有按目标稳定身份关联的草稿及提交错误；QML字段显示当前目标草稿，已有规范化数值是最近一次有效参数。切换目标/字段不得丢失另一目标草稿，非法一栏不得禁止编辑另一栏。上下限必须作为同一目标的一组参数校验，不把一栏夹到另一栏；清空后可继续输入，全选替换与键盘/IME编辑保持原生行为。

## 提交边界与单位

Enter、editingFinished/失焦是完成编辑边界，重复通知须幂等。警告不替换输入。计算开始、快捷启动、冻结请求及保存配置必须先检查最新草稿；非法时明确给出具体字段/范围错误并拒绝本次动作，不得偷偷运行旧值或默认值。纠正任一相关字段后可恢复有效状态，不产生pending-key死锁。正在运行的冻结任务不读取后来草稿。

界面目标上下限单位为百分比，0和100均有效；构造物理目标时只除100一次。相等上下限按现有精确目标语义处理，包括0=0；缺失/None与有效0必须分开判断。浮点小数不通过显示格式化字符串回写，保存重开保持已验证真实数值。其他物理采样/权重/角度适用域仍由现有模型规定，本次不改变评分公式或采样算法。

## 失败、公共组件与验收

公共ThemeField的数字展示同步不能覆盖尚未成功提交的业务草稿；页面必须明确由草稿持有输入。原生validator若拦截业务范围内的中间文本/Enter，则不能用于这些遵循完成后告警的业务字段；输入法提示只帮助键盘，不作为业务校验。旧共享格式化约定只适用于可安全展示的已提交数值，不能覆盖这条草稿保留规则。

定向真实Qt验收：新目标、先上限后下限/反向、全选替换、清空中间态、小数、有效0、相等界限、Enter/失焦、非法警告后原文保留、切目标、有效配置保存重开、最终普通优化及从零合成冻结请求的数值正确并可启动。对相关角度/范围检查不做无关全量回归。
