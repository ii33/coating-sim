# 工程 BBS 附件与预览契约

日期：2026-10-18。接口真值为 `core/project_bbs_attachments.py`、`ui/project_bbs_attachments.py` 和契约测试。

附件复用工程 `binary_asset`，角色 `bbs_attachment`、私有载荷后缀 `.bbsasset`，每个文件最多 32 MiB。导入仅接受可信适配层已授权的普通本地文件；GUI 文件选择器的 URL 仅允许本地 file URL，不接受网络地址、符号链接、重解析点或特殊文件。模型参数不能通过预览请求传入路径。原文件按原始字节复制到工程，保存大小和 SHA-256，完整工程包携带附件；发布失败不产生有效附件记录。

BBS 修订保存附件描述 `{asset_id,name,mime,size,sha256}`。文件名只作显示和导出建议，不参与路径解析。每次修订最多 8 个附件。历史版本引用的附件继续保留，预览只解析当前绑定工程的登记 ID，验证角色、哈希和大小，再读取已验证字节。外部修改导致预览/导出失败；不会回退搜索外部文件。核心读写在既有工程操作锁和原 binding/generation 内执行；GUI 异步完成再次由协调器复核绑定。

预览白名单为 PNG/JPEG/GIF/WebP 静态首帧、UTF-8 纯文本/代码/CSV、PDF。扩展名与已知签名不匹配则拒绝导入/预览。HTML、SVG、未知格式只作为二进制保留及导出，不解析脚本、宏、HTML、外链或嵌入对象；CSV 只显示原始文本，不执行公式。不解压任何附件。文本最多显示 64 KiB；图像预先检查尺寸（最多 16 百万像素、单边 8192），缩放至最多 1200×1200 后通过仅含内存图像的私有 image provider 显示。QML 只接受该 provider 的随机能力 URL，不接受 HTTP、file 或 data URL。预览缓存至多保留 8 张图并在原会话关闭时撤销。

PDF 通过既有隔离 pypdf 解析器提供逐页文字预览，不保留版式、不执行 OCR。解析进程限制为 768 MiB 内存、12 秒 CPU、15 秒墙钟时间、16 MiB 输入、200 页及 4 MiB 输出；最终单页显示最多 64 KiB。超过解析限制、加密或损坏的 PDF 明确提示导出。当前未安装 QtPdf，不提供 PDF 图形页面渲染，不启动网页引擎或自动安装组件。所有格式都可通过明确的保存对话框导出；本版本不自动启动外部应用。导出不覆盖已有文件，不改变附件原始内容，也不在后台下载资源。

`ProjectBbsAttachmentPreview.qml` 是内嵌组件，父页面拥有请求/加载/失败状态和选择。它接收附件与有界预览结果，只发出预览、分页、导出信号；不独立读盘、不持有工程路径。主题沿用共享逻辑尺寸与颜色，文本可选且滚动，关闭/切换后父页面清除预览；不新增独立窗口或几何例外。
