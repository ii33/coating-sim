# 自动合成的物理表面选择：界面与网关契约

优化窗口的合成设置由 `FilmOptimizationQuickController` 独占：`selected_surfaces` 是正面、背面的有序数组，缺省为 `["front"]`。双面基片可分别勾选正面和背面；名称始终指物理面，不随入射面切换。空选择可作为编辑草稿保存，但界面显示错误、禁止开始，适配器也拒绝提交。单面基片的背面控件禁用；切换到单面或恢复含背面的配置时，取消活动背面选择并提示，原背面膜层不删除。若因此为空，须用户明确选择正面。旧配置缺少此字段时恢复正面。

构造一次请求：仅清空所选物理面，未选层保留为固定环境；入射/出射介质、基片几何与 `first_surface` 不翻转。显式当前处方种子保留原完整设计；两面同时选择仍是一个完整膜系任务。层数和总厚度预算合计用于所选面。结果仍经现有冻结源身份、版本与应用/撤销守卫处理，不自动保存。继续结构搜索的设置签名包含所选表面，改变后显示需重新开始；旧签名缺省正面。后台提交、取消与结果所有权仍属于既有队列协调器。

MCP 的 plan、submit 使用相同的 schema 6 请求字段；模板由产品请求默认值产生，省略为正面。该字段为非空、不重复的 `front`/`back` 数组，背面仅双面基片可用。网关不替代核心验证、数值求解或审计；plan 只冻结请求，不能提交或应用设计。

表达式文本及符号是源文档的编辑元数据，请求构造不清空也不预先改变其同步标志。当前表达式 schema 没有记录最近展开到哪一面；应用时沿用 `FilmDesignSession` 既有的完整双面膜堆签名守卫。因而即使仅背面改变而表达式实际上描述正面，也可能标记为不同步；不会推测表达式所属面或重新展开而覆盖候选。
