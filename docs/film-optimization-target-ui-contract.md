# 膜系优化目标、变量与配置界面契约（2026-10-19）

当前更新（2026-10-24）：波段 mean/pointwise 两组、版本、raw coverage 与严格判定以[双约束契约](film-band-criteria-contract.md)为准。旧 flat 目标与旧协议不迁移。

## 厚度变量默认与有限域边界

新建目标的波长范围默认 400–700 nm，以 1 nm 请求步长含端点生成 301 点；角度范围默认 0°–0°、请求步长 1°，实际为单角度 1 点。新增目标使用同样默认，复制目标保留原目标的采样设置。显式保存的点数基准或步长基准保持不变；旧配置只保存点数而没有基准时按点数恢复。队列候选只含冻结后的点数，检查时按点数重建实际步长。该“采样步长”不改变求解器的厚度试探步幅或达标容限。

新建优化配置由 `FilmOptimizationQuickController` 拥有编辑状态：所有膜层默认选中，物理下界为 0 nm，上界为 `None`（未设置）。零厚膜层仍可选。默认 `baseline` 算法在半无界物理厚度域直接运行；其搜索步长不是人工上界。其他现有有限域求解器须由用户填写有限上界且严格大于下界，缺少上界时状态文字说明原因并拒绝启动与提交。用户已保存的层选择和边界按稳定 layer ID 恢复，刷新设计不会覆盖匹配层的约束。优化异步结果和取消仍沿用本文件下述冻结 revision 与 operation ID 规则。

厚度下界和上界的用户编辑提交保留三位小数；显示精度不改变既有配置或科学常数。设计层编辑、保存与零厚膜层的物理校验见 [算法文档 14i-0](algorithms.html#film-thickness-edit-domain-20261019)。

## 状态与持久化

`FilmOptimizationQuickController` 拥有本窗口的可编辑目标、稳定层 ID 对应的变量选择/边界、算法和结构搜索参数。`FilmDesignEditSession` 是 `.cfilm` 文档和 `workflow_settings.optimization` 的唯一持久化所有者。控制器通过 `exportOptimizationConfiguration() -> QVariantMap` / `loadOptimizationConfiguration(QVariantMap) -> bool` 转移完整配置；用户成功编辑后写入 session，加载期间禁止回写。新建/打开文档恢复新配置，旧文档缺失配置时恢复默认；普通物理设计刷新保留用户手选变量。无效配置整体拒绝并显示原因，不静默修改层 ID 或厚度边界。

每个目标有独立 `id`。复制目标深复制角度、偏振、R/T、权重、范围和值以及采样设置，仅生成新 ID 和副本名称。编辑副本不影响原目标。目标 ID 属于配置身份，不改变冻结优化数值请求的旧 schema。

## 波长采样

波段 `[a,b]` 的单位为真空 nm，两个端点均包含，均匀网格。以点数输入时，非零波段需要整数 `N >= 2`，实际步长 `h = (b-a)/(N-1)`。以正步长请求 `s` 输入时，`N = ceil((b-a)/s)+1`（至少 2），实际 `h = (b-a)/(N-1)`；不整除时均匀缩短步长，绝不丢弃上端点。控制器显示请求步长与实际步长，保留最后编辑的采样基准，波段编辑按该基准重新换算。

`a=b>0` 是单波长：规范化 `N=1`、实际步长为 0。非零波段显式输入单点、非整数点数、非正步长、非有限值、非正波长或倒序波段都拒绝，保留此前合法值并阻止启动，直到对应输入修正。单波长扩展为波段时，点数基准自动恢复至少 2 点；步长基准保留原正请求步长。`10001` 仍可作为服务调用的分块大小，不是采样上限。桌面 QML 数字输入通过文本按整数精确解析；会进入 QML 的整数字段最多接受 `2^53−1`，超过时明确拒绝，避免 JavaScript Number 静默舍入。该值是当前桌面界面的整数表示边界，不是计算量限制；纯 core/队列请求 schema 仍接受正整数且不增加人工条件总量配额。浮点网格无法表示为严格递增点时明确报错。

## 入射角采样与旧配置

新目标以 `angle_sampling_mode="range"`、`angle_min_deg`、`angle_max_deg`、`angle_step_deg` 保存角度范围。角度单位为度，要求 `0 <= low <= high < 90` 且请求步长为正。`low=high` 只产生一个角度；否则 `N=ceil((high-low)/requestedStep)+1`，以均匀含端点网格生成 `N` 个角度，并显示实际步长 `(high-low)/(N-1)`。所有生成角度都进入冻结请求的 `angles_deg`，串行、prepared/cache、batch forward 与结构优化评分逐角计算。

旧配置中仅有 `angles_text` 的目标恢复为 `angle_sampling_mode="points"`，逗号/分号/空白分隔的显式角度点保持原样，包括不等距列表。不能把旧点列表猜成均匀范围；点模式可继续编辑，新的范围模式由用户显式切换。旧文件配置 schema 1 与队列优化请求的 `angles_deg` 元组字段都保持兼容。

范围模式的编辑、切换有效性检查和绘图角度选择器只读取算术样本数，不因一个很小的步长同步展开完整列表。绘图选项超过 101 个时，只提供最多 101 个真实网格索引的代表点，并明确显示代表选项数和完整运行样本数；这不截断优化输入。范围切换为旧点列需要把网格序列化到可编辑文本，超过 4096 个点时拒绝该 UI 转换并保留范围模式，提示用户缩小范围或增大步长；此表示限制不限制范围模式计算、任务条件数或队列点数。

运行请求的角度元组超过 100000 项时，桌面端将预提交展开移到可取消的 run coordinator worker；阈值只选择执行线程，不拒绝、截断或降采样请求。准备任务捕获设计 revision 与未提交编辑 epoch，准备 worker 完成完整角度展开、材料冻结和队列 spec 序列化后，只有来源仍匹配且 operation ID 仍有效才接纳该准备结果并进入后台队列提交；GUI 回调只转交已准备的 request/spec 引用。准备阶段取消或来源失效时不接纳结果；提交中的取消若与接纳发生竞态，则按同一任务 ID 请求队列取消，失败时明确提供重试。关闭窗口停止观察；已经接纳的作业由服务管理，不因窗口关闭自动取消。核心和队列仍只接收既有 `angles_deg` 元组。

采样间隔控制离散覆盖密度，不能称为光学精度保证或连续波段/角度达标保证。留出验证增加波长密度，仍不是数学收敛认证。

## 变量与异步边界

去除固定层序、队列重放、有限针插与经典结构搜索的人工 8 变量限制。新来源默认选择全部厚度可用膜层；后续刷新按稳定 ID 保留手工选择和边界，不能仅优化前 8 层。结构总层数按照用户显式正整数预算验证，去除 128 层业务硬上限，遵守现有文档解析 4096 层资源防护；单轮经典结构搜索仍只允许一次新增针层，这是现有算法范围，非膜堆容量上限。

层数、变量数、波长/角度和群体预算共同影响内存与耗时。迭代数、评估数、起点/群体、验证倍率、结构位置/厚度采样和候选预算都由用户设置正整数，不设计算量上限或 0/None 无限预算哨兵；桌面 UI 受上段所述 `2^53−1` 精确整数表示边界约束，超过时拒绝输入，纯 core/队列接口不引入该 UI 表示限制。求解仍受用户明确设置的预算控制。保留实际内存/后端失败、取消与有效性校验；单次完整候选边界取消，最佳已评估候选保留。启动冻结整个请求，不在此改求解算法。

唯一窗口复用通过 `reuseWindowOpen(document_path='', payload=None) -> bool`，payload 是设计控制器或 `FilmOptimizationSourceSnapshot`。相同来源仅刷新；运行中不同来源拒绝且不改变原任务，未保存候选先确认。确认前的快捷启动只记录意图，不能计算旧来源。

均匀含端点网格沿用 [NumPy linspace 官方定义](https://numpy.org/doc/stable/reference/generated/numpy.linspace.html)。步长转点数的取整、零宽规范化、编辑基准保留与浮点可表示性校验都是本项目约定；未找到外部精度保证依据，不据此声称连续波段/角度达标或收敛认证。算法公式和离线图解由 [算法总文档](algorithms.html) 统一说明。
