# 独立膜系减层 / 减厚优化

日期：2026-10-28。此功能以当前膜系为起点进行有界后优化，独立于普通光谱优化、针插/增长及从零合成。它不承诺全局最小层数或最小厚度。

## 输入、约束和唯一状态所有者

`FilmReductionRequest` 封装现有 `FilmOptimizationRequest`，另有 `layer_count`（减层）、`thickness`（减厚）和 `combined`（先减层再减厚）三种模式。输入冻结当前设计、设计 revision、完整目标、所选厚度变量及边界、材料光学闭包、可选减量预算和独立验证网格倍率。单位为物理 nm；总层数、总厚度和最薄层统计正反两面，不包含块体基片与介质。

新减量请求和结果为严格 v3：`limits` 恰含 `max_iterations` 和 `max_evaluations`，均默认 `null`，表示不限制。普通优化的 200/1000 默认值仍属于普通优化，不作为减量上限。页面“算法”中的减量上限可编辑、可清空；配置单独保存为 `reduction_limits`，旧编辑配置缺该键时恢复为不限，不继承旧 `solver` 限额。迭代上限最小 1，完整网格评估上限最小 2。没有内置减量时长或轮次硬上限。历史 v2 请求/结果仍严格按其原字段及原冻结预算读取、回写，不把旧有限预算静默改成无限；不接受 v1 或额外未知字段。

删层修复不再有不可配置的 8 次迭代和 `max(35,18N+1)` 次评估配额；复用 baseline 数值收敛、目标通过、边界和取消。只在用户明确设置减量上限时，向修复传递剩余额度并为独立网格保留 1 次评估。初始原网格和独立网格恰计 2 次；内层训练和验证的完整网格也计入同一总数，多目标/角度/波长分块不被重复当成新完整网格。此计数不等于物理正向调用数。取消在每个正向分块边界检查，并保留之前已完成双网格审计的最佳候选，不追加终态重算。

默认搜索结束原因为提案穷尽或减厚步长数值容差，与用户预算耗尽严格区分（结果 `solver_validation.termination_reason`）。同一最佳设计下已修复的删层/合并提案不随减厚步长重复修复；最佳设计一旦变化即清除该缓存。该局部缓存不宣称证明全局不可减。

Controller 唯一拥有页面草稿、活动 operation 身份和候选；编辑 session 唯一拥有实际设计、revision、未提交编辑 epoch 与撤销栈；scheduler 唯一拥有作业身份、取消状态及持久候选。worker 只处理冻结输入，不能修改编辑 session 或保存工程。

默认保守边界：只改变用户在约束页选中的厚度变量。未选层视为固定层，逐行保留其 ID、材料、厚度和顺序。只有所选变量下界为 0 的层才允许删除；下界大于 0 的层必须保留。保留的层仍须满足自身厚度上下界。同材料且同 optical_set_id 的相邻层只有在均可删除且合并后厚度满足保留层边界时才可合并；不跨固定层或正反面界面，不吸收基片，不合并不同 nk 数据组或有必须保留约束的层。删除/合并后的候选复用现有有界光谱优化，在原边界内调整选中的存活层以恢复光学可行性；存活层允许增厚。减厚模式保持拓扑。所有模式不选新材料，不改入射/出射介质、基片、传播方向、正反面、角度或偏振。

当前膜层 schema 和编辑页没有独立的 `locked` 属性/锁定标记。这里的“固定层”明确指未加入厚度 `variables` 的层；不宣称识别或覆盖某个外部锁定字段。

## 光学可行性和排名

复用当前冻结膜系光学评估与名义目标归约，包括所有启用的 mean / pointwise、R / T、角度、偏振及原波长网格。权重或求解可接受误差不放宽名义目标。每个被接纳的候选还须完成同一独立加密网格的复核；源设计使用相同的原网格和验证网格建立基线，不能用候选的稀疏搜索分数与源设计的完整结果比较。

有效减量必须同时满足完整目标与独立验证，且按所选模式严格改善。减层模式必须减少层数，允许总厚度增加，达标候选按层数、再总厚度排名；减厚模式在固定拓扑下严格减少总厚度；联合模式要求层数和总厚度相对原设计均不增加、至少一项严格下降，通过此双指标资格后按层数、再总厚度排名。联合模式不把层数减少但总厚度增加的候选标为有效联合减量。光谱误差不与层数或厚度组成任意加权和。原设计已达标时，不允许将未达标减量标为有效。原设计未达标时，明确保留未达标状态；不能悄悄扩大原目标范围或借数值容差称为达标。

有限网格通过只表示所记录网格的名义通过，不是连续光谱或制造鲁棒性证书。有界搜索未改善不证明不可再减。首版采用有限删层/合并、现有有界光谱修复和厚度坐标搜索，具有局部性，修复预算不足或未收敛仍可能错过可行低层数膜系；不承诺全局最优。

## 队列、终态和应用

独立请求/结果 envelope 通过现有 `film_optimization` executor 冻结和排队；重复提交继续受活动 operation 和队列身份约束。结果绑定原请求摘要、源设计版本、完整实际候选及其评分，不把旧设计的分数重标为新设计的分数。历史/检查点恢复遵循冻结材料重放校验；当前取消响应不额外启动长物理复核。

类型化膜系结果的字段由对应 core writer/reader 独占定义。scheduler 在成功收尾、取消边界及历史结果接收时保持该 envelope，不向其加入通用仿真资产字段（包括空的 `result_artifacts`）。此约定不放宽减量 schema：只接受明确实现的 v2/v3 严格格式，未声明字段仍被拒绝。队列完成、UI 接收和显式应用属于不同步骤，候选接收成功不等于已改写设计。

取消在候选/网格分块边界协作处理。半次计算不进入候选；已经完成原网格及验证网格的候选可保留。失败同样保留此前完整候选及真实失败信息。取消、失败及非最终检查点均不自动回写。只有正常完成、完整独立审计通过且严格满足所选减量模式的改善，才复用现有安全应用事务自动回写当前来源一次，并请求刷新光谱；不保存工程，保留一次撤销。来源/未提交编辑/材料发生变化、关闭或取消意图、应用失败均保留候选并显示原因。无改善或未通过验证的结果保持原设计，可比较、预览、另存，不能强行应用。

状态栏与详情使用同一减量终态反馈，明确区分启动/提交失败、计算失败、取消、未找到合格改善、候选保留未应用、已应用及刷新失败，并显示原始终止原因、层数与总物理厚度前后值。worker 收到严格 reduction envelope 的 `state=failed` 时，队列终态同样为 failed，保留原错误及 envelope，不把捕获后的算法失败记作 succeeded。普通光谱优化、合成和敏感度分支不改变。

显式应用前同时校验活动来源项目/session、revision、未提交编辑 epoch、冻结材料闭包和候选拓扑。来源改变时保持用户设计，候选保留并显示失效原因；不将候选重新绑定到另一来源。通过现有原子编辑事务一次写入完整减量层序，产生一次可撤销操作，不保存或覆盖工程文件。撤销还原应用前的完整设计。

提交保障来自现有 `FilmDesignEditSession.apply_optimized_design`：在同一 session 锁内先检查 revision、验证整个候选及准备上下文，失败时不进入提交；随后一次替换完整设计并记录一次 undo。项目 session 再沿用既有 `service._operation()` 边界。这是并发版本与提交前校验保障；本功能测试覆盖正常应用/撤销和来源冲突，没有注入提交后 `_refresh_derived` / 通知期间异常，不把普通 undo 回归称作任意中途异常回滚测试。

## 页面和验证边界

膜系编辑页提供独立入口；优化窗口沿用现有目标、约束、计算设备、队列和主题控件，提供三模式选择及保守删除规则提示。纯减层模式没有选中且下界为 0 的层时提前禁用并说明原因；联合模式仍可尝试减厚，并明确说明没有可删层。界面明确加载、空候选、失败、取消、来源过期和无改善状态。前后对比显示层数、总物理厚度、最薄层、完整原目标/独立验证达标状态及最差归一化误差。

沿用 [共享 Qt Quick 控件](quick-theme-controls.md) 和 [窗口几何策略](window-geometry-policy.md)，不增加独立几何或主题规则。类型及实际函数签名是接口真值；算法说明见 [离线算法图解](algorithms.html#film-reduction-20261025)。测试与未跑项目记录在本次实施报告，不以单个膜系或桩评分推断实际性能。

## 逐轮实时反馈（仅显示，不改变算法）

“算法”页在减层/减厚运行时显示当前阶段、源设计与最佳完整审计候选的层数/总物理厚度、原目标与独立加密网格的现有误差和通过状态、评价/轮次数，以及按源 layer ID 对齐的逐层原始/最佳厚度、变化和背景条。结果来自核心已有完整评分；不增加光学调用、不展示试探中或未完整双网格核验候选，不把百分比估算成收敛进度。无改善、自然停止、取消、失败和反馈 I/O 错误各自显示真实状态，失败反馈不会使算法候选丢失。

跨 worker 反馈使用 job-local `film-reduction-live.json`，由现有 `film_optimization` 执行任务创建。核心只将由不可变替换所有权保证安全的来源/最佳候选引用放入一个 latest-only 槽；独立写线程再构建、严格校验并原子写入最多 512 KiB 的 JSON 快照，快速试探可合并为最新快照。不会在评估线程计算显示哈希、深复制层堆、序列化或同步 fsync。最终终态快照强制刷新并等待成功写入；超时、快照生成或写入失败以进度错误明确呈现，不能伪报成功。反馈故障不改物理搜索结果。

本地和远程 `reduction_live(job_id, input_digest, after_sequence=-1)` 仅只读指定作业、冻结输入摘要和严格递增序号的侧车数据；它不启动 worker、不重放或执行光学计算。读取器在 JSON 解析前限制到 512 KiB，校验 job 目录/文件所有权、符号链接、请求类型及完整帧字段。远程 RPC 拒绝缺少/多余字段、摘要不匹配、布尔/负游标（除首读 `-1`），并对非减量作业拒绝返回。Qt 只接收当前 operation/job 的新快照，校验失败或读写错误进入可见诊断；隐藏算法页不触发逐帧动画或额外仿真，取消和来源失效仍沿用原 session/worker 保护。
