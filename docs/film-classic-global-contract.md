# 经典结构＋全局搜索核心契约

日期：2026-10-19。第三条路线只增加固定拓扑厚度差分进化（DE），不改变前两条路线，不含局部精修或交替优化。实现和类型签名是接口真值；算法见 `algorithms.html#film-classic-global-20261019`。

`FilmClassicGlobalRequest` 包含第二阶段 `FilmClassicLocalRequest` 作为枚举输入、显式 `FilmGlobalThicknessBounds(lower_nm, upper_nm, source)`、显式随机 `seed`。枚举输入的 `max_local_iterations` 必须为 None，防止被忽略。共享目标、真实色散 n/k、环境、材料快照、制造约束、整个运行的 max_evaluations 和独立密网格验收保持原语义。波长 nm、厚度 nm、角度度、R/T 0–1。有限搜索区间必须由调用者提供且 source 非空，禁止程序猜测通用上限；实际区间与显式制造单层上限相交，并在候选中返回。

一个候选内材料、层序、层槽数及 ID 固定，只搜索每槽物理厚度。结构变化来自已有五类模板、角色材料、设计波长与周期对数的完整显式枚举。零厚度槽允许但保留槽位，不插层、不换材、不删槽。制造最小非零厚度是 `{0}∪[m,∞)`，未显式设置则没有默认值。超制造总厚度、禁用薄层区间的点在物理解算前拒绝。经典起点越界则报告不适用，不静默截断起点。

核心同步调用独占请求的深复制快照、当前最优存档和结果，调用者拥有取消 Event；不修改 session、材料库、用户设计或输入对象。每个候选返回经典基线、最佳训练候选、独立密网格结果、逐目标状态、有效区间及来源、确定性派生随机种子、已完整完成代数、提案/约束拒绝/数值失败次数和停止原因。多候选的状态、排序和覆盖率沿用第二阶段定义。训练和独立网格都通过所有未加权最大归一化违约条件才能报告达标；权重只参与搜索/排序，不放宽验收。

DE 复用现有后端所用 SciPy 的 best1bin、F∈[0.5,1)、CR=0.7、立即更新、单 worker；显式种群12个个体（不是每变量倍数），首个成员为经典起点，其余均匀取有限区间。种群最少5，不静默增大；可显式配置。无自动 polish。为避免 public API 默认1000代成为隐式上限，封装 SciPy DifferentialEvolutionSolver 的逐代迭代接口；本机 SciPy 1.18.1 验证，私有接口兼容性是已知风险。绝不宣称保证找到全局最优。

max_generations 默认 None；max_evaluations 默认沿用共享 None。无默认总代数/评估次数硬上限。每候选默认20个无实质最佳分数改善的完整代触发停滞，relative_improvement_tolerance 默认共享1e-9；这是本项目约定的停滞判据，并非收敛证明。另使用 SciPy 能量离散度收敛判据，默认相对阈值1e-6、绝对0，均可显式配置。起点已达标或所有边界固定则直接独立验证，不消耗虚假的搜索代数。所有物理评估计入共享预算，当前候选保留一次最终验证，剩余不足2次不启动新候选；已计算经典起点在种群初始化重复出现时复用其分数，提案次数与物理评估次数分开。

进度含阶段、候选、计划/已尝试数、物理评估、完整代数、提案次数和最佳误差。每次提案、每代和物理解算分块检查取消；发布进度回调后再检查，防止最后一个提案/验证回调的取消被吞掉。validation_complete 是提交候选之前边界；candidate_complete 是已提交后的通知，取消只停止后续候选，已验收候选继续保留。取消、预算用尽、停滞、代数上限、模板不适用和数值失败有不同原因；尚未找到不能说不可行。密网格只验证最佳训练候选，不回馈优化，不保证连续谱任意点合格。
