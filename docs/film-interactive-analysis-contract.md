# 膜系交互式全层分析契约

## 唯一入口与状态所有者

“减层 / 减厚优化”仅由 FilmOptimization 窗口的“优化方式”选择器提供；FilmDesign 不再提供重复的减量按钮。逐层交互分析和批量修改位于 FilmDesignQuick 的 F4 设计侧栏“交互分析”页，用户无需打开优化窗口；临时光谱也可同步显示于独立光谱仿真窗口。此功能不创建优化作业。

`FilmInteractiveAnalysisController` 是独立临时分析控制器，由 `FilmDesignQuickController` 持有，并捕获 `FilmDesignEditSession` 的当前设计、设计修订号、编辑 epoch、仿真工作流设置和材料服务。它仅持有临时草稿/预览，不是设计状态所有者。`FilmDesignEditSession` 仍是膜系物理设计、脏状态、撤销事务、持久化与工作流设置的唯一所有者；“应用到设计”须由设计源控制器依据修订号和编辑 epoch 原子提交。`interactive_group_id` 是每层可选的正安全整数管理元数据，独立于表达式标签 `group=G1/G2`。详见[膜系设计服务契约](film-design-validation.md#设计-schema-与引用)。

## 输入与输出

分析面板一次列出正、背两侧的所有层，显示侧别、稳定层 ID、材料、分析基准厚度、当前临时厚度及分组号。双面设计的两面都参与实际光学计算；单面设计仍列出存储的背面草稿并明确标为未启用。无效或不可换算层保留行但禁用相应编辑，并展示预览错误。

| 变量模式 | 输入 | 临时预览/显式应用行为 |
| --- | --- | --- |
| 物理厚度 | nm；每个显示数字位可分别上/下微调或直接替换为 0–9 | 只改写编辑层为物理 nm；未编辑层保留源值和单位 |
| 光学厚度 | QW；沿用设计的参考波长及选定材料 n | 只改写编辑层为 QW；已有计算服务解释 QW，未编辑层不重新舍入 |
| 入射角 | `0 ≤ angle_deg < 90` 度 | 仿真设置改变，物理膜厚不变；应用只更新 `workflow_settings.simulation.parameters.angle_deg` |
| 组系数 | 按当前 `interactive_group_id` 分组设置非负系数 | 每组临时厚度始终以本次分析开始时捕获的厚度乘系数；系数不与前次预览累乘。改变的层写回为物理 nm 与组号 |

默认显示精度使用应用既有膜厚显示精度（默认三位小数）；仅打开面板不舍入源数据，且预览副本保持每层未编辑的原始厚度精度。编辑一个数字位时，受编辑层才从显示位值构造新数值。负厚度无效，零厚度有效。QW 模式无法确定 n 或比例时该层不可编辑，并阻止对该层执行可能不完整的批量换算。

批量修改只作用于临时会话，可按正/背面、材料与组号筛选，并可按材料及光学数据集批量替换目标层材料。筛选字段留空表示不筛选；替换材料、厚度或新组号留空表示不修改；“取消分组”可显式清除组号。厚度单位遵循当前变量模式。所有筛选与替换先校验，再整体提交到临时会话；任一项非法或筛选不匹配时不修改任何层。材料替换保留其它未指定字段；单纯替换材料不重写厚度值/单位。

当前批量界面尚不实现材料常数 N/K、混合百分比、每层“是否优化”、约束开关、最小/最大厚度、针插许可、组约束/组系数优化或其它 TFCalc 替换字段；这些数据不会被伪造或默默重写。组系数只是本次交互分析的临时缩放值，不是优化变量，也不会单独保存为新的组属性。

## 预览、提交与取消

交互预览在单次短防抖后，使用已有 `FilmDesignService.freeze_design` / `FilmDesignService.simulate` 在工作线程上计算临时设计副本；不引入新的光学物理或求解算法，不向队列提交作业，也不修改源设计。快速编辑会取消较旧任务，并由单调生成号拒绝任何迟到结果。当前预览失败时，界面保留最近一次有效曲线、明确标成旧结果并显示错误；最新预览成功前不可应用。

“应用到设计”是唯一提交入口。膜厚/分组/材料修改以来源修订号和编辑 epoch 通过既有设计应用事务写入，保留已有单次撤销/脏状态行为；角度模式通过原工作流设置接口保存，只改角度并保留其它设置。底层会验证候选。交互候选省略组字段时现有会话按稳定层 ID 保留当前组；候选显式给出新组或 `null` 时按请求改组/清组。应用成功后清空临时会话，独立仿真窗口随设计源的正常联动重新计算已应用设计。未应用时，设计侧的临时计算光谱会通过源的临时预览信号显示到独立仿真窗口；临时曲线不能导出，取消/折叠/切换侧栏页/关闭分析会恢复独立窗口原有结果。

来源设计修订、编辑 epoch、文档 ID 或仿真设置在分析打开后改变时，会标记会话过期、取消待算预览并禁用应用；旧会话不得覆盖新数据。应用期间的会话通知由当前事务持有，应用后立即重新载入。用户可“重置”当前分析到捕获基准而继续操作，或“取消”、折叠侧栏、切换设计侧栏页、关闭设计窗口；这些操作取消临时预览并清空临时状态，不提交膜厚/材料/分组改动。关闭窗口仍按设计既有关闭确认流程；取消关闭不会提前丢弃设计会话。

## 验收边界

契约测试分别覆盖：输入位的进退与零值、未编辑高精度保留、全层预览刷新、来源冲突拒绝、重置/取消隔离、四变量模式、批量厚度/材料替换/分组提交、组系数从基准计算、显式应用与撤销、独立仿真窗口临时曲线联动、组号保存/加载/复制和优化候选继承，以及 FilmDesign 设计侧栏的实际 QML 控件路径。未实现的 TFCalc 功能边界仍是材料常数 N/K、混合比例、约束编辑和针插；未添加任何物理、优化或光谱算法。离屏 Qt/QTest 只证明测试环境中的 QML 加载和交互，不代表 Windows 原生窗口、全部显示缩放或长时间工作线程压力验收。
