# 应用后约束与膜厚显示精度

日期：2026-10-26。此修订仅涉及现有 UI 来源模型和显示设置，不改变求解器、停止条件、目标或厚度量化。

普通优化、从零合成完成及明确用户取消的候选，仍通过原有身份、工程 generation、session、revision、未提交编辑 epoch、冻结材料和来源关闭门禁决定能否应用。只有应用成功后才重新加载同一来源的约束模型；不能凭候选层表绕过未通过的写回。独立减量仍显式应用，其合法应用后的模型也同步。

约束以 `(side, layer_id)` 精确对应，保留匹配层的上下限及用户显式启用/取消选择；新可优化层默认启用、下限0 nm、上限未指定，不按行号、材料名或邻居迁移旧边界。没有用户配置的新窗口同样默认选择所有可优化层。恢复旧文档配置时只覆盖匹配行，不把新层全局清成未选。已应用结果之后的撤销/后续已提交编辑会重建来源；在途作业、未应用候选或未完成的输入冲突仍保留原保护，不覆盖新编辑。

UI 不为自动重建约束而改写膜厚或新增物理计算；原始目标、候选审计、继续来源和进度均由既有所有者保留。用户编辑约束仍按既有文档工作流配置保存。

膜厚显示使用现有共享 `config/ui_settings.json`，键为 `film_thickness_decimals`，默认3，可选0–6；入口为设置的外观页。SettingsBridge 保有待保存设置；保存后通过既有 ThemeSettingsSync 文件订阅分发。ThemeService 只维护显示偏好，向各引擎桥与膜系显示 controller 通知；该字段不进入主题 token 包，不修改配色、DPI 或数值请求。

主设计表格、总厚、优化结果/最佳详情、独立减量和实验 A/B 来源及比较厚度按同一选项显示，沿用 Qt locale 的舍入。百分比、误差和波长不套用膜厚位数；小厚度若固定小数会显示成零，采用科学计数表达。现有手动输入验证策略不受显示选择影响。

ThemeField 展示位数变化仅重绘失焦的文本；聚焦编辑使用原始完整来源文本，用户未触发 textEdited 时失焦不会提交。切换位数不增加编辑 epoch、不更改 design revision，也不重新计算光谱。只有用户真实编辑才走既有提交入口。求解的 float64、阈值、候选数字、保存及导出仍保留真实全精度，格式化字符串不能作为数值输入。

回归使用临时工程覆盖真实合成→设计写回→新约束→普通优化→同源光谱、完成/取消、撤销、失效ID、项目/来源切换与未保存编辑冲突；显示回归覆盖0–6位持久化与文件订阅、主表仅聚焦失焦不丢精度、全精度保存/导出、A/B和最佳详情、小窗口及明暗主题。用户活动工程未作为写入或测试目标。

联合 GUI 回归还暴露目标编辑 ScrollView 在12pt主题字体、显示错误消息并滚动后，使用子布局833px的隐式宽度而非387px可用宽度；横向滚动224px后角度下限框中心移至窗口外。该编辑器现显式令 `contentWidth: availableWidth`，让表单布局及换行决定内容，保留原键盘/鼠标和无效草稿校验，并在9pt/12pt下重复同一完整交互。不是通过重置字体或删除断言隐藏联合失败。
