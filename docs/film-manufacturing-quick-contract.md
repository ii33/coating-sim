# 工艺薄层修复 Qt Quick 边界（2026-10-25）

本页是已有优化窗口中的主题对话框，不新增普通顶层窗口的几何记录。布局沿用共享主题逻辑尺寸：来源及风险提示、稳定 ID 的前层复选列表、四个显式参数、原始/A/B 三份只读证据、独立选择及应用操作。主视区纵向滚动，小屏按可用父窗口尺寸收缩，不隐藏参数或结果；关闭后焦点由调用入口恢复。

唯一状态所有者为 `FilmManufacturingQuickController`。QML 只转发真实输入和明确动作。初次不选择任何层，reference_nm、每路评价、迭代、秒数均为空；空白不等于零或无限。只支持当前单面前入射、保留 k 来源；QW 按冻结材料和已有物理厚度接口在后台明确换算为 nm，不把 QW 数值当作 nm。A 起点保留并增厚选层，B 起点删除选层后按核心既有规则合并；两路随后均精修全部保留层，不只改选层。参考厚度不是全局硬下限，两路运行均不更改原始设计。逐键保存草稿，不校正、不回填；提交时拒绝无效输入。

控制器用 `FilmOptimizationRunCoordinator` 管理代次及取消。后台 QRunnable 冻结当前目标、材料内容和可编辑材料闭包，经 `film_manufacturing_repair` 本地 CPU 调度器执行；当前可信调度器结果只做绑定和完整证据验证，不在取消或预算结束后追加物理复算，历史报告验证由队列加载器负责；Qt 主线程不执行光学评价。取消意图不等于服务已取消。提交状态未知时保留原作业 ID，不重复创建。结果只有通过作业绑定和完整验证才进入比较；没有独立审计时显示“未知/未通过”，不能用训练分数宣称通过。完整 JSON 导出保留所有原始训练/独立审计、覆盖及逐目标证据、终止原因和预算账目。

比较读取原始及两路 champion（无完整 champion 时只展示缺失状态），分别展示原始约束训练/独立审计 nominal 和 solver 分类、每波段每角度固定网格诊断均值、采样最小/最大与最大违反点（零违反并列时仅展示首点，不当作波段极值）、层数、最薄层和总厚度 D。未启用的约束明确标为未启用，不把派生统计充当额外验收约束；审计均值使用核心固定稠密网格证据，不用增补极值点重算。

结果不会自动应用。必须显式选择 A/B，再点应用并接受可见的原始目标不变提示。owner 的 `_manufacturing_can_apply(payload, context, snapshot)` 和 `_apply_manufacturing_candidate(payload, context, snapshot)` 是最终安全边界，复用来源 `applySynthesizedDesign` 与提交时冻结的可编辑材料闭包以及撤销/修订验证。context 绑定来源 session/controller 身份、design revision、pendingEditEpoch、原始目标签名、项目根与项目代次，worker 同时返回 frozen_request 和 editable_snapshot。来源/目标/项目变化、取消、关闭/解绑、迟到或重复结果均不能自动覆盖。普通优化、敏感度与本操作互斥。

保存失败保留输入及已验证结果，覆盖已有报告须确认；关闭不保存或应用设计。Linux offscreen QTest 是定向验证，不代表原生 Windows、多屏 DPI 或屏幕阅读器验收。

就绪属性只做廉价的作业/会话/修订/编辑代次检查，不在 QML 重绘或动画期间展开大型角度网格、散列完整结果或反复读取材料目录。实际“应用”动作仍再次核对完整原目标签名、冻结物理指纹与实时材料内容；外部材料文件发生变化时，按钮可能在点击后的最终核验才给出拒绝，不代表跳过核验。

持久队列的历史报告使用独立只读 AppWindow，复用同一比较组件，且没有来源上下文或应用资格。创建后先隐藏并调用共享 prepare_window_geometry（film_manufacturing_report），再显示；默认 1100×760 逻辑尺寸、屏幕可用区域夹取及每模块几何恢复均沿用共享策略，没有几何例外。重复打开复用同一窗口。

整数配额按十进制原文精确判定并转换，不先经 binary float。`2.0000000000000001` 明确拒绝，`9007199254740993` 保持原整数；既有合法科学计数法（如 `1e2`）仍接受，但必须精确为正整数。有限正数输入域保持原行为，过大的指数在构造整数前拒绝；不舍入、夹取或修改草稿。参考厚度和秒数仍为有限正浮点数，配额含义和停止上限不变。
