## 重放候选

输入仍为原服务与固定拓扑 checkpoint mapping，输出必须是同字段、同数值的独立 dict；结构分支仍交原结构验证。候选不重新搜索、不修改 seed/预算/K，不跳过 schema、冻结材料、设计、厚度、逐条件错误或留出校验。先通过一次温态实际验证的 caller/callee 统计定位复制与转换，再决定最小等价变化；不依据旧 fresh cProfile 的累计时间猜测调用来源。

返回值与输入不得共享可变容器；自定义对象、错误输入和异常路径须保留原类型、消息与检查顺序。物理计算、稳定 `frexp/fsum` 评分、波长分块、完整训练/留出条件与误差诊断沿用原函数，不做新的数值算法。

## 编码候选

输入仍为路径、受控膜系 payload 和原可选 `max_bytes`；输出、完整 UTF-8 字节、大小限制、目录创建、flush/fsync、`replace_with_retry`、失败临时文件清理与旧文件保护均沿用原保存契约。内存预检需先给出保守界限；不能无界 `dumps` 后才检查。超候选资源阈值、非受支持 JSON 数据或编码错误回原 streamed writer，以保留检查次序和错误副作用；不是更换通用 JSON 后端。

取消与归档的唯一所有者仍是原 worker/优化器。一次写入内部不新增取消点，停止提交与晚到结果边界不变；不能减少 checkpoint/验证频次，不能为加速省略完整光谱。诊断统计不得进入严格 v1 结果/checkpoint。

## 验收与后续边界

专属测试覆盖合法与损坏输入、错误类型/消息、输入不变、返回隔离、编码同字节、资源回退、fsync/replace 失败与旧目标保护。先分别测同 checkpoint 的完整验证和真实原子写盘，再测同材料/网格/预算的温态完整 worker；首次依赖加载单列，至少三次温态对照交替顺序，保留每次数字和变慢场景。测试/基准数值负载串行，不停止用户应用或扩大队列并发。

优先目标仍是代表组重放阶段降低至少20%（旧基准约0.21s/job），或未插桩端到端明确省至少0.10s/job；这些是本项目筛选约定。当前写入阶段有局部收益，端到端改善小且不足稳定门槛；原始数值与限定结论见下文。GPU 能力与数值模块维持此前状态，本阶段不扩展框架。

## 已测结果与最小交付

完整证据见 STAGE3.md（历史验证记录，未随公开源码发布）。重放复制候选13项测试通过，三组温态 baseline/candidate 中位为0.287013/0.296327s，慢3.25%；其补丁已标为 rejected，不交付为推荐优化。

编码候选23项测试通过，严格保留原 JSON 参数、字节限制、UTF-8、flush/fsync、替换重试、错误清理和旧目标保护。预检支持 exact builtin dict/list/tuple、字符串键和有限 JSON 标量；tuple 用原 JSON 数组表示，子类仍回退。阈值是512KiB、32768次节点访问、深度32、单串262144字符、整数4096bits、每调用256条字符串缓存；资源域外仍走原 streamed writer，不产生新的合法输入拒绝或截短光谱。64MiB是设计预算，不是进程RSS硬上限。调用期间 payload 由worker独占，装载时核对原写函数指纹；调用方负责测量前后来源核对。

旧磁盘读回的315977字节文件实盘中位为244.893/94.995ms；该版本仅支持list，不能追认实际typed请求。首组完整worker因live `angles_deg` 为tuple而全部回退，被 `accepted_calls>0` 检查挡住，保留在 NOT_ACCEPTED.md（历史验证记录，未随公开源码发布）。修复tuple后新目录独立测量，未把该失败首组计入预热结果。

当前真实worker函数级对照（非生产队列端到端）两侧均开启既有缓存、CPU1、FP64/complex128，1001波长×12层、同seed=19、预算49/实际47次评估与3代。首次依赖加载9.1449s和候选装载0.0131s单列；首次worker为5.2392/4.8830s。三组warm total为 baseline [5.552946,5.441751,5.405598]、candidate [4.979832,5.357710,5.313004]s；总中位5.441751/5.313004s，1.02423x，独立中位差0.128747s。配对节省[0.573114,0.084041,0.092594]s，中位0.092594s，小于0.10s筛选目标；不声称稳定20%端到端收益。进程CPU中位两侧均4.28125s，不能声称CPU总体降时。
