# 严格名义验收与求解可接受状态

本修复不改变用户门限、归一化比例、权重或误差容差，不添加制造余量。

- `targets_met` 表示原始目标严格名义通过：原完整训练约束和已完成的独立核查均满足实际门限，不再以 `acceptable_normalized_error` 放宽目标。
- `solver_acceptable` 单独记录实际分数是否满足用户的求解误差容差；未知或没有完整对应核查时不得冒充已核通过。停止原因、失败、取消和最佳候选证据仍分别保留。
- 原有range约束默认保留上下界包含等号的语义。自动合成新增可选 `strict_upper_bound_objective_indices`，明确指定上界采用数学 `<`；例如严格R<3%的等号边界不通过。不能按3%数值硬编码推断运算符。既有显式严格下界配置保留原来的 `>` 语义；未选严格标记的下界仍为 `>=`。
- 判定直接使用各条件的实际值与原门限。归一化下溢、权重为零或浮点残差不会把真实越界变成名义达标；精确数值目标不额外赠送epsilon。
- 普通结构优化v1请求保持原有严格未知字段拒绝规则，不把此字段静默混入普通请求。
- GUI、CLI、队列与独审核查同时呈现原门限名义结果和求解容差结果。只读旧历史必须绑定冻结请求并经过物理重放重算，旧的容差通过标志不是名义证据；不能削弱设计、材料、分数或请求身份核对。
- 敏感性是独立可选能力；其名义/有限场景通过标签采用原门限，不借求解容差伪装通过。线性指标与实际有限扰动仍分开。

必需回归：R=0.04而上限0.0395、默认求解容差0.001时名义失败但可求解接受；严格R<0.03在等号处失败、略低通过、略高失败；旧包含等号的上界仍可在等号处名义通过。所有原始波长/角度约束及独审核查门禁保留。

## 实际接口与状态

自动合成结果封套增加 `acceptance_semantics="nominal_bounds_v1"`，内部结果、候选独审及每项目标分别给出名义结果与 `solver_acceptable`。旧文件缺少标记时不直接信任其通过标志，必须在后台重放后打开只读兼容副本，原文件不变。任务执行完成或队列 `succeeded` 仅是生命周期状态，不等同名义达标；取消、失败及未完成核查不变成绿色成功。

优化窗口在自动合成模式下提供“严格上界”选项，保存为该目标行独立的合成设置；它只进入合成或独立敏感性请求，不进入普通优化v1。勾选不会改变原上界数值。独立敏感性捕获同一运算符，但不依赖其他未提交合成设置是否完整。敏感性请求未使用严格上界时省略新增可选字段，维持原独立请求的规范化身份；解析旧敏感性结果时从完整实际条件推导缺失的求解可接受字段，不采用历史容差通过标签。

敏感性报告的百分比违规使用实际物理差值乘100，和归一化误差分别显示；有限场景也单独显示名义通过和求解容差可接受。线性估计不参与有限扰动验收。只有真实终态且来源版本/编辑代际仍一致的结果才开放显式确认应用；中途检查点不能因含有最佳候选就获得应用按钮。

数值上“极接近零”的正反射仍不满足精确R≤0；此时允许求解可接受而名义未通过。搜索因此继续到不同厚度的更优候选是正常行为，不能把旧的容差早停结果硬性指定为终态。
