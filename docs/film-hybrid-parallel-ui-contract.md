# 混合合成多核入口与诊断合同

日期：2026-10-22。此合同先于本次界面实现。

## 输入及唯一所有者

`parallel_batch_size: int | None = None` 只属于独立合成请求。空值表示AUTO，冻结时按用户请求进程数及真实可用CPU解析为正逻辑批次。显式正整数保持不变；布尔、零、负数、非整数拒绝。普通优化v1和独立敏感性请求不接受此字段。legacy的AUTO保持兼容，不宣称已采用新混合调度。

逻辑批次不是实际并发保证。正式核心还按候选数量、阶段及总预算、冻结内存估计和通信帧大小准入；实际工作进程可以小于用户请求。没有人为4进程上限。串并对照保留同一冻结逻辑批次，只改变执行宽度。

GUI控制器拥有编辑中的合成设置与代际，核心拥有冻结请求、预算、子进程和按源序采纳的结果。开始后不能通过编辑改变正在运行的请求。配置保存恢复走已有合成设置序列化；不改变当前膜系、材料、原目标或原网格。

## 正式入口及异步边界

自动合成设置提供“独立候选逻辑批次”，留空为AUTO。CLI的 `--parallel-batch-size auto|N` 显式覆盖此项，仅在内存中形成实际执行/规划请求，不回写输入文件。MCP公布同一可空正整数字段，计划仍只读，提交保留原确认和去重流程。job/checkpoint沿既有冻结序列化路径，不增加旁路执行器。

所有光学计算继续在现有后台正式作业路径。独立先验/全局候选和同一轮解析针扫可多进程；联合全部厚度精修、档案采纳及下一轮构造仍保持必要的顺序依赖。子进程使用现有正式stdio执行器，不新增socket或网络通道。

## 诊断及失败语义

结果展示请求进程、真实记录的工作进程和PID数量、冻结逻辑批次、资源准入上限、已提交/完成/按序采用/未采用/回退及原因。历史缺失字段显示未知，不能从请求19推断实际19。PID仅为本次记录，不代表仍存活。阶段基准不能冒充整体加速，预算停止、未知工作、子进程失败、取消和清理状态分别记录。

本次不改变渲染、硬件加速、用户门限、名义验收、敏感性误差目标或最终应用确认门禁。
