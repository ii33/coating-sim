# Intel 核显支持范围

更新：2026-10-17。设备出现、运行时探测通过、有限数值验证和完整任务验收是不同状态。设备弹窗按任务显示支持范围；运行时缺失或检查失败时仍显示不可用原因，不会用 CPU 结果声称 GPU 通过。

| 功能 | 当前支持口径 | 限制与操作 |
| --- | --- | --- |
| CPU 沉积、膜系优化、外观 | 产品已支持 | 作为可明确选择的本机路径；不表示所有物理模型或输入已全面标定。 |
| Intel 核显 DirectML 平面沉积 | 数值后端有限验证通过 | Windows、兼容 torch-directml 环境、显式 Intel 设备绑定的两个限定测试之一；不是当前默认设备选择的端到端验收。 |
| DirectML 遮板/姿态边界 | 实验范围，边界精度待验证 | 已观察到遮挡采样差异。涉及边界的结果应与 CPU FP64 对照，不能宣称完整精度已通过。 |
| Intel XPU 膜系前向批评估 | 本机后端限定验证通过，窄范围桌面实验入口已接入 | 修复标量 pow 停顿后，18 组 FP64/complex128 对照通过，最大绝对误差约 2.45e-14；不普遍快于 CPU。桌面仅显式固定拓扑 DE 延迟批量、单条件单角度、前表面半无限基片，UUID/运行时冻结到队列；默认 CPU，失败不回退。 |
| Intel 核显外观 GPU | 不可用：产品后端未实现 | 现有 GPU 外观入口只接受 NVIDIA CUDA/OptiX；Intel 没有 DirectML、XPU、SYCL 或 DXR 渲染入口。可显式选择 CPU 外观。 |

## 已有实测依据

原生 Windows 主机 sakuya，Intel Core Ultra 7 265K / Intel(R) Graphics，PCI `8086:7D67`，驱动 `32.0.101.9033`，D3D12 FL 12_2。源码基线为 `3ff4916611e7f3f1bb71ac32d435051f203aa224`。沉积/外观说明归纳该基线实测；后续 XPU 后端验证使用23bba330加幅值自乘修复。两者均不声称整个版本重新完成所有硬件验收，也不能推广为所有 Intel 核显和驱动的保证。

沉积测试使用独立 Python 3.12.14、torch-directml `0.2.5.dev240914` / PyTorch 2.4.1 / NumPy 1.26.4。生产数学路径未修改，测试进程显式绑定 DirectML 索引 1，GPU 张量和读回均核验为 `privateuseone:1`，计算为 FP32；CPU 对照为 FP64。最终 NumPy float64 容器不会恢复 GPU FP32 已损失的精度。

- 平面点源：257×257 网格、51,433 有效点、600 步，最大归一化绝对误差 `6.31723e-7`，筛查超阈值点为 0。
- 倾斜/遮板/衰减：181×181 网格、25,445 有效点、360 步，7 点超筛查阈值，最大归一化绝对误差 `0.00352624`、最大相对误差约 `0.364455%`。单点重放观察到遮板投影跨越边界，不能归结为所有 FP32 都必然出现同样偏差。
- 使用的 `rtol=1e-4, atol=1e-5` 是此次测试的项目筛查约定，不是产品精度承诺。未扩大容差，也未修改几何或计算算法。

XPU 测试使用官方 PyTorch `2.10.0+xpu`。FP32、FP64、complex128 及项目 `gpu_capability("xpu")` 基础检查通过；16 候选×81 波长×2 内层膜的真实批评估先后达到 90 秒和 180 秒诊断期限，没有返回批量结果、实际评估后端或 CPU 回落元数据。这是早期失败记录，不能将它描述成硬件没有 FP64 或只是缺依赖。后续同步逐算子诊断定位 `aten.pow.Tensor_Scalar`，以同精度幅值自乘修复，已完成 18 组本机后端数值对照与 17 个性能点；详见[后端实测及产品接入边界](intel-film-backend-benchmark-20261017.md)。当前窄范围桌面接入及生命周期验收另见[桌面合同](film-xpu-desktop.md)；不代表所有 Intel 型号或功耗条件已验收。

CPU 外观在真实 `render_job()` 中完成 2 波长×24×24 像素、2 spp 的限定运行，执行元数据为 `cpu_scalar`。这不是 Intel GPU 渲染证据，也不是外观物理精度认证。

完整原始报告及数据在本次本机验收目录 `task-2/INTEL-GPU-TEST-REPORT.md`、`results-summary.json`；它们未随仓库发布。公开仓库中的本页保留设备、版本、输入规模、结果及验证限制，不嵌入用户安装目录或运行时凭据。

## 当前设备选择和回退

正式沉积选择器仍保留 CPU、CUDA、DirectML 的手动选择。`directml:default` 只表示现有后端的默认/AMD 优先选择，不是 Intel 物理适配器 ID；多 GPU 主机不能仅凭选择 DirectML 就认定计算发生在 Intel 上。设备名称未知时保持“默认设备／物理 GPU ID 未指定”，不伪造 Intel 标签。膜系实验桌面入口使用独立的冻结 XPU index/UUID/运行时绑定协议，见[合同](film-xpu-desktop.md)。

运行探测的 `available` 只表示该后端的有限初始化和算术探测成功；`runtime_probe` 与 `support_level`、`support_note` 分别表达运行状态和验收范围，不将硬件名称升级为任务支持。选择后限制说明继续可见。缺少依赖、探测超时或失败仍保留明确原因；不可用设备不接受选择。

显式 GPU 选择不静默替换为 CPU 或其他主机，参考/转速搜索等仅 CPU 算法仍拒绝 GPU。自动后端模式若沿用既有回退，会记录实际 `backend_selected` 与回落说明；验收必须核对实际后端。CPU 是用户可明确选择的路径，不能替代 Intel GPU 支持证据。

设备选择与探测的唯一状态所有者为 `ComputeTarget`，显式批量及 CPU 线程/轴草稿由优化控制器持有；队列拥有作业状态、结果与取消。探测继续在有期限的后台进程中执行，过期异步结果按原 generation 丢弃。不自动启动性能基准、安装依赖或修改驱动；执行仍沿用队列的取消及候选应用门禁。

实现位置：[设备探测](../coat_sim/core/compute_device_probe.py)、[设备选择模型](../coat_sim/ui/compute_target.py)、[共享设备弹窗](../coat_sim/ui/qml/ComputeTargetSelector.qml)。相关合同见[计算主机与设备选择](compute-host-selection.md)。


补充的60层、10000波长×1角度证据中，核显单候选0.0389秒对CPU0.0575秒，但64候选核显1.2504秒对CPU0.6031秒；异构为0.4720秒。完整256次评估CPU/核显/异构分别约2.3076/4.7916/2.0263秒。最大光谱绝对误差约4.27e-14。详见[10000离散目标测量](intel-film-backend-benchmark-20261017.md#补充60层10000离散目标同日)。这不是10000候选，也不是对所有任务更快的承诺；不固化本次8线程或43/21拆分。

上面的10000目标计时为旧候选轴 CPU 基线；补齐波长并行后，单候选 CPU4线程0.03431s vs Intel0.04382s，64候选 CPU8线程0.51216s vs Intel1.18319s，均为同包装7次交替稳态。本机 CPU 更快；旧异构12.2%不能沿用为对新基线的优势。详见[公平复测](cpu-wavelength-workers-20261017.md)。

新异构闭环已完成：60层/10000目标/256评估，独占进程五轮热态中位 CPU2.385s、Intel4.835s、异构2.269s（约4.8%）；冷启动2.291/7.689/4.875s。捕获未知 Python 约1核瞬时活动，4.8%不构成稳定收益保证；旧12.2%作废。异构不自动启用，不再追加调参，见[闭环报告](hybrid-closure-20261017.md)。
