# 优化终态写回、数值零与实时详情契约

日期：2026-10-26。源码候选，尚未发布；补充既有合成、取消应用和实时展示契约。

复核补充：完整复算后光谱不等价只拒绝该清理候选，保留完整冠军并继续其它合法拓扑；不发布原 tiny 层或非等价清理结果，不把真实配置/前向异常吞成普通拒绝。显式暖起点被拒且没有此前完整候选时，允许在原共享预算内评分裸环境后继续；不能评分则如实返回空。environment 必须裸栈，带层输入由验证明确拒绝；层序须作为 seed 冻结。普通优化 completed 但未全部达标而已自动应用时，状态明确报告“未全部达标、已应用、未保存、已请求刷新”，不改变既有应用策略。

`FilmOptimizationQuickController` 唯一持有当前尝试、冻结来源和应用资格。正常完成的普通优化/从零合成共用自动应用入口；显式用户取消沿用原取消入口。每个入口都保留 operation、工程 generation、session、revision、pendingEditEpoch、材料闭包和来源关闭判定。失败、无有效候选、历史浏览和切换/编辑冲突不会覆盖当前设计。合成通过 `applySynthesizedDesign` 原子写回完整拓扑、冻结材料和一次撤销；普通优化沿用固定拓扑厚度写回。成功后只通过同工程 `openSimulationAndCalculate` 刷新；仿真接收应用后的新 revision，旧缓存不能冒充新设计。独立减量仍显式应用。

数值零清理属于核心候选提交边界，QML 不按显示精度改厚度。原始固定维数求解值和 Jacobian 继续供求解器使用，只有清理后的候选在真实原网格复算、确认等价后才进入训练最好候选与展示档案。额外调用计入共享预算及阶段额度，不能占用保留工作/审计槽。独立审计不由清理继承；正式达标仍需原目标的真实独立验收。精确尺度、约束和光谱等价阈值见 algorithms.html 的 14ba。

取消或资源不足使潜在更优数值零试探无法清理复算时，返回已有完整训练候选；没有这种候选则返回空。`performance.search.numeric_zero_fallback` 记录未发布输入哈希、返回物理哈希及其训练/审计绑定状态，结果消息和 GUI 状态明确说明回退，不能将其称作最新未完成试探。手工编辑冲突仍由原 `_error` 判定保留，回退提示仅附加状态文字，不清除冲突。取消后不为清理或审计追加工作。

`FilmCandidateDisplayObserver` 从已有完整原网格 coverage 计算所选波段/角度均值与峰值，绑定同一个物理哈希；无需额外前向。缩略曲线可抽样，统计不从缩略点重算。`bestDetailSummary` 只读真实 `best`，不读最后试探或展示分 Top10。均值是波长梯形质量统计，不是暗中启用 mean 目标；详情同时给出全目标最大违规与 RMS。更换条件后尚无对应统计时不伪造数值。

`FilmCandidateDisplayController` 独立持有显示纵轴状态，默认自动、百分比显示、内部 fraction。自动范围包括当前/最佳曲线、完整峰值和目标线，上升立即扩张，连续两帧低于旧上限 45% 才缩小；无数据保留上一范围。手动范围只改变图形，要求有限的 0 ≤ 下限 < 上限，不修改目标或求解器。`axisChanged` 与数据包通知分离以免递归更新。QML 仅提交设置、绘图和呈现详情；现有窗口尺寸/主题 token/布局政策不变。

回归使用临时合成材料工程：正常/取消自动写回及真实光谱刷新；旧 revision、edit epoch、session、工程和 operation 拒绝写回；tiny/1e-15 删除、0.7 nm 保留、正下限、不同数据集和合并厚度上限；预算/取消回退身份；真实 Qt Quick 图表、手动轴、原网格统计与小窗布局。用户活动工程仅作此前只读检查，不作为测试输出目标。
