## 唯一状态所有者与合法载入

`FilmDesignEditSession` 继续唯一拥有当前设计、dirty、revision、路径及一次生成撤销。只读配方目录单独提供稳定 ID 和名义层表，和五条参数化模板、SQLite 用户保存设计分别显示。侧栏增加“文献/教程参考设计”列表及局部映射面板，沿用既有膜系窗口和共享控件；不建立额外设计窗口，不改材料注册或写入用户材料库。

schema v1 的膜层仅接受明确 `material_id/optical_set_id`；基片同样必须绑定材料。仅入射/出射介质支持常数 n，不能借此向膜层或基片塞入名义常数模型。故当前原名义配方不直接伪装成可仿真的 `.cfilm`，采用明确材料映射后生成的合法载入路径。

每个原始膜材料角色、入射介质和基片都须明确选真实材料 ID 及所属数据集 ID。膜层映射初始为空；不能根据 MgF₂/ZrO₂/CeF₃/Ge/ZnS 等名称自动配对，也不能悄悄沿用其它模板的选材。原始理想膜也是抽象角色，由用户指定实际材料。所有选择都显示在映射面板并须勾选确认“映射后的设计不同于原名义模型，性能须重新仿真”。未知 k 另须显式无损假设；已知吸收不得用此选项绕过。

映射固定原始 λ₀，按所选数据集原始 n/k波段严格求值，不外推，不猜常数。固定nm参考映射允许膜层和基片的有限、非负已知k，保留该值用于实际仿真，显示Δk及吸收提醒；负k或已知吸收入射端口拒绝。未知k仍须另行显式无损假设，不能将已知非零k清零。五条透明参数模板仍沿用1e-9阈值，不因参考映射扩展而改变公式适用范围。**保留原配方每层物理厚度 nm，不用映射后的 n 重算 QW 厚度。** 同一原始角色的所有重复层复用该角色的明确选择。映射只改变材料引用和实际光学模型，不能宣称原设计指标仍成立。此区别是本项目实现约定。

预览同时返回不可变的原名义配方和映射结果：原始层序/n/k/物理nm、每个角色的实际材料/数据集及 n(λ₀)/k状态/与名义 n、k 的差异、层数/总厚度、单面/半无限基片假设、材料数据有效域及限制。未知k的Δk为null，不能表示测得零。映射后设计名称/备注清楚标记“参考配方映射”，保存原始配方 ID、来源、名义模型、原nm层表和明确映射。前层按入射→基片读取后反转存入 `substrate_outward`；正面涂层、背面为空、single基片，保留当前基片物理厚度与当前文件路径。

预览不更改 session、文件或 SQLite。确认应用复用既有 opaque单次token、design_revision和pendingEditEpoch校验、`applyGeneratedDesign` 原子路径、dirty/伴随页通知与一次生成撤销。用户还须确认“应用映射结果并替换当前设计”；原始配方不会被覆盖，用户库仅在显式保存后改变。不存在新后台计算或迟到结果；调用同步且配方层数有限。源关闭、设计/未提交编辑改变、切换配方或修改映射均使预览失效。

## 加载、空数据、错误、取消与恢复

controller未ready时禁用预览；无材料或无数据集显示明确空状态。缺角色、数据集不属于选中材料、无效 n、数据域越界、未知k未确认、负k、已知吸收入射端口、确认未勾选或旧token均拒绝，保持旧设计。映射预览错误由局部面板 `errorText` 显示，不伪造 session 修改或设计 revision，不清掉原始配方或用户选项；标题栏继续绑定既有 controller 状态。

取消仅丢弃候选；折叠/切换功能保留映射输入与滚动，恢复焦点，清除待应用预览。关闭整个设计页沿用原关闭/dirty确认，不另加退出业务。正常与窄宽使用现有侧栏内部滚动区和Theme逻辑尺寸，不改公共窗口/侧栏布局。固定参考目录没有用户库删除、版本管理、搜索或分类编辑功能。

## 实现与验证真值

当前实现：`coat_sim/core/film_design_reference_recipes.py` 提供只读目录与映射预览；`coat_sim/ui/film_quick_controller.py` 提供目录和preview适配；现有 `FilmDesignQuick.qml` 库区及局部映射面板呈现。Python签名、数据结构和定向契约测试为真值，不另造文件格式。

定向验证须覆盖每条原层表的独立复算、目录JSON往返和无共享可变数据、真实材料映射固定nm、已知吸收保留及独立复数矩阵对照、源配方/旧设计防覆盖、未确认/无绑定/未知k/负k/吸收入射负例、确认取消/token过期/一次撤销、用户库与 `.cfilm` 保存读取。算法公式与说明图同步写入可离线打开的 `docs/algorithms.html`。
