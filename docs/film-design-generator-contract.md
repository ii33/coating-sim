# 膜系参数化生成器契约

日期：2026-10-20（保留经典模板原契约，追加物理结构分支）

入射端口适用边界：参数模板要求已知k精确为0，微小非零k也明确拒绝，与实际光谱求解器一致；不能按透明阈值将它清零。膜层/基片保留现有1e-9透明近似阈值，未知入射k仍须显式无损假设。独立测试数据的生成→真实服务观察及修补后验证见`artifacts/film_design_reference_library_validation/incident-k-boundary-*.json`。

本文原有透明阈值与未知k选项仅适用于经典模板。新增物理结构分支严格采用其独立真实n/k契约，不继承该无损假设选项；见文末。

## 范围与唯一状态所有者

生成器是现有 `FilmDesignQuick.qml` 右侧共用侧栏中的一个并列内容区，用公开经典结构公式构造一次性预览。它不创建窗口，不写 `.cfilm` 文件，不写 SQLite 用户设计库，也不自动启动仿真或优化。右侧同一侧栏提供表达式编辑、参数化设计和设计库三项功能；内置模板目录与 SQLite 用户保存设计分别显示。`FilmDesignEditSession` 是唯一设计状态所有者；生成器目录和计算函数只读输入材料目录并返回预览候选，QML 只负责选择、呈现和显式确认。

一个候选由模板 ID、目标真空波长、整数 pairs、每个膜层角色的材料 ID/光学数据集 ID、入射介质材料/数据集、基片材料/数据集、未知消光系数的显式无损假设，以及生成时的 `design_revision` 和 Quick controller 的 `pendingEditEpoch` 组成。默认沿用当前设计的入射介质与基片绑定；用户可在侧栏修改。入射介质选择沿用 Quick 现有入口目录：可从 `medium`、`film`、`substrate` 三个材料选项集合中选择，但仍必须匹配用户选定的材料 ID 和其光学数据集 ID，再在目标波长严格求值。新生成的前表面序列先按“入射介质 → 膜层 → 基片”解释，再反转为 schema v1 的 `substrate_outward` 顺序，写入 `front_layers`；`back_layers` 保持为空。

## 输入、输出与边界

目标波长 `lambda0` 以真空纳米为单位，必须为有限正数，并落在所有选中数据集 n 的原始有效波段内。所有介质及膜层均从材料库中选择明确材料和光学数据集；生成器在目标波长处直接求值所选数据集。不得用文献示例折射率代替材料库数据，也不得外推、端点钳位或使用仿真器对缺失 k 的零值默认。

膜层采用正常入射、透明材料的实折射率薄膜公式。`n` 必须有限且大于零；高低折射率结构还要求实际求值 `nH > nL`。已知k必须有限且非负，负k一律拒绝；在目标波长处实际求值，若 `k > 1e-9` 则拒绝生成。若k不存在或来源波段无法覆盖目标波长，只有用户显式勾选“对未知 k 假设无损”才继续，并在预览与设计说明中留下该假设。此确认只处理未知 k；任何已知且超过阈值的吸收都不能被无损选项或 `use_k` 设置绕过。生成的设计保持 `use_k=true`，并将 `assume_lossless` 设为该显式确认值。固定nm参考层表的已知吸收映射另见[参考库契约](film-design-reference-library-contract.md)，不套用本节QW生成公式。

成功预览返回：模板目录元数据、所选材料与数据集、各层入射侧到基片侧的次序、每层由 `d=q lambda0/(4 n(lambda0))` 得到的物理厚度（nm）、总物理厚度、中心波长解析公式参考值、原理、适用域、参数技巧、近似和仍需优化的限制。预览保留基准 revision/epoch，不能修改 session。确认应用时，session 必须仍匹配基准设计 revision；controller 还必须匹配 `pendingEditEpoch`。否则拒绝并要求重新预览。

应用是单次原子替换：候选先通过现有 schema/service 校验，然后 session 更新设计、derived 层视图、dirty 标志和 design revision，并通知现有仿真/优化伴随页订阅者。应用保留当前内部设计 ID 和文件/工程文档句柄，生成结果成为该文档上的未保存草稿；整个层堆被替换时生成新的层 ID，不伪造旧层对应关系。新建、导入和保存副本是独立的创建操作，保存/覆盖仍走现有流程。用户可对这次生成应用执行一次专用撤销；撤销恢复原设计、dirty 状态、路径及项目膜系的材料快照，只在 session revision 仍等于该次应用产生的 revision 且 controller 的编辑 epoch 未改变时成功。之后任何设计更改都会使该撤销失效，不提供全局历史栈。

侧栏“设计库”中的“保存当前设计到库”先提交表达式草稿，再调用现有 `saveToLibrary()`/session SQLite 保存流程；成功后刷新用户设计列表、清除 dirty 并推进设计 revision，从而使生成器的一步撤销失效。验证失败沿用 session 错误状态，当前设计不被新候选替换。窗口只有在关闭被接受时才标记 source closed；被取消的关闭不失效 session。已关闭 source 拒绝新的预览、应用和撤销，且预览面板会收到失效信号清除旧结果。

生成候选统一设 `substrate.sides="single"` 并清空背面层，保留当前基片物理厚度值。中心解析结果按正面涂层接半无限基片计算；`single` 使用现有设计语义，不把有限厚度基片或背面反射纳入解析参考值。预览和候选备注均明确此约定。

## 名称与材料快照

默认占位名称和可严格识别的旧自动名称使用简洁的当前模板名，例如
`HR (HL)^8 · 550nm`；N 使用实际对数，不重复追加完整模板标题。
切换模板或改变参数时可识别的自动名称随之更新。其他用户自定义名称
（包括120字符长名称）完整保留，不截断，也不从自由编辑备注推断其来源。
旧名称仅在“已知默认占位名 + 一个或多个完整已知模板标题”的严格格式下
折叠，无法确定的旧后缀保留。新短格式作为自动名称约定保留。

项目生成使用当前设计已捕获的材料值和明确选择的数据集；若材料目录在
预览后改变，应用拒绝并要求重新预览。应用时捕获新引用的完整材料记录，
撤销恢复先前材料上下文。冻结默认膜系草稿的首次保存仍携带生成后全部
引用的材料闭包；外部同ID材料随后改变时保存拒绝且保留未保存草稿。

模板与参考配方都由 session 保存最后一次成功预览的完整候选副本、设计
revision 和材料 provider；应用只接受该候选，拒绝未知、已被后续预览替代、
内容被改动或材料来源过期的候选。失败的重新预览同样使先前候选失效。
撤销继续保留生成后用户修改的工作流配置，并把其新增材料引用加入原设计
的恢复快照及冻结首次保存闭包，优先保留已经捕获的材料值。若同 ID 的
原快照不能满足后续配置的数据集引用，撤销在改变设计或快照前失败，
不替换原物理数据，也不丢弃用户的后续配置。

## 模板目录

目录为内置只读数据，与 SQLite 保存设计和用户表达式模板分开。每项使用稳定 `stable_id`，并声明 `family`、来源 URL、原文章节、原示例材料/波段条件、公式说明、许可边界、角色列表和 `verification_status`。目录元数据记录原始示例材料与波段条件；其中的示例常数只用于标明出处，不进入材料库数据集或运行时求值回退。目录只保留独立撰写的公式摘要和来源链接，不复制教材或教程正文、图像、软件模型、配方或数据库。已收录条目为：单层四分之一波 AR；双层 Q/Q V-coat AR；Q/H/Q 文献示例比较种子；`(HL)^N` 四分之一波 HR；以及 `(HL)^N C (LH)^N` 半波缺陷 FP，默认 `C=H`，且 `C` 可选其他材料。参考条目只说明结构依据，不保证实际选材的谱性能。

五条均为参数化结构模板；当前内置完整的固定材料/厚度公开设计文件为零。原始条件元数据不等于可直接载入的公开配方。用户保存设计区提供现有 SQLite 保存、刷新、列表和加载功能；未新增库删除、版本管理、检索分类或固定公开设计导入集。

双层 Q/Q V-coat 中心匹配条件为 `n2/n1=sqrt(ns/n0)`，其中心导纳 `Y=ns(n1/n2)^2`。Q/H/Q 示例用于可比较的起点，不宣称中心反射率更低或具有宽带保证。四分之一波 HR 以 `Y=ns(nH/nL)^(2N)` 计算中心反射率。半波缺陷 FP 的中心矩阵简化只在 `n0=ns` 时给出理想 `T=1`；非对称边界不适用该结论。所有模板的材料 n 均在运行时由所选数据集求得。

## 错误、加载、取消与界面状态

设计器沿用 Quick 页现有初始化状态：controller 未 ready 时不能开始生成，ready 后若材料或数据集列表为空，应显示“没有可用的光学数据集”并禁用预览；材料选择后没有符合波段的数据集时显示该角色的明确错误。无数据、无效 n、波段越界、k 未知未确认、k 超阈值、nH/nL 次序不成立、非法 pairs、schema 校验失败和 revision/epoch 过期均显示可理解的错误，不替换旧设计。

切换离开参数化侧栏、取消、切换模板或改动任何输入都会清除临时预览。侧栏折叠后再次展开，模板、角色选择、参数、编辑值和滚动位置仍保留；重新打开整个膜系页时保持一致的初始几何并清除旧预览。计算在当前界面事件调用中同步完成，目录最大 pairs 限制使工作量受控；不存在后台任务或迟到的异步完成结果。取消边界是开始 apply 前：取消立即丢弃预览；apply 作为一次原子 session 调用，不暴露半成品状态。

预览确认按钮是唯一应用入口，标签清楚说明它会替换当前未保存设计。成功后保留生成设计为 dirty；失败仍留在参数侧栏且原设计不变。撤销只对刚完成的这次生成应用可用。默认入射介质和基片沿用现有设计，选择控件在侧栏内可编辑。

膜系页顶部将名称、备注入口和常用操作压为一条可换行的工具带。备注按钮打开同页 ThemeDialogBase 编辑器：打开时读取 session 当前备注到局部草稿，最多 20,000 个字符，只有确认才调用 controller 的 `setDesignValue("note", draft)`；取消丢弃局部草稿且不改变设计、dirty 或 revision。膜系备注仍由 `FilmDesignEditSession` 唯一持有，编辑没有异步任务；对话框不保存文件。

侧栏复用 [共享 Qt Quick 页面与控件规范](quick-theme-controls.md) 和 [窗口几何策略](window-geometry-policy.md)：沿用 Theme token 的逻辑间距、按钮高度、颜色和字体；使用内部滚动区；切换内容区不销毁其它内容，所以表达式编辑值、焦点所属输入和各区滚动位置可恢复；模板和参数变化清掉预览。窗口宽度低于 1030 逻辑像素时初始自动收为 64 像素功能条，始终显示“表达式”“参数设计”“设计库”完整标签。用户点击任一功能按钮或按 F4 可在同一窗口展开当前侧栏内容。宽度至少 720 像素时侧栏与层列表并列，侧栏总宽度 384–520 像素（扣除 64 像素功能条后内容为 320–456 像素）；低于 720 像素改用层列表上方、侧栏下方的上下布局，展开时功能按钮横向排列、表单单列滚动，层列表至少保留 200 像素高度。行列按左侧可用宽度计算并裁剪，不得伸入侧栏。F4 只展开/折叠当前侧栏内容，文字按钮用于切换功能。整个膜系页再次创建时使用一致的初始几何，不持久化侧栏尺寸或功能状态。该侧栏不执行另存、覆盖或关闭整页操作。

## 实现真值

数据结构、Python 签名和契约测试为实现真值。核心生成器与目录位于 `coat_sim/core/film_design_templates.py`；session 的原子替换和一次性撤销位于 `coat_sim/core/film_design_session.py`；Quick 参数适配位于 `coat_sim/ui/film_quick_controller.py`；侧栏与各功能区位于 `coat_sim/ui/qml/FilmDesignQuick.qml` 和 `FilmDesignGeneratorPanel.qml`。算法来源、公式推导和有说明的图解见 [离线算法文档](algorithms.html)，用户操作说明见 [生成器指南](film-design-generator-guide.md)。

## 物理结构分支（2026-10-20）

原侧栏的模式选择在“经典参数模板”和“物理结构与组合段”之间切换；经典模板行为不变。`film_physical_generator.py`只将表单参数转换为既有`FilmStructureSpec`，目录与默认值为本项目交互约定，不新增光学公式。`FilmPhysicalGeneratorForm.qml`、`FilmPhysicalSectionEditor.qml`、`FilmPhysicalFields.qml`呈现可编辑结构段、次序与真实材料/数据集角色，调用`previewPhysicalStructure(inputs)`；会话`preview_physical_structure(inputs)`复用同一预览token、revision、provider守卫和应用/撤销入口。

环境来自当前设计：保留真实介质/基片/参考波长，在单面front的替换预览副本中展开正面层表。双面、back入射、禁用k或无损假设等不支持环境明确报错；未知k和数据域不足拒绝，不从经典模板无损复选框继承许可。输入变化或预览错误使旧预览失效；确认应用前不修改文档。完整逐层nm处方并不代表目标通过。角色、结构公式、支持范围及出处见[结构契约](film-physical-structures-contract.md)和[14u](algorithms.html#film-physical-structures-20261020)。

加载/空材料/失败状态、Theme逻辑尺寸、现有侧栏焦点和滚动约定继续生效；没有新窗口和几何例外。纯核心、会话与真实Qt验收分别见`test_film_physical_structures.py`、`test_film_physical_generator_session.py`、`test_film_physical_generator_frozen_apply.py`和`test_film_synthesis_gui_review.py`。操作见[GUI指南](film-synthesis-gui-guide.md)。

## 两膜料交互修复（2026-10-20）

内部用途ID `role`不是不同材料数量。表单默认只有H/L，显示高/低折射率膜料和真实材料名，腔层默认复用H，可改L；额外C/M1等只在需要独立用料时添加。不同用途允许相同material_id/optical_set_id。旧显式C保持可用，核心真实nH>nL和k/波段检查不变。GUI预览只提交当前结构实际引用用途，未用的附加用料不因缺集/越域阻断当前结构；真正引用的缺项明确失败。`physical_required_material_uses`遍历当前段、独立端镜、腔和耦合镜，材料服务仍由当前会话提供。默认腔C→H及用料过滤为本项目交互约定，不新增物理算法或证明。

字段以nm、rad、无量纲及整数标注，光学厚度0.25/0.5的说明分别为四分之一/半波长。真实两膜料预览、确认替换和撤销，以及同材料不同数据集合法、同实际n被核心拒绝，见`test_film_physical_generator_usability.py`和`test_film_synthesis_gui_usability_review.py`。
