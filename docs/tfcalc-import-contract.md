# TFCalc 明文层表导入插件契约

日期：2026-10-14

## 已有扩展点与最小扩展

`PluginRegistry` 原本是可信 callable 的显式、版本化注册器，只有
`source_sampler`、`analysis`、`exporter`，没有自动发现、安装或插件管理页面。
本功能复用它，增加 `film_importer` 类别和显式启停；宿主登记内置
`tfcalc_plaintext` v1。禁用后调用拒绝，不卸载模块，不中断已完成的解析。
不自动扫描或执行第三方代码。
可信标记只接受 `trusted is True`；API 版本只接受严格整数 1，启停值只接受
bool，不把字符串 `"false"`、整数 1 或版本 1.0 当作相应授权/版本。

## 输入、输出及支持范围

插件输入为用户选择的 `.tfd` UTF-8/ASCII 明文（最多 2 MiB），输出不可变的
结构化层表、原始环境/表达式记录及未解释字段报告。只支持 `VERSION*1*`、
星号分隔并以星号结束的记录，首记录 VERSION、末记录 EOF；声明层数必须
和连续 1 基层号匹配，第二面层表单独处理。二进制、未知版本、截断、重复
关键记录、非法数字、零/负厚度、超限、层数不符均拒绝。不会执行表达式。

结构依据仅为用户合法提供的明文记录，不依赖复制厂商软件、库、手册或
样例。没有外部格式语义依据：本项目仅识别 LAYER 的层号、名称引用及两列
数值。用户已确认本次合法提供的 VERSION 1 profile 为第二数值=物理 nm、
层序从基片向外；UI 对该受限 profile 可见地采用此默认。此依据不是厂商
通用格式规范，不声称覆盖所有 TFCalc 版本/文件；其他文件须核对预览，
高级映射可改数值列、单位 nm/um 和源层序。字段编号不计 `LAYER` 标签：
`LAYER*层号*名称*第一数值*第二数值*…`，选项 3/4 对应数值数组索引 0/1。
不推断面标记或 ENVIRON 各列角色。用户必须选择目标面 front/back，并确认
参考波长及沿用当前
文档的基片、介质、入射面、光学开关和工作流设置。第二层表只有在明确
选择源表后导入，不猜测正背面。ENVIRON、尾部 flag、TARGETS、PLOT 等
只保留在预览报告，不导入模拟设置。不从未知 flag 推断无吸收或 use_k。

材料名称仅是别名。每个选中层表的别名必须显式绑定已有材料及其确属该
材料的 optical_set_id；不按名称匹配、不补造 n/k。保存的显式层表是唯一
导入真值，FORMULA/FORMULA2 仅作为原始参考写入备注，不能用于重建膜层。
当前文档已有 expression.text/symbols 保留，只标记 in_sync=False；不会因
导入另一面而丢掉原表达式草稿，也不会执行旧草稿重建导入层表。
每层使用新的稳定 ID，厚度写入项目物理单位，不由 QW 或新材料 n 换算。

## 所有权、确认、取消和同步

`FilmDesignService` 所有其注册器，插件只读解析；Quick 控制器所有临时解析
预览、令牌和输入 epoch。预览不修改 session。输入改变、文件重开、禁用、
取消、文档修订或关闭都会使旧预览不能提交。解析是有界同步只读操作，
没有后台写回；若以后异步化，须增加 token/revision/关闭检查，不能把旧
结果直接应用。

`FilmDesignEditSession` 仍是设计及 pending confirmation 的唯一所有者。
提交接口先验证候选及基础 design_revision，再建立显式替换确认，确认前
文档、路径、dirty、配对仿真不变。确认时再次核查基础修订；冲突、取消或
错误不部分改动。成功只替换选中面层表、标记未保存、清除旧文件路径，发出
一次设计通知，配对仿真沿用同一 session 自动同步并使旧结果失效。另一面
层记录及所有明确沿用的设置保留。参考波长默认沿用当前值；若用户修改，
它是文档全局值，会改变保留面 QW 层的物理厚度（nm/um 层不变），UI 明示
此影响。导入不会保存或改写 `.tfd`、不会覆盖 `.cfilm`。

UI 复用膜系设计窗口的打开入口（`.cfilm`/`.tfd` filter），导入对话框使用
共享 Theme 控件。预览明确显示加载成功/空层表/失败和未解释报告；禁用操作
只作用于该 service 的内置导入插件，不表示完整插件市场或第三方安装管理。

## 验证边界

公开测试只用本项目合成文本，绝不包含用户实际层表。覆盖 registry
信任/版本/启停、解析拒绝、两层表、材料所属检查、列/单位/层序明确选择、
原文件不变、预览隔离、取消/冲突/关闭/重复打开、未保存确认和共享同步。
实际私有文件验收只报告解析结构及保护结论，不提交文件或真实配方数值。
