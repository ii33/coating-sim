# 工程资源操作栏

本文描述统一资源操作栏。按钮共享实现，各工程的当前资源、草稿和保存状态仍互相隔离。

## 打开、新建和保存

- **窗口菜单**切换当前工程中的功能窗口；**资源下拉列表**选择当前窗口对应类型的工程资源，两者用途不同。
- **新建**创建当前类型的未保存草稿。切换资源或新建前，若已有修改，先选择保存、放弃或取消。
- **保存**写回当前工程。新草稿首次保存获得工程资源身份，之后保存更新同一资源；名称不等于文件名，不需要通过改文件名重命名。
- 膜系设计、优化和光谱仿真采用同一工程膜系及其配置。光追、外观的输入配置与计算结果分别管理，保存输入不等于导出结果。
- 处理较大的输入依赖时会显示进行中状态。保存成功后才继续待执行的资源切换；失败保留草稿。已开始提交的写入不能被“取消”伪装成未发生。

## 信息

点击 **信息** 查看名称、概述、备注，点击 **编辑** 后修改。确认编辑只更新草稿，仍需普通保存写入工程；取消不更改资源。

信息以纯文本显示，保留换行。长备注可以滚动查看。异常恢复保留未确认的编辑内容为待确认状态；恢复出的未保存副本仍需明确保存，不会自动覆盖原件。

## 导入与导出

从 **导入/导出** 选择操作方向，再选择全局资源库或浏览文件。

- 设计器仅列出、选择和传输该窗口对应类型的根资源；工程包和工程描述文件也按同一范围筛选。后端拒绝错类型选择，依赖仍自动复制。
- 通用全局/工程资产库按当前分类操作，材料档案与光学投影统一为“材料”；独立光学记录仍可访问和编辑。
- 独立资源文件按其实际类型读取。
- 工程描述文件使用任意名称的 `.coatproj`，内容仍为 JSON；工程包使用 `.cproject`。
- 选择工程描述文件或工程包后，可按分类和资源条目选择。预览会列出自动带入的依赖以及冲突。
- 外部资源及必要依赖复制进目标工程。导入后不依赖原文件继续存在，也不与原工程共享可修改的数据。
- 冲突必须明确选择处理方式。复制生成独立身份，替换影响预览标出的目标资源，跳过必要依赖也会跳过依赖它的所选资源；不会留下断开的引用。
- 导出到另一个工程保留其无关资源和默认工艺配置。导出新工程包不会默认包含所有计算结果，但输入配置明确引用的沉积资产属于必要依赖。
- 全局导出按既有资源库的类型和存储能力处理。跨多种存储的操作不会假装成一个不可失败的事务；不支持的组合会给出明确说明，不能静默只导出一部分。

浏览、预览或取消不保存当前草稿，也不会导入全部全局材料。工程材料编辑遵循只在实际编辑或依赖使用时写入工程的规则。

## 输入操作

可编辑输入框每次新获得焦点时默认全选，输入直接替换；已聚焦时再次点击或拖动可以定位光标、局部选择。单行输入在校验通过后按 Enter 提交并失焦，点击其他位置也会失焦。表格保持同列 Enter 导航，多行表达式及聊天保持原有换行或发送语义。

资产库复用同一行主操作栏：分类选择器后紧邻信息入口，导入/导出菜单集中承载文件和全局/工程复制操作，放不下的操作折叠到末尾“…”；嵌入材料编辑器不重复显示资产操作栏，保存、信息及材料文件操作保留在主栏。
