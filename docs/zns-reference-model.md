# ZnS 文献数据与条件源通量参考

本页对应内置 ZnS 文献材料及源编辑器的参考计算入口。数据来自已有 T04/T05 研究及其经原件核验的补充。新增功能是**有温域和假设边界的文献参考计算**，不是逐材料机台物理模型已经全部完成，也不是新的工艺膜厚控制模式。

## 三层数据分开

1. **材料证据**：来源、产品/物相、单位、条件、未填项和冲突项。Merck 的 QCM 设置密度 4.09 g/cm³（4090 kg/m³）及 z-ratio 0.775 不等于本机实测膜密度。0.8–2.5 nm/s 是该产品给出的工艺起点，不是根据输入功率算出的源率。各来源 n 数据保留波长与来源，不平均；有冲突的 k 和源温隔离展示。
2. **条件热化学参考**：厂家压力内插，以及窄温域 Zn/S₂ 理想气相平衡和指定边界的单向粒子/质量流。没有把 ZnS 化学式质量作为解离气体物种质量。
3. **既有沉积仿真**：空间角分布、有限源、盖孔、扫描和工艺 target_nm/rate_nm_s 归一化。参考计算不自动修改该工艺速率、源空间权重或最终膜厚。因此不能把计算页的 kg/s 称为已校准沉积 nm/s。

内置文献记录只读。用户可复制到自己的材料库并配置空间模型；文献数据完整副本随材料/源保存，不能无声改写文献系数并仍标为原始引用。旧材料和旧源不含新字段时行为保持原样。

## 厂家压力模式

Umicore IR02 的锚点是 950°C / 10⁻² mbar 与 1070°C / 10⁻¹ mbar，即 1223.15 K / 1 Pa 与 1343.15 K / 10 Pa。

log10(P/Pa) = 11.192916666666672 − 13690.616020833342 / T

这是对两点的工程内插，**只允许 1223.15–1343.15 K**。厂家未说明它是总压、等效压还是某物种分压；本模式只输出压力参考，禁止直接传给 Zn/S₂ HK。温域外不外推，不将斜率冒充可靠解离焓，不与另一来源拼接。

## RI8301 气相模式

Schaefer，Bureau of Mines RI8301（1978），印刷 p.12 / PDF 第16页：

Zn(g) + ½ S₂(g) → ZnS(sphalerite)

ΔGf° = −92.720 + 0.04817 T，单位 kcal/mol，**1180–1210 K**，原文误差 ±0.650 kcal/mol，压力标准态 1 atm = 101325 Pa。948–1180 K 的另一条式子包含 Zn(l)，不能替代这条气相式子。

先乘 4184 转为 J/mol。对纯固相活度1、同温、理想且仅含 Zn/S₂ 两物种的假设：

Kd = exp(ΔGf° / RT)

Kd = (pZn/p°) (pS₂/p°)^(1/2)

给定 r = pZn/pS₂ > 0：pS₂ = p°(Kd/r)^(2/3)，pZn = r pS₂。

### 闭合方式不能混用

- **封闭化学计量理想气体**：r=2，只输出封闭平衡压力。分子撞击不是净逸出，不能由此计算封闭容器的净质量损失。
- **明确指定压力比**：由用户提供 r。有效逸出系数 α 明确时可算传输前的一侧参考流；α 与传输系数 τ 均明确时才算传输后参考流。未知阶段保持未知，不隐藏已具备条件的前级结果。
- **条件化学计量出口**：规定 ΓZn=2ΓS₂。若 fi=αiτi 为有效出口系数，则 r=2(fS₂/fZn)√(MZn/MS₂)。fi 必须正且有限；零系数时该比值闭合未定义。
- **显式理想小孔逸出**：用户明确选择后，声明 α=τ=1，r=2√(MZn/MS₂)。这是所选理想假设，不是测得的开放 ZnS 升华系数，也不是任意盖舟的真实透射。

α 在条件出口模式中是给定的有效逸出系数。若要把它解释成真实开放料面的反应升华系数，必须另有气相生成、回凝、壁面和压力平衡模型；本版未求解这些机制。

### 物种与元素流

使用 MZn=0.06538、MS₂=0.06412 kg/mol，mi=Mi/NA：

Γi = αi pi / √(2πmi kB T)，出口通量再乘 τi

ji = Γi Mi / NA，单位 kg/(m²·s)

S 原子通量是 2ΓS₂；Zn 原子通量是 ΓZn。总质量必须同时等于按物种求和与按元素求和。输出保留传输前后值，避免把被截留部分重新归一化。

这些是一侧参考流，缺少反向气体温度/分压、壁面再发射和基片留存时，不计算净成膜。

### 面积

总参考率 Q=jA 仅适用于所选均温边界。理想小孔和条件出口使用**用户明确输入的出口/孔口面积**，不能用装料面积替代。只有明确指定压力比的一侧均温表面情景可选源几何面积；它使用圆盘、圆环或矩形的实际几何面积，不把经验 active_fraction、高斯 σ 或扫描区自动当真实热发射面积。点/线源没有可推导的物理面积，需要明确输入。

带盖/挡板箱的 τ 不从开孔图形自动推断；现有逐射线遮挡仍服务于空间沉积模型，不自动构成总分子传输/再发射解。

### 误差敏感性

固定 T、r 和出口系数时，原文 ΔG 误差对应乘数：

F = exp[(2/3) × 0.650 × 4184 / (RT)]

压力及相应通量区间为中心值/F 至中心值×F。1200 K 时 F≈1.199276。它仅传播这一个报告误差，未含温度、物种、相态、α、τ 或几何误差；不是统计置信区间或机台总误差界。

## 数值核对示例

1200 K 的显式理想小孔两物种情景：Kd≈4.3757793×10⁻⁷，pS₂≈3.6552444 Pa，pZn≈7.3819673 Pa，总质量通量≈0.0112354193 kg/(m²·s)，Zn/S 原子流比=1。此例是方程与单位核对，不是机台验证或操作设定建议。

## 仍未实现

ZnS 开放表面的可靠 α(T)、粉床热容/导热/接触热阻、功率到温度、舟内温度分布、电子束热PDE、实际扫描热响应、盖舟多次壁面碰撞/再发射、其他气相物种、动态库存、基片反应留存及真实沉积率耦合仍未实现。其他材料也不能仅因可新建记录而被称为已有专属验证模型。
