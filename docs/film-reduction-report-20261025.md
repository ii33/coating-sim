# 独立膜系减层 / 减厚实施与验证

日期：2026-10-25。候选基于当前 `48e8fc624f59876fc447668ebb43a3de7904ceab`，在 Sakuya 的独立任务 checkout 实现。本阶段不发布，不改固定运行副本，不写入用户工程。

## 实际行为与代码位置

- `coat_sim/core/film_reduction.py`：独立冻结请求/结果、完整原网格与加密网格基线、受约束删除/合并、复用 `optimize_film_design` 的存活层有界光谱修复、减厚坐标搜索、可行性与减量资格、真实预算及取消。
- `coat_sim/core/film_optimization_job.py` 与 `coat_sim/scheduler/{worker,result_capability,remote_contract}.py`：复用现有 `film_optimization` executor，识别独立请求/结果及持久候选，绑定完整请求，保留实时取消回包；历史恢复继续独立物理重放。
- `coat_sim/ui/film_optimization_quick_controller.py`、`film_quick_controller.py` 与 `qml/{FilmDesignQuick,FilmOptimizationWindow}.qml`：独立入口、三模式、配置持久化、队列、比较、显式应用和现有原子撤销。应用只做来源/材料/拓扑检查，不在 GUI 线程重复运行光谱。

减层先产生删除/合并拓扑，再复用现有有界厚度优化修复所选存活层。光学可行性是完整原目标及同一加密网格的硬门槛，不与层数或总厚度组成任意加权和。减层必须严格降低层数，允许总厚度增加；减厚保持拓扑且严格降低总厚；联合必须层数和总厚相对源设计均不增加、至少一项严格降低。未达标源设计的状态明确保留，不放宽目标。

只有所选变量下界为 0 的层允许删除。未选层固定；正下界层必须存在且可按所选变量原边界修复。合并要求确切的材料 ID 与光学数据集 ID 相同、参与层允许删除且保留层符合原边界。所有其他设计字段、介质、基片、正反面、角度/偏振保持冻结。纯减层没有可删层时 UI 提前拒绝启动。

## 真实光学示例

合成无损常折射率材料：基片 n=1.5、低折射率膜 n=1.2、高折射率膜 n=2.1，k=0。目标为 540–560 nm、0°、s 偏振 R∈[0.015,0.022]。原网格为 540/550/560 nm，独立网格为 540/545/550/555/560 nm；这些有限网格不构成连续谱或制造鲁棒性证明。

| 状态 | 层数 | 总厚度 nm | R 范围 | 原网格 / 加密最大归一化违规 |
|---|---:|---:|---|---|
| 原设计：低折射率 40 nm + 高折射率 5 nm | 2 | 45 | 0.01586958–0.01712692 | 0 / 0 |
| 直接删去高折射率层，未经修复 | 1 | 40 | 0.0292045–0.02989402 | 0.00789401747 / 0.00789401747 |
| 有界修复后：低折射率 60 nm | 1 | 60 | 0.0185357–0.0197196 | 0 / 0 |

存活层原厚度下界 40 nm、上界 200 nm；没有改变材料。减层模式正确报告减 1 层、总厚增加 15 nm。相同源设计与目标的联合模式保留 2 层 / 45 nm，不把该增厚结果称作联合减量。

该减层任务的 6 次完整网格评估包含全部内层修复正向工作：源设计训练和独立网格各 1 次，内层训练 3 次（存活层 40/50/60 nm），内层最终独立网格 1 次。实际记录 6 次 `simulate` 调用，终态额外回放 0 次。此例只有一个目标、一个角度，每个网格为一次 `simulate` 调用；多目标、多角度或波长分块时一个完整网格包含多次正向调用，不能把网格次数解释成逐波长物理运算量。说明用的直接删除额外复核为 2 次，另行披露，不计作上述减层任务的一部分；单独联合任务为 16 次完整网格 / 5 次独立网格。完整冻结请求、逐条件原始数据、结果、逐次前向调用及计数保存在 `artifacts/reduction/numerical-example.json`。
