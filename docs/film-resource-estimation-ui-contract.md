# 膜系资源评估侧栏契约

资源评估位于膜系设计窗口 F4 侧栏，不属于优化设置页。设计会话仍是设计及目标配置的唯一所有者；评估控制器只在启动时读取不可变副本，并持有该次运行的状态与结果。指标、物理面、基片、未知 k 策略及工艺参数来自现有优化/合成配置；候选材料由评估控制器独立持有当前设计会话的内存草稿，关闭设计后不持久化，不改动合成配置或膜层。材料目录按膜料用途枚举，允许添加、删除、排序及选择数据集；空、重复、缺失或已移除的数据集明确报错且不得回填当前膜系。启动时冻结草稿，复核沿用同一快照，编辑使旧结果过期。无目标配置时提示用户进入现有目标设置。评估不得启动主优化、写回设计、变更优化约束或应用结构。

开始后在工作线程准备和计算，界面展示阶段、工作量与来源版本；取消是协作式请求，并非硬实时中断。运行结束前不可重复启动，结束或取消后可再次运行。设计、目标或材料等来源变化应将原结果标注过期，不能当作当前结果；晚到的旧任务不可覆盖新任务。窗口关闭时请求取消，结果归属原窗口。未开始、缺数据、不可用、取消、异常与成功均有独立状态。

显示冻结的材料、指标、选面、固定面环境和假设；条件数值必要界明确标识为非严格证书，每个推荐节点逐项显示其未知 k=0 条件及受影响材料（条件未知时不得称无条件），并标注有限采样审计不是连续域或实测吸收/制造良率证书；冻结开始次数与完成次数分开记账，UI 来源复核额外冻结另列，不并入核心账本；未实现的预测标为 unknown，不显示未经校准的概率。现有单层最小非零厚度及单层最大厚度作为工艺条件沿用；优化搜索的总层数/总厚度帽不作为评估资源帽。制造良率未评估。用户调整的下界枚举上限仅为评估工作量范围，绝不写入优化约束；超过枚举范围时只能报告 unknown，不能当作全局不可行。
