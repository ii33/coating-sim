# 膜系资源评估优化算法页契约

资源评估位于膜系优化窗口的算法选项，复用开始/取消生命周期；它是只读评估，不产生可应用的优化候选，切换算法后共享应用按钮不得应用其他算法的陈旧候选。设计会话仍是设计及目标配置的唯一所有者；评估控制器只在启动时读取不可变副本，并持有该次运行的状态与结果。指标来自优化编辑器启动时已确认的当前草稿；物理面、未知 k 策略及工艺参数来自现有优化/合成配置。基片材料和数据集由评估控制器独立持有，初始取当前设计，编辑不写回设计或合成配置；启动时与候选材料一起冻结并用于全部候选审计。候选材料由评估控制器独立持有当前设计会话的内存草稿，关闭设计后不持久化，不改动合成配置或膜层。材料目录按膜料用途枚举，允许添加、删除、排序及选择数据集；空、重复、缺失或已移除的数据集明确报错且不得回填当前膜系。启动时冻结草稿，复核沿用同一快照，编辑使旧结果过期。无目标配置时提示用户进入现有目标设置。评估不得启动主优化、写回设计、变更优化约束或应用结构。

开始后在工作线程准备和计算，界面展示阶段、工作量与来源版本；取消是协作式请求，并非硬实时中断。运行结束前不可重复启动，结束或取消后可再次运行。设计、目标或材料等来源变化应将原结果标注过期，不能当作当前结果；晚到的旧任务不可覆盖新任务。窗口关闭时请求取消，结果归属原窗口。未开始、缺数据、不可用、取消、异常与成功均有独立状态。

显示冻结的材料、指标、选面、固定面环境和假设；条件数值必要界明确标识为非严格证书，每个推荐节点逐项显示其未知 k=0 条件及受影响材料（条件未知时不得称无条件），并标注有限采样审计不是连续域或实测吸收/制造良率证书；冻结开始次数与完成次数分开记账，UI 来源复核额外冻结另列，不并入核心账本；未实现的预测标为 unknown，不显示未经校准的概率。现有单层最小非零厚度及单层最大厚度作为工艺条件沿用；优化搜索的总层数/总厚度帽不作为评估资源帽。制造良率未评估。用户调整的下界枚举上限仅为评估工作量范围，绝不写入优化约束；超过枚举范围时只能报告 unknown，不能当作全局不可行。

普通结果区使用材料名称、单位及明确状态展示必要界、当前候选审计和有限证据；未计算、不适用和未找到可行见证应区分，不得把 unknown 描述成不可能。散列、原始数据和工作计数仅放在可展开的技术详情中。评估结果不得启用结构应用。

启用进一步验证时，通用试探设置由评估控制器拥有并随请求冻结：每种子评价上限（含审计）默认 256，随机种子默认 0、1，范围沿用原生求解器的 0–4294967295；上限为 0 表示仅预检和当前候选审计，不是无限预算；启用搜索时至少为 2。此上限不是所有种子合计上限，也不是层数或总厚度的硬帽。界面分别展示实际逻辑评价与物理光谱调用、当前阶段和种子；有限搜索未找到见证不等于证明无解。通过原始目标审计的见证以层数与厚度成对呈现，未通过的近优候选不得混入可行 Pareto。统计明细可在技术详情查看，未校准预测仍为未知。进一步验证的参数无效时拒绝启动该模式；编辑、来源变化和取消沿用本契约的过期及代次边界。

## 快速评估与进一步验证

默认关闭“进一步验证（合成探测）”：控制器显式冻结 `probe_max_evaluations=0`、`audit_candidates=False`，不启动合成探测或独立密网格候选审计。快速模式仍可计算适用的条件必要界；未校准的通用层数和厚度预测为未知，不得伪造区间或把必要界、审计实例称为最小值。启用进一步验证后，使用用户编辑的每种子预算和种子，显式设置 `audit_candidates=True`；预算默认 256、种子默认 0、1，零预算仅关闭合成探测，不关闭当前候选审计。该模式可能与自动合成的计算量接近。预算与种子的草稿错误仅阻止进一步验证，不能阻止快速模式；两模式采用同一个开始/取消操作。控制器是模式和草稿唯一所有者，运行中禁止改变模式及选项；切换模式使旧结果过期。结果应分别标识条件必要界、未经校准的未知预测、以及（仅有时）有限采样审计实例。
