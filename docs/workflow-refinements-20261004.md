# 设计器、材料与队列改进验证

完成验证日期：2026-10-05（2026-10-04 请求批次）。基于产品版本 `83392021d6bea2700b58f68aba907bd5a9f1915a`，保留此前 Pipe109 通信修复。本轮发布状态以 GitHub 对应提交的远程校验结果为准。

## 功能与兼容性

- 已完成队列结果可重开；读取保存的结果，不重算；新请求覆盖旧加载，渲染失败不会把旧热图标成新结果
- 源、基片、修正板、机器、工艺分别默认 `.csrc`、`.csub`、`.cmsk`、`.cmac`、`.cproc`；保留显式旧 JSON；设计器、依赖、队列快照及 `.coatasset` 往返经过检查
- 覆盖保存需要明确确认；不同类型或损坏目标不覆盖，须选择另一个名称；没有自动改名或删除旧文件
- 取消最大网格501，保留整数与最小21；显示内存粗估；CPU/非CPU仿真和修正板优化使用独立计算进程，保留错误和输入，资源不足不重试
- 原传统源更名“简单快速模型”；“源类型/发射模型”置顶，去除重复设备类型选择；旧坩埚配置仍兼容
- 多孔厚盖按同一孔的两平面判断，孔并集不重复计数；源采样精度可独立调整，旧默认数值行为保留
- 统一膜层用语；PDF默认建议摘要文件名，工艺摘要每层一行，分页重复表头
- 材料选择与参考内容后台加载，关闭/切换不会回写旧结果；参考证据收纳到详情按钮，原有证据不删除；隐藏旧ZnS参考计算入口而保留旧配置
- 膜料、基片及其他用途分类明确；源只绑定膜料，基片有自己的材料入口及完整快照
- 每种材料可有多组具名/带备注的离散n/k或Cauchy、Sellmeier数据；明确单位/系数/波段，拒绝非有限值、奇点与外推；缺少k保留未知
- 工艺温度、气体和真空继续按层继承/覆盖；关闭输运隐藏相应参数且保留原值

## 物理解释

有限源原本已有几何半影。旧默认少量源节点可能造成分段几何面，单独加密接收网格不能补足源积分；应分别做源采样与接收网格收敛比较。源角向cosⁿ与面内高斯权重属于不同维度，不互斥。本文及界面不宣称模拟已复现实机花瓣纹。

详细公式、坐标、单位、图解及适用范围见 [算法图解](algorithms.html)。光学常数是可保存/求值的用户材料数据，当前不自动改变沉积速率或膜厚模型。
