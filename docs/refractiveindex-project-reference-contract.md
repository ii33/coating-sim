# 工程内按需使用折射率来源

工程资产库仍以只读分页索引浏览完整离线来源。选择已支持的单个数据块时，后台读取并校验快照 ID 与源文件摘要，生成附带完整来源、缺失项和警告的会话材料；工程膜系会话是唯一所有者。切换来源、条目或关闭浏览器使未完成的读取失效，失败不写磁盘、不改变草稿。会话引用数量和字节数受限，冲突不会覆盖项目或全局材料。

膜系和优化器沿用工程材料选择器；只有实际引用的光学数据随膜系保存至工程，离线重开不依赖数据库。未选择或未保存的会话引用不持久化。n₂、只有 k、无效或暂不能转换的记录仍可查看来源，不能冒充完整线性材料。缺失 k 不代表实测零吸收；原有计算的零值假设和警告语义保持不变，来源与缺失信息随记录保存。工程现有文件大小及文档数量限制不变。

工程资产库可切换到只读全局目录，再通过已有预览、冲突决策及确认路径复制；来源切换清除选择和预览，保留未提交编辑草稿。删除和编辑只针对项目目录；同 ID 时膜系选择器优先使用工程材料。目录读取失败不会修改任何来源。
