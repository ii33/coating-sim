本文仅保留历史开发阶段的技术范围与验证边界，不提供私人执行记录。历史测试数量、性能数字与环境不代表当前公开提交的 CI 结果；当前验证应以公开仓库对应提交的实际运行结果为准。

## 原始来源与许可核对

- [COMSOL 6.4官方教程](https://doc.comsol.com/6.4/doc/com.comsol.help.models.roptics.antireflective_coating_multilayer/antireflective_coating_multilayer.html)：λ₀=550nm，空气1/基片1.5；MgF₂1.38、CeF₃1.63、ZrO₂2.2及Q/Q、Q/H/Q层序。发布日期未标，核对日2026-10-11。400–800nm是教程扫描区间，不是材料数据有效域。
- [TFCalc/Hulinks官方13层表](https://www.hulinks.co.jp/en/tfcalc/examples/list-of-coating-design/growing-antireflection/)：从官方设计目录链接成功读取原表。第一层靠Ge基片，厚度单位nm，H=Ge4.2/L=ZnS2.2，Ge基片4.0，参考10000nm、目标7700–12300nm。版本/发布日期未标，核对日2026-10-11。空气1、正入射、k=0另标本项目复算假设。

只独立结构化公式与数值事实并编写本项目说明，没有复制论文/教程正文、图片、软件模型、TFD、专有代码或未许可数据库。公开网页未核得开放许可，不声称原内容获准再分发。原始网页是来源依据。

## 历史独立数值对照

- 三个COMSOL名义模型各81个固定nm扫谱点，共243点；独立特征矩阵对照既有散射递推。理想单层中心R≈0，Q/Q与Q/H/Q中心R≈0.00131190193。
- TFCalc原13层合计10263.39nm，7700–12300nm扫描20001点。201个等距样本加该离散最坏点经独立矩阵对照，最高R≈0.897930613%，最坏样本11369.19nm。名义对照最大绝对残差约3.66e-15。这不证明连续带宽、收敛或实际映射性能。
- 四条目录的原事实、深复制防污染、JSON往返、合法schema及入射→substrate_outward反转通过；真实数据映射164个光谱点保持原物理nm，透明对照最大绝对残差约2.89e-15。故意选择与原名义模型不同的合法材料，中心结果不同，证明确实不继承原指标。
- 真实Ge膜`ri_ge_amotchkina_film`在10000nm的k=0.00498258被保留；ZnS及Ge Burnett n-only数据仅在显式未知k假设下使用。9000–11000nm 61点与独立复数矩阵一致，最大绝对残差约5.77e-15，A在约0.01514–0.01985。N=n+i k、矩阵−i sinδ和端口实功率导纳均单独计算，没有调用生产散射递推作为oracle。
- 缺映射确认、未知条目、缺角色、未知k未确认、数据集归属错误、真实数据不能覆盖IR波长六个负例通过，旧设计/输入/名义目录无副作用。另由核心契约测试覆盖负k、微小非零吸收入射端口拒绝。

这些都是选定数据/模型下的计算证据，不是制造性能、吸收测量或材料映射误差证明；目标全带必须有实际数据覆盖，不能外推凑齐。

## 保存与界面验证边界

验证范围包括预览不改旧设计、取消不写文件、I/O 失败保留草稿、显式保存与 JSON 往返、旧 token 拒绝、设计修订失效、一次撤销及未知 k 的显式处理。合法旧记录不能被新预览替换；应用不是持久化保存。

原生拖动、多 DPI、所有主题、完整 GUI 套件与制造性能不由这些定向记录证明。历史实际材料对照只覆盖 9000–11000 nm，不能扩大为原 7700–12300 nm 全目标带验证。当前目录没有未经核验的边缘/多腔配方，亦不提供一键制造优化。

复现入口：`python tools/verify_film_design_reference_library.py --with-library`、`python tools/verify_film_design_reference_storage.py`。参见 [参考库契约](film-design-reference-library-contract.md)、[初版模板范围](film-design-generator-stage-report-20261011.md)。
