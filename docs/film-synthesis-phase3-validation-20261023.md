# 原门限验收与历史重放修复验收

日期：2026-10-23。本阶段与随后多核调度提交分开；不将阶段通过宣称为全部自动合成目标已解决。

## 实际修复

- 自动合成在完整原训练约束和已完成独审上直接检查原物理门限，`targets_met` 与用户原数值容差的 `solver_acceptable` 分离。显式严格上界采用数学 `<`，不引入epsilon、额外余量或3%特例。
- GUI、CLI、队列及独立敏感性的名义/有限场景标签同步。百分比违规来自实际物理差值，不再混用归一化误差。非终态检查点不可应用，普通优化v1仍拒绝新增独立请求字段。
- 当前及旧历史都必须绑定真实JobSpec、冻结请求和原始源记录，再在后台逐条件物理重放。自洽的三份设计与旧光谱、旧通过标志或展示metadata不能充当物理证据。64项缓存仅保留小型状态及完整源/规范摘要，不保存大量Jacobian副本，不改写历史文件。
- 下拉材料数据菜单继承主题字体；原像素、颜色、tooltip及交互断言保留。工具栏测试按实际对象所有权作用域销毁，避免全局DeferredDelete误删无关对象，未改变产品渲染或硬件加速。
