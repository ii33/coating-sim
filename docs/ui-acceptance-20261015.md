# UI 验证范围与历史结果边界

历史开发记录：本页的运行数字与环境仅说明当时的限定验证，不代表当前公开提交通过 CI；原始私有执行记录未随公开源码发布。

本文仅保留历史开发阶段的技术范围与验证边界，不提供私人执行记录。历史测试数量、性能数字与环境不代表当前公开提交的 CI 结果；当前验证应以公开仓库对应提交的实际运行结果为准。

公开源码不包含开发环境的私有 CI 链接、提交对照、主机标识或原始运行日志。本文不声明任何当前公开提交已经通过验证。

## 应验证的行为

- 正常启动、首次字体注册、工程打开/关闭和进程退出。
- 工程与全局资源的范围隔离，材料/文件编辑器的真实就绪状态。
- 窄窗口、长文本、焦点、滚动、主题与 DPI 行为。
- 重复创建/关闭窗口、异步取消、旧结果拒绝，以及长序列原生生命周期。
- Windows 原生交互与离屏 Qt 测试分开记录，退出异常不得被中间测试通过数量掩盖。

## 结果解释

历史开发期间曾观察到原生退出崩溃、字体回退及测试夹具就绪竞态。后续定向修复不能自动证明所有平台、长序列或 GPU 后端无问题。测试收集成功不等于执行成功，分片通过不等于单进程完整序列稳定，缺少最终退出状态的运行不能登记为全部通过。

使用 [测试入口](testing.md) 复现；布局和窗口约束见 [共享控件规范](quick-theme-controls.md) 与 [窗口几何策略](window-geometry-policy.md)。
