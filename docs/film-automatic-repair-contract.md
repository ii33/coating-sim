# 自动薄层修复v3：实时阶段改进与取消应用（2026-10-27）

当前界面仍只有单层目标厚度T（nm）、厚度容差dt（nm）和光学指标容差（百分点）三个输入，不新增搜索预算栏。v3将“可应用改进”“厚度全部修好”“原指标达标”和“局部收敛”分开；下面的v2算法保留为旧请求/历史兼容说明，不作为当前入口的应用门槛。

## 光学安全与改进排序

本轮源设计、材料内容、目标、比较设置始终冻结，不随冠军变化滚动更新。原曲线差仍逐波长、角度、偏振、R/T配对，最大绝对差不得超过用户容差；零容差仍严格为零。保留原材料插值/外推政策、原生物理约束和既有有效入射模型，不以均值抵消峰违规。

已达标的原光学条件必须保持。原来已违规的条件，按同物理点对齐原值，候选违规量不得增加；显式mean仍先按同一固定网格积分后比较其违规，不增加未启用mean。原指标仍失败时必须显示失败和差距，即使该候选相对基线受到保护、可以作为阶段改进应用。

令F=max(0,T−dt)，对非零保留层定义u_i=max(0,F−d_i)/F；精确0表示消层分支，不计作仍需增厚的薄层，F=0时所有不足为0。只在完整物理和光学保护核验通过，且厚度不足前三项(Σu_i,max u_i,薄层数)严格优于原设计后，按(Σu_i,max u_i,薄层数,原目标最坏归一化违规,最大曲线差)字典序选择冠军。Σu不除以当前层数，新增厚层不能稀释缺陷。只有光学改善但厚度不足未改善、原本无需修复、未变或只有劣化时，没有可应用冠军；不以减总厚冒充薄层修复。

例如F=8nm，薄层7→7.5→7.9nm均可成为逐步改进，但仍显示未达到8nm；是否可应用还须完整光学保护证据。F是非零保留层的软修复目标，不是厚层上界或中途应用的物理硬下限。常规局部器对初始薄层使用距F的平方误差，其余层只惩罚低于F的不足，均以F归一化；另为每个待修薄层安排零厚定向局部片，选中层j使用d_j²/F²目标，其余层继续原F软目标，允许其他厚度联动补偿。它与离散删层提案不同，连续厚度变量的真实下界为0，不以float.tiny或显示舍入冒充零。

零厚数值点复用既有 `zero_thickness_layer_ids` 和精确厚度Jacobian，原始0仅是training预览。进入正式候选前必须删除精确0，再仅合并material_id与optical_set_id均相同的相邻层，保留真实ID与合并来源；清理后重新计算完整训练光谱，再按同一规范设计hash完成曲线差与原目标保护独审，不给旧分数重新贴hash。规范化改变拓扑，不能继承原始求解终态的converged标记。若用户明确设置原生最小非零厚度，仅零厚定向片选中的该变量可在训练试探中穿过该下限趋于0；非零未达原生下限的试探不可应用，规范化后全部非零保留层仍严格复验原生最小厚度、最大单层厚度、总厚和层数。合并超过原生上限也必须拒绝，不通过拆分同材行绕过工艺限制。

## 证据、实时变化与传输

当前试探只作实时预览，未经完整独审不能冒充冠军。冠军必须有同一任务、冻结源、候选physical hash绑定的完整训练覆盖、原目标独审及成对差分证据。训练/审计的原指标状态、最大差和最坏物理点分别记录。all_requirements_met仅在厚度全部修好、曲线正式容差及适用原指标全部通过时成立；applicable_improvement允许厚度尚有不足，但不允许越光学保护。

逐层展示原始、当前和最佳厚度及变化。对应依据稳定层ID与source_ids，不按数组行号套用。原始零厚试探标为“待核验消层”；规范化后的删除以来源行的零长度条表示不存在，不伪造仍保留的零厚层；合并及新增均有明确来源标记。`liveTotals` 的current/best物理nm总厚分别从同一被显示候选的完整层表以math.fsum投影，并附current_hash、best_hash、seq与显示模式；未转换QW或缺失数据报未知，真实空设计总厚才是0，不拼接旧帧。各行仅以一条背景条表示当前厚度，共用 `liveBarScaleNm`；刻度上限由本轮原始、当前和最佳厚度共同确定，只扩不缩，下轮重置。应用或终态回看时主显示切到实际完整best的层表、hash和总厚，不能继续把旧未审试探显示为已应用。

复用既有本地CPU执行器、job身份和原子checkpoint。worker持久化有界完整快照，进度广播仅传轻量序号；client按合法job_id和input_digest读取固定job-local快照，校验请求、源指纹、候选hash和单调序号后显示。普通进度压缩继续禁止广播大几何/光谱数组；不新增通用流框架，不允许任意文件路径读取，也不在每帧重跑光学。

## 搜索与取消事务

当前v3没有固定全程秒数、候选数或物理调用数上限，也不继承普通优化页的隐藏总预算。每个局部求解与反馈片仍有限，以保持取消响应；保留物理/内存等资源准入。达到厚度目的、真实邻域耗尽或无有效推进可以明确自然结束，不能把局部驻点、失败或资源停止说成全局无解。轨迹滚动保存并保留累积计数、冠军和必要游标，不因取消总cap而无限积累内存。

当前内部局部片最多80轮；独立光学保护审计失败时，最多反馈8个违规采样点并重求解一次，再独立审计。反馈约束仍比较固定原快照；原本违规条件使用同点原违规包络，不被错误强制为已达标。取消检查位于每次新物理调用前，进度或取消交付不重放历史光学计算。

仅当原设计的原指标训练与独审均名义通过，range内部引导边界才可向内移动m=min(m0,s/2)：m0为下述原有内部小余量，s为冻结源训练及独审在该边界的最小实际余量。原源仍是该引导的可行点；原已违规、value、零宽、0/1端点及零余量边界不强迫改善。完整接受步不因求解器q残差的微小正值被跳过，而要进入真实光学训练/独审门；该门仍使用用户原阈值，不能因求解器success或显示舍入而放宽。

审计入场完整测量本地已持有对象B0并预留工作集Wa。审计内用B0+18×2048×(本次实际新增候选/参考波长点+一完整待交付网格点数)保守计本地持有量，再加max(Wa,下一物理工作集)及每次实时读取的外部所有者字节；正常、异常或取消出口恢复完整对象扫描。18份点所有者沿用既有九记录模型并计成对参考，不是物理或时间上限，也不是OS硬内存保证。该本项目资源模型避免每个标量极值调用前后递归遍历全部已冻结光谱，不免除资源准入。

用户“取消并应用当前改进”先停止搜索，只使用取消前已完整计算的冠军，不在取消后补光学评价。确认终态后沿原整设计应用事务写回一次，刷新层模型、约束和光谱，并可一步撤销。无有效改进、证据不完整或上下文失效时不替换原设计。手动应用当前改进也结束本轮，不要求最优或局部收敛。

来源编辑、pending edit epoch、材料/目标/比较设置改变、项目切换、源关闭或shutdown导致的取消，不能被当作用户应用意图。保留session/controller、revision、edit epoch、项目operation及材料内容全部保护。迟到帧、重复终态、旧任务或程序自身写回回调不得再次覆盖。自然结束保留结果回看和手动应用，取消自动应用不扩展成任意终态自动写回。

## 历史v2算法及请求说明

当前“工艺薄层修复”入口为自动修复，只有三个用户参数。旧手动 A/B 的 v1 请求和历史报告仍可读取；当前 GUI 不提供手选优化层、步长、计算次数、迭代或秒数配置。它是独立修复操作，不改自动合成的局部余量→减薄流程、P1/P2终态身份或结构续接状态。

| 输入 | 单位 | 含义 |
|---|---|---|
| 单层目标厚度 | nm | 与厚度容差共同确定单层下限，不是总膜厚目标 |
| 厚度容差 | nm | 允许薄于目标多少；接受下限 L=max(0,T−δd) |
| 光学指标容差 | 百分点 | 相对本轮原快照对应曲线的逐点最大绝对变化 |

三个输入初次为空。目标厚度为正有限数；两项容差为非负有限数，0有效。不会按显示小数位扩大0容差，也不暗加20 nm等工艺下限。T=10、δd=2时，下限为8 nm；原[100,7,60]应识别7 nm层，100和60 nm不受12 nm上界限制。

自动识别、增厚、删除、合并及插层候选都复用原材料和光学数据闭包。优先把原拓扑薄层最小增厚到L并联动补偿，其后才考虑目标厚度附近和结构变化候选。其他层可联动；所有最终保留层，包括新插入层和合并后层，都重新核对L及已有更严格原生限制。数值近零清理是原光学相位尺度整理，不是此处的工艺厚度容差，不据此删除真实薄层。

本轮原设计、材料内容和比较范围只冻结一次，不随试探更新。光学差为每一对应波长×角度×偏振×R/T的绝对差，再取最大值。50%→51%为1个百分点，内部fraction从0.50到0.51；一正一负的差不得平均抵消。连续两步各变化0.6个百分点、相对原快照累计1.2个百分点，必须被1个百分点容差拒绝。

浮点验收用原值±容差的物理区间比较，避免0.51−0.50的相减舍入将恰好1个百分点误判超限；不额外添加固定epsilon，光学容差为0时必须精确相等。显示最大变化保留真实数值及其百分点单位，不用格式化后的数值替代验收。

有启用目标时比较其原范围和物理分量；原目标只有均值约束时，差分仍覆盖完整曲线逐点比较，不增设均值目标。没有启用目标时，比较范围、采样、角度和偏振来自当前仿真配置或原曲线设置，比较对应R/T；只有缺少现有配置时才复用既有 `simulation_settings()` 默认值，不另设400 nm等范围。此时原目标达标状态为不适用，光学差仍需通过。沿用原有插值及外推政策，包括既有 `endpoint_hold`，不因源数据表范围另加修复限制；既有政策下原曲线真正无法计算时才报告未核验，不能报告零变化。QW源按冻结材料和参考波长换算为物理nm后识别薄层。

核心状态唯一归 `automatic_repair` 所有。UI只持有三项原文草稿和冻结报告；worker通过既有本地CPU executor提交v2作业。协议输入含冻结源、目标/比较范围、材料和三项物理参数；`comparison_settings` 是已有仿真配置的快照，并非第四个用户参数。内部搜索策略在结果中记录，不作为用户设置。v1人工路线不被自动任务的结果重新标注。比较配置变化也使原候选失去应用资格，即使设计修订号未变。

`CurvePair`按精确物理键配对。求解用影子响应z=0.5+(candidate−source)/2，使既有全约束SLSQP可处理差分；差分行与真实原目标行共同进入局部可行性求解，保留所有显式启用的pointwise、mean、权重和归一化，不添加隐藏mean。影子响应及其误差只用于引导，不冒充真实R/T或原目标分数。独立审计新建差分缓存，在稠密、偏移及局部差分极值处成对计算。最终通过必须同时满足全层下限、实际成对最大差，以及所有启用原目标的训练和独立审计；无原目标时该项为不适用。差分通过但原目标失败的候选只能回看，不得成为最佳可应用修复。

搜索采用内部有限片，包含增厚起点、删除薄层/相邻合并、已有删层提案以及原材料插层；每个候选精修全部保留层。版本1内部默认最多32个结构提案、每次局部80轮、2048次物理调用和60秒；继承请求有更小工作/时间额度时取较小值，实际策略随结果记录。这些是本项目工作调度约定，不是用户参数或物理约束；到时或用尽本轮工作只表示本轮未找到/未完成，不表示无解。任何预算或取消后不得补算审计再伪称是取消时结果。已有完整审计候选保留回看。

内部差分引导使用εg=ε−min(0.01ε,10⁻⁵)，正式差分验收仍为ε。原range约束只在非零宽且内部边界b∈(0,1)留最多min(10⁻⁵,10⁻³min(b,1−b),0.01区间宽)的引导余量；value、零宽及物理0/1端点不强套余量。零差分容差仍为0。独立审计失败最多反馈8个违规条件、进行一次局部修复并重审，消耗原工作片而非重置预算；联合通过即结束，不继续盲目删层。训练和审计最坏差、物理点、候选hash、原目标最大违规及实际停止原因分别记录。

结果不自动应用。候选只有通过全部适用原指标的训练及独立审计、匹配的成对差分、全层厚度核验和冻结作业身份验证，才可由用户明确应用。应用继续使用来源session/controller、修订、pending edit epoch、项目代次和材料内容验证，以及原有撤销事务。参数编辑、来源改变、取消意图、迟到/重复结果和只读历史都不能覆盖正在编辑的草稿。再次运行重新冻结当前设计作为新基线，不继承上一轮试探作为本轮基线。

资源和序列化复用既有准入与原子checkpoint机制，只处理已冻结JSON，不引入pickle。报告保留真实停止原因、工作计数、检测层ID、原始目标分数、成对曲线及明确的非连续谱证明标记。实际验证范围和未执行的完整CI以本轮交付manifest为准。
