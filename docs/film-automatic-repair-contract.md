# 三参数自动薄层修复（2026-10-27）

当前“工艺薄层修复”入口为自动修复，只有三个用户参数。旧手动 A/B 的 v1 请求和历史报告仍可读取；当前 GUI 不提供手选优化层、步长、计算次数、迭代或秒数配置。它是独立修复操作，不改自动合成的局部余量→减薄流程、P1/P2终态身份或结构续接状态。

| 输入 | 单位 | 含义 |
|---|---|---|
| 单层目标厚度 | nm | 与厚度容差共同确定单层下限，不是总膜厚目标 |
| 厚度容差 | nm | 允许薄于目标多少；接受下限 L=max(0,T−δd) |
| 光学指标容差 | 百分点 | 相对本轮原快照对应曲线的逐点最大绝对变化 |

三个输入初次为空。目标厚度为正有限数；两项容差为非负有限数，0有效。不会按显示小数位扩大0容差，也不暗加20 nm等工艺下限。T=10、δd=2时，下限为8 nm；原[100,7,60]应识别7 nm层，100和60 nm不受12 nm上界限制。

自动识别、增厚、删除、合并及插层候选都复用原材料和光学数据闭包。优先把原拓扑薄层最小增厚到L并联动补偿，其后才考虑目标厚度附近和结构变化候选。其他层可联动；所有最终保留层，包括新插入层和合并后层，都重新核对L及已有更严格原生限制。数值近零清理是原光学相位尺度整理，不是此处的工艺厚度容差，不据此删除真实薄层。

本轮原设计、材料内容和比较范围只冻结一次，不随试探更新。光学差为每一对应波长×角度×偏振×R/T的绝对差，再取最大值。50%→51%为1个百分点，内部fraction从0.50到0.51；一正一负的差不得平均抵消。连续两步各变化0.6个百分点、相对原快照累计1.2个百分点，必须被1个百分点容差拒绝。

浮点验收用原值±容差的物理区间比较，避免0.51−0.50的相减舍入将恰好1个百分点误判超限；不额外添加固定epsilon，光学容差为0时必须精确相等。显示最大变化保留真实数值及其百分点单位，不用格式化后的数值替代验收。

有启用目标时比较其原范围和物理分量；原目标只有均值约束时，差分仍覆盖完整曲线逐点比较，不增设均值目标。没有启用目标时，比较范围、采样、角度和偏振来自当前仿真配置或原曲线设置，比较对应R/T；只有缺少现有配置时才复用既有 `simulation_settings()` 默认值，不另设400 nm等范围。此时原目标达标状态为不适用，光学差仍需通过。沿用原有插值及外推政策，包括既有 `endpoint_hold`，不因源数据表范围另加修复限制；既有政策下原曲线真正无法计算时才报告未核验，不能报告零变化。QW源按冻结材料和参考波长换算为物理nm后识别薄层。

核心状态唯一归 `automatic_repair` 所有。UI只持有三项原文草稿和冻结报告；worker通过既有本地CPU executor提交v2作业。协议输入含冻结源、目标/比较范围、材料和三项物理参数；`comparison_settings` 是已有仿真配置的快照，并非第四个用户参数。内部搜索策略在结果中记录，不作为用户设置。v1人工路线不被自动任务的结果重新标注。比较配置变化也使原候选失去应用资格，即使设计修订号未变。

`CurvePair`按精确物理键配对。求解用影子响应z=0.5+(candidate−source)/2，使既有全约束SLSQP可处理差分；差分行与真实原目标行共同进入局部可行性求解，保留所有显式启用的pointwise、mean、权重和归一化，不添加隐藏mean。影子响应及其误差只用于引导，不冒充真实R/T或原目标分数。独立审计新建差分缓存，在稠密、偏移及局部差分极值处成对计算。最终通过必须同时满足全层下限、实际成对最大差，以及所有启用原目标的训练和独立审计；无原目标时该项为不适用。差分通过但原目标失败的候选只能回看，不得成为最佳可应用修复。

搜索采用内部有限片，包含增厚起点、删除薄层/相邻合并、已有删层提案以及原材料插层；每个候选精修全部保留层。版本1内部默认最多32个结构提案、每次局部80轮、2048次物理调用和60秒；继承请求有更小工作/时间额度时取较小值，实际策略随结果记录。这些是本项目工作调度约定，不是用户参数或物理约束；到时或用尽本轮工作只表示本轮未找到/未完成，不表示无解。任何预算或取消后不得补算审计再伪称是取消时结果。已有完整审计候选保留回看。

内部差分引导使用εg=ε−min(0.01ε,10⁻⁵)，正式差分验收仍为ε。原range约束只在非零宽且内部边界b∈(0,1)留最多min(10⁻⁵,10⁻³min(b,1−b),0.01区间宽)的引导余量；value、零宽及物理0/1端点不强套余量。零差分容差仍为0。独立审计失败最多反馈8个违规条件、进行一次局部修复并重审，消耗原工作片而非重置预算；联合通过即结束，不继续盲目删层。训练和审计最坏差、物理点、候选hash、原目标最大违规及实际停止原因分别记录。

结果不自动应用。候选只有通过全部适用原指标的训练及独立审计、匹配的成对差分、全层厚度核验和冻结作业身份验证，才可由用户明确应用。应用继续使用来源session/controller、修订、pending edit epoch、项目代次和材料内容验证，以及原有撤销事务。参数编辑、来源改变、取消意图、迟到/重复结果和只读历史都不能覆盖正在编辑的草稿。再次运行重新冻结当前设计作为新基线，不继承上一轮试探作为本轮基线。

资源和序列化复用既有准入与原子checkpoint机制，只处理已冻结JSON，不引入pickle。报告保留真实停止原因、工作计数、检测层ID、原始目标分数、成对曲线及明确的非连续谱证明标记。实际验证范围和未执行的完整CI以本轮交付manifest为准。
