## 先选哪种方法

| 任务 | 首选 | 可换用 | 主要限制 |
| --- | --- | --- | --- |
| 已有层序，小幅调厚；暂不知合理上界 | 基线坐标搜索 | 设定每层真实上界后选 Powell | 基线可能停在局部最优 |
| 少数层耦合明显，已有较好起点 | Powell | Nelder–Mead、TRF、L-BFGS-B | 局部搜索依赖起点 |
| 多峰，怀疑起点不好 | 多起点 Powell 或差分进化 | 模拟退火 | 需要更多完整光谱评估 |
| 单面正面膜系，想快速局部精修 | TRF 或 L-BFGS-B | Powell | 解析导数有明确适用域；代理目标是平方和 |
| 需要增加膜层或变更位置 | 结构搜索 | 独立 needle API | 只尝试指定材料和预算内的结构 |
| 修正板形状/中心需要调整 | 修正板优化 | — | 使用沉积模型评分，结果需复算和实测 |
| 工艺中只想调整公转转速 | 转速局部优化 | — | 只搜索转速倍率，不改修正板和膜系 |

八种固定层序方法均不改变材料、材料光学数据集、层序和未勾选层。它们不会自动删层，也没有“最少层数”目标。零厚度是合法边界；能否实际搜到零由目标、方法、预算和停止阈值决定。

## 开始前：目标、单位和边界

在膜系优化窗口，先选**优化方式**。默认“固定层序”，方法为“基线坐标搜索”。新建目标默认正入射、非偏振、400–700 nm 按请求步长 1 nm 含端点采样，共 301 个波长点，反射率 R 在 0–5% 内；角度请求步长默认 1°，0°–0° 的单角度范围仍只有 1 点。界面的 R/T 目标用 **%**，底层请求与模拟结果用 0–1 功率比例；膜厚与波长用 **nm**，角度用 **°**。单波长可设相同起止波长并取 1 点。所有启用目标**同时生效**：每个目标的每个波长 × 角度点均为一个离散条件；目标权重须为正，默认 1，作为该目标所有点的额外倍率。已明确保存的目标点数或步长保持原设置。

**目标类型**：“目标值”按实际值与目标之差计误差；“范围”仅对越过上下限的部分计误差。每个条件先除以正的归一化尺度。搜索以所有离散点的**加权 RMS** 为目标；默认每个 λ×角度点等权，因此一个目标的总权重质量为“点数 × 用户权重”，不会先求各目标均值再平均。候选排序先保证已达标者优于未达标者，再比较加权 RMS。TRF/L-BFGS-B 对逐点带权残差平方和求局部下降。**达标与搜索分开**：`targets_met` 仍要求每个点的未加权误差不超过容限，增大或缩小权重都不能隐藏违约。默认“达标容限”0.1 **百分点**，对应底层归一化误差 0.001；它不是连续波段的精度证明。角度不另乘 cos 权重，偏振沿用原光学计算。

例如目标 A 有 1 个 λ×角度点，误差 0.1；目标 B 有 2 个波长 × 2 个角度，共 4 点，误差均 0.2。两者默认权重均为 1 时，加权 RMS 为 `√[(0.1² + 4×0.2²)/5] ≈ 0.18439`。把 B 的用户权重设为 2，则为 `√[(0.1² + 8×0.2²)/9] ≈ 0.19149`。两种设置下未加权最大误差都为 0.2，达标判断不变。增加采样点会改变**离散目标**，不能当作连续谱积分精度保证；不同指标仍分别遵守已有的归一化尺度。

默认勾选全部膜层，单层下界 0 nm，上界留空。只有基线法支持当前实现中的空上界；其域为 `d ≥ 下界`。其余七法须给每个被选层输入有限、严格大于下界的上界。这是**当前软件的约束**：SciPy 的 Powell、Nelder–Mead、TRF 等通用接口在其他用法中可能接受无界变量，不能据此认为本程序也支持。上界应根据工艺、总厚度和希望探索的光学周期设定；过宽会浪费评估且增加多峰性。取消勾选的层保持原厚度。四分之一波厚度先按参考波长换成物理 nm 再搜索。

常用控制：最大迭代数默认 200、搜索评估数默认 1000、随机种子 0、留出验证倍率 2；多起点 Powell 默认 4 个起点，差分进化群体大小默认 12（至少 5）。迭代与评估均是上限，不保证搜索必然用完。留出验证另计评估，在波长相邻点间加密，**不会自动增加角度**。达到训练容限、步幅变小、预算耗尽、取消或方法自身收敛都可能结束；须看结果的终止原因、评估数、失败数及留出结果。

### 可复现的小例子

建一个单面膜系：基板与单层的常数实折射率分别取 1.5、1.23，单层初厚 100 nm；这是**合成测试材料**，只用于演示，不能代替有来源的真实材料。给该层 0 nm 下界、上界留空；设 500–600 nm 共 7 个波长的 R 目标为同一基板**移除该层**后的计算 R，目标值按各波长分别输入（程序支持多个目标），并把达标容限设得足够严格。这是检验冗余层退到 0 的小型数值实验，而非通用镀膜配方。对应可执行验收在 `tests/test_film_zero_thickness_and_precision.py::test_redundant_layer_reaches_zero_without_deleting_its_id`，测试用空上界的默认基线，从 100 nm 找到 0 nm，并在 7 点比较 R/T/A。实际材料应先核验 n、k 的来源、波段和适用条件。

## 固定层序的八种膜厚方法

### 1. 基线坐标搜索 `baseline`

**原理与用法。** 从当前厚度出发，逐层往负、正方向试探，保留改善候选。所有上界均有限时，先对每个变量在闭区间含端点取 17 点粗扫，再做归一化坐标试探；一轮没有改善时步长减半。只要有空上界，改用物理 nm 坐标：以 `max(当前厚度−下界, 参考波长/4) × 0.25` 为初步幅，改善后该轴步幅加倍，否则减半；负向试探会夹到下界，正向没有虚构的厚度上限。最小步幅比例默认 `1e−4`。

**适合**少量变量、需要可解释的默认搜索，或暂无法确定上界。**避免**用它证明全局最优；强耦合层可能需要组合方向，17 点粗扫也会漏掉窄谷。空上界不代表无限计算：仍受预算、停止阈值与物理模型有效性限制。代码在 `coat_sim/core/film_optimization.py`。

### 2. Powell 方向集 `powell`

无导数局部搜索，沿单层和组合方向作一维线搜索。适合已有合理初始膜系、多个层厚联动精修；多峰时可能停错谷，线搜索可耗费多次光谱计算。当前实现先把每层有限厚度区间映射到 `[0,1]`，所以所有选中层都必须有有限上界。依赖 SciPy；设置小而可信的工艺范围，必要时换起点比较。见 [SciPy Powell](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-powell.html) 与 `coat_sim/core/film_optimization_solvers.py`。

### 3. Nelder–Mead 单纯形 `nelder_mead`

以初始候选附近的单纯形反射、扩展、收缩，免解析导数。适合少量变量和非光滑或导数不可靠的局部探索。维数多时顶点与评估开销增加，边界裁剪可能使单纯形退化；本实现也要求有限上界。可与 Powell 对照，不把小预算内的停机视为最优。见 [SciPy Nelder–Mead](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-neldermead.html)。

### 4. 多起点 Powell `multistart`

先从当前厚度启动，再用种子生成其余区间内起点，逐个运行 Powell。默认 4 个起点，**共享**本次迭代与评估预算；起点增多而预算不变会缩短每次精修。适合多峰且变量不多的膜系；重复不同种子看结果稳定性。它仍没有全局最优保证，也要求有限上界。实现见 `film_optimization_solvers.py`。

### 5. 差分进化 `differential_evolution`

在有界群体中做差分变异、交叉和选择，可同时探查多个吸引域。默认群体数 12、种子 0；当前候选包含在初始种群中，SciPy 使用 `best1bin`、变异区间 `(0.5,1)`、交叉率 `0.7`、不做内置 polish。适合宽而仍有物理意义的边界和强耦合；预算至少覆盖初始群体及若干代。它只给出有限预算下的最好候选，不保证全局最优，且必须设有限上界。见 [SciPy differential_evolution](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.differential_evolution.html)。

仅固定层序的差分进化可**显式**启用“延迟批量评估（按代更新）”，并可选择 CPU 前向线程数（默认 1）或受支持的 Intel XPU FP64/complex128 前向设备。它不会让所有求解器都运行在 GPU；批量前向以外的评分和独立验证仍在 CPU。XPU 有设备、单目标/单角度/结构等能力限制，运行前会校验，设备失败不会悄悄切到 CPU。普通串行差分进化也不等同于 GPU 计算。详见 [HPC 契约](film-optimization-hpc-contract.md)。

### 6. 模拟退火 `simulated_annealing`

有界随机扰动，按下降温度偶尔接受较差候选，以尝试跨越局部障碍；默认种子 0。适合群体法预算不足时探索多峰区，再用局部法精修。温度日程、初始步幅、有限预算会强烈影响结果；短运行不保证走出局部谷。当前实现为项目自定义有限日程，非 SciPy 包装；同样要求有限上界。经典思想参见 [Kirkpatrick 等，1983](https://doi.org/10.1126/science.220.4598.671)，具体参数属于本项目约定。

### 7. 信赖域反射最小二乘 `trf`

用解析厚度 Jacobian 在有限界内降低**残差平方和**，适合多条件但处于解析支持域的单面正面膜系局部精修。相较无导数法可减少候选评估，但首次 Jacobian 本身计一次评估；起点、边界和残差尺度仍重要。支持域是单面、从 front 入射、相干前表面；双面、背向入射、不相干基板及内部未支持分支会明确拒绝。需要支持所用回调参数的 SciPy 版本。平方和下降不意味着最坏条件达标，应单独核对原始目标及留出误差。见 [SciPy least_squares / TRF](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html) 与 `coat_sim/core/film_optimization_derivatives.py`。

### 8. L-BFGS-B `lbfgsb`

以解析梯度和有限内存拟牛顿更新对有界厚度求局部下降；代理目标同样是带权残差平方和。适合解析支持域内的多变量精修，不会改层数。线搜索、尺度或边界附近可能影响收敛；需要有限上界和 SciPy，并检查最终最坏误差、梯度方法失败数及留出验证。解析支持域与 TRF 相同。见 [SciPy L-BFGS-B](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)。

## 把冗余层优化到零

零厚度的实际用途是让光学目标判定某层**冗余**：在理想薄膜模型中，它的传播相位为零，若其它层和界面条件相同，0 nm 层与删除该层的 R/T/A 应等效。这里有三个独立判断：

1. **边界允许零**：该层下界必须设为 0 nm，不能设制造最小厚度。默认固定层序已经如此。
2. **算法实际到零**：结果的该稳定层 ID 厚度须显示为数值 0，而不是“很薄”。基线可评估下界；有限边界方法也允许含端点，但随机/局部轨迹未必命中。放宽达标容限可能使搜索在小正数提前结束。检查原始结果数值、终止原因、预算；不要人为用任意阈值把正厚度改写成零并称优化成功。
3. **最少层数目标**：现有固定层序优化并不惩罚层数，也不自动删除零层。即使某层到零，它的稳定层 ID 仍在结果中；用户可在验证光谱、工艺与设计引用后**手动**清理，并重新仿真。

复现上节合成案例时，把一层 100 nm 的 n=1.23 膜覆在 n=1.5 基板前，目标设为移除该层的 500–600 nm 七点反射谱、容限 `1e−10`（底层比例）、下界 0、上界空、基线 100 轮/300 评估。测试实际要求厚度**恰为 0**、保留原 ID 和一层记录，并比较优化结果与移除该层的七点 R/T/A，绝对差不超过 `1e−12`。这是受控数值回归，不能推断真实制造中 0 nm 膜的物理可实现性，也不声称知道 TFCalc 内部算法。

## 改变膜系结构

优化方式改为“结构搜索”后，可选“组合”“仅针层”“仅层增长”。此路径会在候选光学材料与光学常数组内，按层内位置采样考察薄层插入，或对层厚做有限增长，再做局部精修与留出检查。它不是固定层序八种 solver 的同义开关。默认界面预算：总厚度 2000 nm，新层厚度 0.5–200 nm，总层数 32，新增针层数 1，位置采样 17，结构候选 128，针层厚度采样 9，增长步幅 `0.5,1,2,5,10 nm`，光学相位比例 `0.25,0.5,1`，增长循环 1，种子 0。搜索还受目标评估总预算。这里的“总层数 32”包含已有层；“新增针层 1”不是整个设计只许一层。

适用于允许新增层且已有可信材料数据的设计。先确认材料波段、n/k、候选层制造厚度、总厚度与层数预算；不要把搜索范围放大成不可生产的膜系。有限位置/厚度采样、候选预算和局部精修不会穷尽全部结构。检查结构轨迹、实际新增层 ID、训练与留出结果。实现为 `coat_sim/core/film_optimization_structure.py`，使用方式见 [结构优化指南](film-structure-optimization-guide.md)。

另有独立 `optimize_film_design_with_needle` API，依次在指定界面/材料上试插有限厚针层；默认最多新增 1 层、每界面每材料 1 次、插层厚 0.5–200 nm、总层数上限采用设计文件的 4096 层资源界限。这个 API 可显式设置多轮新增，**不是**界面“结构搜索”的当前单轮设置，也不是零厚度 needle 灵敏度算法。见 `coat_sim/core/film_optimization_needle.py`。结构搜索具体取样、预算和回退是本项目约定，不能从外部经典 needle 文献推导其性能。

## 修正板轮廓优化

入口为修正板优化窗口，核心 `optimize_correction_boards`。三种模式：“从零自动设计”先按允许的板中心网格生成轮廓；“优化已载入轮廓”从原有顶点开始；“固定板 + 可变板”保持指定板，只调整可变板。各模式都需明确板槽、每板允许的 X/Y 包络（mm）及轮廓/安装位置。默认目标是整套工艺沉积厚度场的均匀性变异系数 CV；也可用目标图的归一化 RMSE。它优化的是前向沉积模型输出，并非直接测量生产厚度。

主要控制及核心默认值：搜索网格不大于 81，评分预算 48 次，中心种子网格每轴 2 点，轮廓控制点 8，最小径向伸出 0 mm，最小边长 0 mm，最大面积占比 100%。自动模式的评估预算至少覆盖两次基线及全部板槽的中心种子组合。搜索先评分基线/种子，后对板中心 X/Y 与径向控制量作有界正负坐标试探；无改善时步长减半，到预算或中心与径向步长均低于 `1e−4` 时停。搜索保留候选短名单，再用原始较密网格复算最多 5 个候选/原板组合，最终应看**原网格**质量，而非只看粗网格排名。

界面可选择精确或快速周期评分、后端自动/CPU/GPU/DirectML 与残余阈值。注意核心 API 默认 `fast_cycle=False`、阈值 5%，但当前窗口会给快速模式及 100% 阈值提供自己的初始输入；保存的配置又可能覆盖默认，务必看当前窗口的**有效参数**。GPU/DirectML 若被选中用于沉积前向计算，优化决策逻辑仍在 CPU；以结果的 `actual_device` 判断实际设备。修正板、工艺及设备几何需复核，候选不会自动证明制造可行。实现见 `coat_sim/core/mask_optimization.py`，界面契约见 [修正板优化](project-mask-optimization-ui-contract.md)。

## 工艺转速局部优化

工艺执行路径中的“转速局部优化”是 `run_recipe(..., algorithm="optimize")`，只调整公转转速倍率 `s`，令 `rpm = 初始 rpm × s`，使当前采样沉积场的 `CV = std(膜厚)/mean(膜厚) × 100%` 下降。默认倍率区间 `[0.8,1.2]`，必须包含 1 且候选不超 ±300 rpm；默认最多 9 次评估。初始步幅为倍率区间一半，每轮在当前最优两侧试探，无改善则减半；评估数到限、步幅低于 `1e−5` 或初始转速为 0 时结束。若有改善且还够预算，对初始和候选都用 8 倍时间采样复算；只有细采样仍改善才接受，否则回退。预算不够时留意 `validation.status`，不能把粗采样改善称为已验证。

“工艺积分” `fast` 是执行仿真，“时间收敛检查” `reference` 是 CPU float64 时间采样对照，**都不是转速优化**。转速优化使用 CPU 完整时间积分；这里的自动/设备选项不意味着此局部搜索跑在 GPU。它适合已确定修正板和配方、只允许微调转速的情况；不能替代空间网格、源分布、周期混叠及生产标定检查。实现见 `coat_sim/core/algorithm_paths.py`。

## 结果判断、复现和排错

- **先看目标网格**：`targets_met` 只说明训练网格误差不超过容限。检查每个条件的实际 R/T、最大误差和加权 RMS，再看 `validation_complete`、`validation_targets_met` 与加密网格最大误差。窄谱峰仍可能落在两网格之间。
- **图区分于总评分**：优化完成后的单张模拟预览图默认取第一个目标的首个角度；结果摘要的目标数、最大误差、加权 RMS 和逐条件清单对应全部启用目标。检查多目标时逐项查看清单及各目标波段，不能只凭该单张预览判断其它目标达标。
- **看预算与停止原因**：`evaluation_limit`、步长限制、取消、失败、达标具有不同含义。初始候选会完整评估；后续失败候选消耗预算并记录，取消不会自动应用设计。梯度法的 Jacobian 与重复缓存命中也会影响计数。
- **比较方法时固定条件**：保持设计快照、材料数据集、目标、厚度边界、计算预算、验证倍率相同。随机法记录 seed；相同软件版本与环境更易复现，跨平台/SciPy 版本不保证逐位相同。
- **应用候选前复核**：核对结构与稳定层 ID、厚度是否触及 0/上下界、留出光谱及工艺约束。大预算不能弥补错误的材料 n/k 或错误目标。
- **常见拒绝**：非基线方法缺某层上界、上界不大于下界、变量光学数据不覆盖波段、解析法遇到双面/不支持端口、差分进化群体太小，都会导致无法开始或明确失败。按具体状态补足输入，不用静默替换 solver。
