# 膜系设计与优化：目标、约束和独立复核

版本：2026-10-18.1。原创研究学习资料；算例为合成教学，非实测、非生产配方或资格证明。

## 把规格写成可检验条件
优化输入要先确定波长区间、角域、s/p 或无偏振、温度/材料数据版本，以及 R/T/A 的定义。目标例如“600–700 nm 内 R≤0.01”是区间约束，不等于中心点满足。层数、可用材料、最小厚度、总厚度和允许层序是另外的制造限制。

本资料建议把每个违反量归一化。对于上限 U，可取 v=max(0,(R−U)/s)，s 是事先声明的尺度，目标 J=Σw v²。若换了单位或采样点数量，必须检查权重含义有没有改变。硬约束单独报告，不能由其他波段的高得分抵消。

## 求解器能与不能回答什么
有界最小二乘适合连续残差的局部求解；结果受初值、尺度与可辨识性影响。[least] 差分进化通过随机群体探索更广候选域，通常需要更多函数求值；有限运行没有全局最优保证。[de] 两类方法可以比较，但本资料没有对本项目进行速度排名，也不声称它们已经成为产品功能。

## 原创教学反例
设两个采样点的违反量为 0 和 0，二者之间却有一个很窄的反射峰。采样目标 J=0 仍可能违反连续区间规格。因此保存最优层表之后，要用独立、错开的较密波长点复算，在峰谷和边沿附近细化，再检查角度与两个偏振。这个反例不依赖任何真实产品数据。

## 建议的可复现实验记录
记录层表、材料来源与有效范围、目标与权重、上下界、初值/随机种子、求值次数、停止原因和未满足约束。训练点和验证点分开。改变层数与改变厚度属于不同搜索空间，不能只拿最终目标值比较算法。

鲁棒性先区分全栈共同比例误差、各层独立误差和材料色散误差。误差分布若只是人为假设，输出应称“情景通过率”，不能称真实良率。对小目标改进，先检查数值采样误差是否同量级，再考虑生产收益。
