## 1. 先给工程结论

1. **先构建“可测材料状态 → 电光输出”，再校准“工艺 → 材料状态”。** 氧流、温度、蒸发速率、源料 SnO₂ 配比本身不足以唯一确定电子浓度 N、迁移率 μ、光学 n/k 或方阻。同一名义工艺在不同腔体、源耗竭阶段、基底及热史下可以得到不同材料状态。
2. **经验模型与机制参考并列。** 有本批次厚度、方阻及光谱时，可以直接采用分层 σ∥ 和有限谱域 ε(λ)；它无需假装知道每个缺陷。需要解释红外自由载流子响应时，再用受约束的 Drude–Lorentz 参数化。两者都必须保留来源、适用域、不确定度和留出验证结果。
3. **Sn 含量、氧缺陷数和电子浓度不是同一个量。** 需要区分替位/析出、有效施主/中性复合体、缺陷电荷态、补偿和局域化。不能使用“每个 Sn 都贡献一个电子”或“每缺一个 O 固定贡献两个自由电子”作为未经校准的通用换算。[EO-S01；EO-S02]
4. **光学 μ、输运 μ、Hall μ必须分字段。** 仅在模型假设和本样品的交叉验证成立时才能连接。非抛物性能使有效质量随载流子填充变化；固定有效质量往往把这种变化错误归到 N 上。[EO-S03；EO-S04；EO-S05]
5. 本目录提供标准库 Python 参考代码、19 项数值测试和三组合成光谱。**没有工艺推荐值、真实样品拟合、独立实验验证或产品运行时集成。** 数值测试通过不代表工艺模型已验证。

证据等级与命题状态分开记录，见 [source_ledger.md](https://github.com/ii33/coating-research-library/blob/d1acac3766a3a1f0a14064edcbeadb7ea4244f4e/11_transparent_conductive_films/ito/electro_optics/source_ledger.md) 与 [evidence_ledger.json](https://github.com/ii33/coating-research-library/blob/d1acac3766a3a1f0a14064edcbeadb7ea4244f4e/11_transparent_conductive_films/ito/electro_optics/evidence_ledger.json)。本报告所有未引原文的建模选择均为本项目推导或待验证工程建议。

## 2. 工艺模型与电光模型之间的接口

建议按三层组织数据，而不是从氧流直接连一条经验直线到方阻：

- **工艺记录**：蒸镀方法、源料组成与质量/原子分数定义、源批次与蒸发进程、基压及残气、氧分压/流量及测量位置、沉积速率/工具因子、基底实测温度和完整热史、离子辅助状态、基底种类和前处理、冷却与储存时间
- **潜在或已测材料状态**：物理厚度 d、密度/孔隙率、Sn 深度分布与化学态、缺陷/补偿、晶粒和界面、连续性、粗糙度、应力；可辨识时再引入 N(z)、μ(z)、m*(z)
- **观测与预测**：Rs(x,y)、Hall 系数与磁场/温度依赖、T/R 光谱、椭偏 Ψ/Δ、雾度、色差、附着力/应力。每种量保存几何、单位、仪器配置和原始数据

### 两条可实施路线

| 路线 | 输入与输出 | 优点 | 不能声称的内容 |
|---|---|---|---|
| E：分层经验校准 | 测得/校准的 σ∥,j 与 εj(λ)，输出 Rs 与 T/R/A | 最短验证闭环，可绕开不可辨识的微观分解 | 插值成功不等于已知缺陷机制；有限谱表不保证全频因果性 |
| M：有边界机制参考 | N、m*、μopt、带间振子、μtransport、层厚，输出 ε、Rs、光谱 | 检查量纲、极限、自由载流子与干涉影响 | 没有缺陷动力学和设备校准时不能由工艺唯一预测这些输入 |

工艺到路线 E 参数的回归可以先选少量维度的有界响应面/高斯过程；路线 M 可以以后接入缺陷/晶化/扩散模型。选择应由样本数量、可识别性、留批验证误差决定。此处未训练任一路线的工艺回归器。

## 3. 载流子、缺陷和电学模型

### 3.1 不把化学计量直接当 N

一般电中性条件写为：

N + Σₐ |Zₐ| Cₐ⁻ = p + Σ𝒹 Z𝒹 C𝒹⁺

这里 C 是指定电荷态的缺陷浓度，不是总 Sn 或总氧缺陷量；中性复合体不直接出现在净电荷一侧，却可能影响散射。电荷态依赖费米能、温度和局部结构；还需区别自由载流子与局域态。Sn 激活比例可以作为待校准隐变量，但不能用总 Sn 原子分数直接代替激活比例。

Furubayashi 等针对 RPD 生长、随后负氧离子处理的 ITO，观测到 N 降低时 μH 先升后降，并将后段与 Sn–O 中性复合体联系。Klein 等的原位研究摘要报告了氧空位中性化和 Sn 施主转为陷阱的限制机制。它们说明“氧越少电导必然越高”的单变量外推不可靠；**均不是本蒸镀设备的标定曲线**。[EO-S01, §3–4/Fig.2；EO-S02, Abstract]

最低可用实现不必强行求所有缺陷：以实际测得的 σ∥ 或 N_H、μ_H 为主，缺陷研究用于约束可能方向和设计辨别实验。

### 3.2 面内电导与方阻

在连续膜、欧姆响应、相同面内电场、层间能充分交换电荷且不受接触限制时：

σ∥(z) = q N(z) μtransport(z) [S/m]

G□ = ∫₀ᵈ σ∥(z) dz = q ∫₀ᵈ N(z) μtransport(z) dz [S]

Rs = 1/G□ [Ω/□]

离散成 j 层：Rs = 1 / Σⱼ σ∥,j dⱼ。**先积分电导，再取倒数；不能先平均电阻率再除总厚度。** 对均匀膜才有 ρ = Rs d；对梯度膜，Rs d 是等效面内电阻率，不能称局域 ρ(z)。[EO-C02, derived；EO-S07, Eq.4]

适用限制：

- 岛状、裂纹、孔隙贯通、横向非均匀或临界渗流：上述标量积分不能代表实际电流网络
- 跨膜输运是不同边界问题；无接触阻的标量串联极限为电阻面积积 R⊥·A = ∫ρ⊥ dz，不是 1/∫σ∥dz
- 各向异性必须积分合适的面内电导张量后求逆；存在 σxz/σyz、霍尔耦合或不同层电位时需要完整张量与边界条件，不能逐元素套标量方阻公式
- 接触、探针压痕、非欧姆、基底并联、边界修正和温升应独立建模/排除

### 3.3 Hall 不等于深度剖面仪

均匀、单电子载流子模型中，RH = −rH/(qN)，所以 NH = N/rH，μH = rH μtransport。只有 rH≈1 才可把 NH≈N、μH≈μtransport；虽然同一模型下 q NH μH = σ 仍成立，两个拆分参数不能自动解释成微观真值。

在各层同号载流子、低场、rH=1、共享面内电场的理想并联例子中，令 S₁=ΣNⱼμⱼdⱼ、S₂=ΣNⱼμⱼ²dⱼ，则：

Nsheet,Hall = S₁²/S₂，μHall = S₂/S₁

这说明多层 Hall 给的是迁移率加权组合，而不是简单的 N 深度平均；高场、多带或不同 Hall 因子需要更完整处理。[EO-C03, 本项目低场张量展开推导]

测量须保存原始磁场/电流反转、欧姆接触验证、样品几何、厚度和温度。van der Pauw 条件包括薄、均匀、单连通样品和边缘小接触；厚度不确定度直接影响体浓度与电阻率。[EO-S07, The van der Pauw Technique]

### 3.4 单位约定

| 量 | 输入常见单位 | 内部 SI 换算 |
|---|---|---|
| N | cm⁻³ | ×10⁶ → m⁻³ |
| μ | cm²/(V·s) | ×10⁻⁴ → m²/(V·s) |
| 厚度 | nm | ×10⁻⁹ → m |
| ρ | Ω·cm | ×10⁻² → Ω·m |
| 光子能量 | eV | ω = E q/ℏ → rad/s，不能当 Hz |

q=1.602176634×10⁻¹⁹ C。代码中 N、μ、厚度均用带单位的字段名；不接受负数、NaN 或无限材料参数。

## 4. 光学介电函数与电学连接

### 4.1 符号、因果性和有限适用域

本目录固定时间因子 exp(−iωt)，沿 +z 传播为 exp(+i k₀ ñ z)，ñ=n+ik；被动吸收要求 k≥0、Im ε≥0。ε=ñ²，α=4πk/λ 是强度吸收系数。[EO-S06, §2–2.1]

采用：

ε(ω) = ε∞ − ωp²/[ω(ω+iγ)] + Σⱼ Sⱼ ω₀ⱼ²/[ω₀ⱼ²−ω²−iΓⱼω]

ωp² = N q²/(ε₀m*)，γ = q/(m* μopt)，σDrude(ω)=ε₀ωp²/(γ−iω)

故 σDrude(0)=Nq μopt。这是**同一 Drude 参数模型的 DC 外推**，不是证明测量的 DC 电导一定等于光学外推值。晶界、连通性和不同测量频率可能造成显著偏差。[EO-S03；EO-S05]

正的 Γ、γ 和非负振子强度保证这一参数模型的被动性与相应解析因果结构。代码采用一个普通 Lorentz 项作为带间贡献的演示；没有实现完整 Tauc–Lorentz 带边、Burstein–Moss/多体重整化或非抛物性能带求解。ε∞ 是所选频段内未显式纳入的高能贡献；有限拟合区间不授权任意 UV/远 IR 外推。演示区间为 400–2500 nm，**只是代码适用域标签，不是经实验建立的 ITO 有效域**。

文献对自由载流子与带边吸收采用不同组合：Fujiwara/Kondo 使用 Drude 与 Tauc–Lorentz；Gui 等在 200–1680 nm 的 RF 溅射样品中使用多步/梯度拟合并交叉比较 Hall、四探针和椭偏。[EO-S03, Abstract；EO-S08, p.2、p.8]

### 4.2 m* 与 μ：必须解耦记录

- 有效质量会受到非抛物性与载流子占据影响，不能默认全浓度、全工艺固定为 0.35mₑ。该数在演示中仅是显式假设。[EO-S03；EO-S04]
- μopt描述光谱拟合所见的有效阻尼；μtransport描述 DC 路径；μH还含 Hall 因子和测量模型。代码要求 μtransport 单独提供，避免自动复制 μopt
- 光谱优先约束 ωp²∝N/m* 和 γ，而不直接唯一约束 N、m*、μopt 三者。固定 m* 的反演应报告“在假设 m* 下得到的 Nopt”，不要把它标成直接实测 N
- 对多孔/纳米晶膜，局部光学载流子响应与宏观 Hall 响应的区别可能更大；Gondorf 等即给出这类反例，不能把其参数搬到致密蒸镀 ITO。[EO-S05, Abstract]

### 4.3 经验 ε(λ) 也是完整模型输入

`EmpiricalEpsilon` 对有限域内复介电函数线性插值；可以来自经校准的实测 n/k 或拟合，代码禁止外推。这样无需把测量无法识别的 N 和 m*硬拆开。插值保持本表的被动虚部，但**不保证全谱 Kramers–Kronig 一致性**；若跨宽谱拟合，应选因果振子、合适的 KK 约束样条或其他有物理约束的表达，并单独验证未参与拟合的光谱。

### 4.4 粗糙度与雾度不能伪装成 k

本实现是平面镜面模型。积分球总 T/R 与小接收角镜面 T/R不是同一观测。若散射光没有被探测器收集，1−Tspec−Rspec包含未收集散射，不能全部解释为热吸收。粗糙表面需有 AFM/PSD 或独立雾度/角分布证据；亚波长细结构可在条件成立时引入有效介质粗糙层，但不等价于雾度模型。直接加大 k来吃掉散射会污染 N、μopt和热吸收推断。[EO-C06, 测量能量收支推导；待实测辨别]

## 5. 膜/基底光谱：相干与非相干分开

给每个薄层 ñj(λ)、dj，从入射侧排序。相位厚度 δj=2π ñj dj/λ；法向界面振幅 rij=(ni−nj)/(ni+nj)、tij=2ni/(ni+nj)。可乘 2×2 矩阵，也可用等价的稳定反射/透射递推。参考代码用后者，避免厚吸收层的指数增长。[EO-S06, §3–4]

### 三种几何不能混报

1. `coherent_rt(..., n_out=glass)`：薄膜后接半无限玻璃，T 是**进入玻璃的功率**，不含玻璃背面
2. `coherent_rt(..., layers=[薄膜..., (glass, dglass)], n_out=air)`：包含有限玻璃厚度，保留全部相位，适用于实际保持相干且仪器可分辨相位的条件
3. `incoherent_substrate_rt(...)`：薄膜相干，厚玻璃相位完全平均，玻璃本身无吸收，背面裸露；适用于仪器带宽、厚度/角度分布等确实平均掉基底干涉的情况。不能仅凭“超过多少 μm”一刀切判断

法向、入射/出射外介质无吸收时 R=|r|²，T=(nout/nin)|t|²，A=1−R−T。代码限制入射、出射介质为实正折射率；不吸收玻璃的非相干公式为：

D = 1−Rfront,reverse Rback

Ttotal = Tfront Tback/D

Rtotal = Rfront + Tfront Rback Tfront,reverse/D

其中反向前膜计算须倒转薄层顺序并交换边界介质。**当前非相干实现没有吸收玻璃、背镀膜、多厚层或部分相干**。有吸收基底时应接入完整强度传输与吸收传播（并正确处理吸收介质中的边界功率），不可简单把这个限制忽略。[EO-S06, §4.4、§6；EO-C05, 几何级数推导]

代码输出的是理想镜面模型的 T/R/A；不含积分球口径、仪器线形、测量偏振/角度展宽、非均匀膜空间平均。真实光谱比较前需按测量分辨率进行卷积或平均。

## 6. 最低输入和建议测量包

### 层 A：能可靠给出方阻及透反射的最低数据

- 样品/批次/位置 ID；物理厚度和误差、均匀性图；基底厚度及裸基底 T/R 或 n/k；明确基底相干处理
- 同位置四探针或 van der Pauw 方阻及接触/边界检查；测量温度、时间、重复次数
- **同时测 T(λ)、R(λ)**，注明绝对值/对裸基底归一化、镜面/总量、波长范围、步长、光谱分辨率、入射角、偏振、积分球/探测器配置
- 如使用经验分层模型：每层厚度/复介电谱/面内电导的来源及协方差；若无法独立辨别各层，应先降到均匀有效层

### 层 B：要解释 N、μ及缺陷时再补充

- Hall原始反转数据及 B扫描、接触图形、Hall因子/单载流子假设；可能时做温度依赖
- 多角度椭偏 Ψ/Δ与独立台阶/XRR厚度；AFM粗糙度，XRD/密度/连续性证据
- 实际膜 Sn/In/O 定量与深度信息、化学态；XPS定量要记录表面污染、灵敏度系数和离子溅射改变价态/氧亏的风险，不能直接将某个O 1s拟合峰面积等同空位浓度
- 应力（如基底曲率）与附着力/环境可靠性测试；实际应用的最高温度、弯曲半径和湿热约束

只有 QCM 标称厚度和单点550 nm透过率不足以识别这些参数。测量计划是待设备/样品确认的工程建议，不是现成合规测试规范。

## 7. 参数识别与不确定度

### 7.1 明确的不可辨识反例

在固定其他振子的 Drude 模型中，同时作变换：

N→cN，m*→cm*，μopt→μopt/c

则 ωp²与 γ完全不变，所以全部 ε(λ)、n/k、T/R也完全相同。代码中有此单元测试。增加波长点或更换优化器不能解除这种结构性不唯一；需要外部质量信息、可信 Hall约束或有证据的先验。若 μtransport也除以c，DC电导亦不变。[EO-C04, derived]

额外常见相关性：d与n干涉相位；粗糙层与低密度层；Drude长波尾与带间背景；两层厚度与介电函数；接触/基底并联与“低体电阻率”。增加自由层数总能改善训练残差，不能据此确认真实深度梯度。

### 7.2 拟合与校准顺序

1. 先拟合裸基底；独立测厚，检查绝对/相对光谱口径
2. 均匀层 + 最少必要振子，施加厚度、非负阻尼/强度和适用域约束
3. 同时拟合T/R，必要时多角度椭偏；多起点检查局部最小值与参数相关矩阵
4. 检查残差随波长/角度是否有系统结构；仅有新增证据时增加界面层或梯度
5. 留出整批或整工艺条件验证，而不是随机分散同一条光谱的波长点
6. 工艺回归仅在训练条件包络内使用，跨设备、基底、源料或热史标为域外

Mendelsberg等摘要强调初值敏感性及联合T/R可降低参数不确定性；本报告未取得其全文，故不提取具体拟合约束或精度。[EO-S09, Abstract only]

### 7.3 不确定度输出

- 区分测量误差、同片空间差异、重复样/批间差异、参数识别误差和模型偏差
- 每次计算应携带参数联合协方差/后验样本，不把相关参数误作独立抽样
- 可对正参数用对数尺度抽样；传播到 Rs、T/R/A 和目标带平均量，报告区间而非只报一个“最佳值”
- 单层独立小误差近似有 δRs/Rs≈−δN/N−δμ/μ−δd/d；方差必须加协方差项，不能机械平方和
- 多层应传播 Σσjdj 的联合不确定性；域外、缺测或不可辨识不应用窄区间掩盖

当前代码**没有拟合器、误差传播器或真实后验**；这些是下一阶段接口要求。

## 8. 最小验证实验：先解决不唯一，再追求最优

建议用本蒸镀设备可安全实现的条件制定DOE，不照抄溅射文献配方：

| 实验块 | 要辨别的问题 | 至少保留的对照 |
|---|---|---|
| 厚度系列 | 均匀σ是否成立、死层/连续性是否重要 | 同批基底、同材料条件、独立测厚、Rs与T/R |
| 氧条件 × 基底热史 | N与μ变化是否混淆、工艺是否交互 | 固定厚度而不是固定时间；记录真实速率/温度 |
| 沉积态/退火态配对 | 厚度、密度、应力及载流子是否同时变 | 同片/同批见证样；测量顺序和空气暴露一致 |
| 界面/基底对照 | 并联导电和界面层是否主导 | 裸基底电学光学、不同绝缘基底/阻挡层 |
| 跨批重复与留批 | 工艺稳定性、外推能力 | 重复中心点；预先保留整批不参与拟合 |

建议预先定义工程可接受的Rs误差、光谱误差、目标带T下限及可靠性门限，再采集重复实验估计噪声；本报告不虚构通用合格百分比。通过标准至少包括：T/R残差与仪器不确定度匹配、独立方阻预测正确、保留批次仍有效、参数符合约束、实测总能量收支与散射口径一致。机械可靠性不应由光学拟合推断。

## 9. 透明导电膜的真正权衡

目标要同时指定 Rs、目标谱带、基底和应用约束：

- 加厚在均匀σ假设下按1/d降低Rs，但干涉会移动、吸收路径变长，透过率并不对厚度单调；真实厚度还可能改变微结构
- 增N可能降低Rs，但取决于μ是否随之下降；自由载流子红外损耗、反射和ENZ位置也会改变
- 提升μ而不过度提高N常是值得研究的方向，但受缺陷、晶界、温度预算和结构约束，不是保证可实现的调参按钮
- 可见平均T良好不代表近IR透过良好；低透过可能来自反射也可能来自吸收，二者对热负荷不同
- 应力、附着力、弯折、湿热稳定性、光学色差和厚度均匀性可能使“最低Rs样品”不适合应用
- 任何 Tᵃ/Rs 类综合指标都应声明谱带、权重和指数；不要把文献中一个FOM称为全用途最优

目标带加权定义为 T̄ = ∫T(λ)W(λ)dλ / ∫W(λ)dλ。明视觉需要明示光源谱与V(λ)，太阳能用途需指定太阳谱/器件响应。代码 `weighted_mean` 接受外部权重；演示仅按波长等权平均，绝不是标准“可见光透过率”。
