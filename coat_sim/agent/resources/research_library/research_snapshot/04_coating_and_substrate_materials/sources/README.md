权利：按用户要求收录项目原创研究文字；来源未声明全库许可证，本导入不改授软件 MIT。第三方原文/图片未内置。
阅读：相对 Markdown 链接改为固定版本在线来源；图片改为原图链接。正文中的源码、数据路径及复算命令仅供阅读，附件与可执行代码未随此快照收录。


本轮共76个来源记录：氧化物/H4 29、红外膜/基片24、Ge/金属/方法23。每条有直达原始入口、核对日期、支持范围、可读范围或限制及对应摘要。数据库里的参考值尽量回到厂商技术表、官方SDS和原始论文；只取得摘要的条目明确标示，没有声称阅读全文。

- `summaries/`：原创摘要、必要事实、原文定位、适用边界
- `originals/`：本地CC0数据原件及许可，不发布
- `../data/source_registry.json`：合并目录，保留各分册的字段和ID
- `../data/local_originals_manifest.json`：本地5个n/k数据文件的校验信息

版权不是按“网页可打开”推断。原厂PDF/完整论文/图表没有明确再分发许可时只链接，不上传全文。RefractiveIndex.INFO数据库明确CC0，其授权不覆盖指向的论文PDF。McPeak论文开放非商业许可，但本轮同样不再分发全文，避免把个人可读误解为任意商业可再分发。

目录中的source class是来源的直接身份，不保证每个厂商表都是独立测量。厂商二次汇编值、原作者实验值和本库派生值在材料卡中分开。实际批料的COA、采购SDS和见证片属于后续本机证据；本轮没有虚构这些文件。
