# 设计几何与工艺详情产物

当用户要求查看修正板、机器、蒸发源或基片形状，或要求展开多层工艺时使用本技能。

## 生成几何图

调用已接入的 MCP 工具 `render_design(kind, design_path)` 输出单项设计的离线 SVG。`kind` 为 `mask`、`machine`、`source` 或 `substrate`，`design_path` 使用工具返回的实际 data 文件引用。将返回的 `files` 和简短 `summary` 交给用户，不要要求模型读取或复述完整 SVG。

俯视图使用机架 XY（修正板/机器）或设计局部 XY（源/基片），长度为 mm。机器图的圆形仅为运动轨迹、参考节圆和基片边界示意；不表示齿形、实体厚度、碰撞或完整三维设备。图面需按实际文件说明坐标与单位。

## 展示多层工艺

对已保存的工作流清单调用 MCP 工具 `render_design_workflow(manifest_path)`。它读取清单中的已保存依赖，返回几何 SVG 和可搜索、可排序的离线 HTML 工艺详情表。工艺层数较多时优先用此工具；不逐页读取层JSON，也不把steps复制进模型上下文。

60 层及更大的工艺应保留在 HTML 文件中；给模型或用户的工具结果只含 HTML 文件引用、工艺名与层数，不返回完整 `steps` JSON。源与监测器位次从 1 开始，修正板在页面中按 1 起始显示。

这些图和表只是已保存设计数据的展示，不运行沉积仿真、不补全缺失参数、不验证制造或工艺性能。SVG 和 HTML 都是单文件离线产物，保存于 `data/tmp/design-visualizations/`；使用工具实际返回的文件信息引用产物。机器文件本身不存基片轮廓；单项机器图只能在工作流提供关联基片时叠加工件盘边界。
